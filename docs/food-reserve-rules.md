# 장기 식량 생산과 비축의 회계

기준 커밋은 PR #24의 `0340e0052599bdaa33fcff6daf88c011c55834b7`이다. 8개국·32개 지역의 기존 연간 경제를 사용한다. 공공 경작을 선택하는 옵션은 `public-harvest/1`이다.

## 세 경로와 같은 연초 대조

세계 생성 후 1년차까지 기존 규칙으로 한 번 계산한다. 이 상태를 복사해 2년차부터 A는 기존 유닛 유지비 우선, B는 기존 주민 구호 우선, C는 A에 공공 경작만 추가한다. 세 경로의 기존 표시·이동 명령과 모든 외생 기후 입력은 같다. 0–19는 개발 표본, 20–39는 독립 검증 표본이다. 결과 확인 후 계수를 조정하는 절차는 없다. C에서 보호선이나 세율을 바꾸는 코드는 없다.

## 공공 경작

지역 연초 인구를 (P), 연초 현지 공공 식량을 (O), 수확 직전 현지 공공 식량을 (D)라 하자. 목표는 `T = P // 8`, 기존 창고 한도는 `H = P // 4`다. `O < T`인 지역에서만 공공 경작을 검토한다. 수확 시 추가 입고 여유는 `max(0, min(T,H) - D)`다. 입고 비용을 피하기 위해 다른 지역의 창고를 가정하지 않는다. 토지와 저장 장소는 같은 지역 집계 단위다.

전체 경작자 (a)는 공공사업·복무·노동 중단·민간 설비 건설·토양 보전 비용을 반영한 뒤 실제 농지 슬롯을 점유한 인원이다. 기존 지역 작물 함수는 다음과 같다.

```text
N = 32 × 생산성 × 기술 × 비옥도 × 생산 직전 토양 × 기후 × 장비 효과 × 농업설비 배율
F(x) = floor(x × N / (10 × 1000⁷))
```

`k ≤ a // 8` 범위에서 `F(a) − F(a−k)`를 현 창고 여유 안에 입고할 수 있는 최대 정수 `k`를 선택한다. 양의 수확이 없으면 배정도 0이다. 주민 민간 계정은 `a−k`명의 수확 `F(a−k)`을, 공공창고는 `k`명의 한계수확 `F(a)−F(a−k)`을 받는다. 두 몫은 총수확과 정확히 일치한다. 두 번 내림한 값을 합쳤을 때의 최대 1단위 잔차도 영수증에 남긴다. 점유한 경작 슬롯은 각각 `a−k`와 `k`이며, 한 개 슬롯은 경작자 한 명이 이용한다. 농지 타일에는 여러 슬롯이 있다. 기존 장비 가동·마모·토양 비용은 공동 수확에 한 번만 부과한다. 농장 건축, 별도 임금, 창고 사이의 무상 배송은 모형에 없다.

수확 시점에 그해 기후와 유효 수확량이 정해지므로 C는 기존 작기 안에서 경작 노동과 산출의 최종 귀속을 결정한다. 파종 전에 작황 위험을 지는 장기 계약은 모형화하지 않았다. 과거 실적을 참조하는 국내 정책에는 지역의 총수확을 전달한다.

## 주민 보호선과 흐름

프로젝트 보드의 ‘장기 식량 생산과 공공 비축’ 그림에 수확·징수·정부창고·주민 식사의 계정 간 이동을 표시했다. [편집 가능한 식량 흐름도](https://www.tldraw.com/f/0bUzL9_Y5-sq8tpY7HMM6)

국경 거래 후, 국내 배송 전에 지역 민간 식량 `S`를 관측한다. 보호선은 모든 군에서 `P + P//8`, 과세 가능 잉여는 `max(0, S − P − P//8)`이다. 세액은 잉여 외에 현지 창고 여유, 정수 나눗셈, 인구별 상한, 비축 사업 선택 및 납부 조정의 영향을 받는다. 원자료에는 기준 부과액, 상시·추가 징수, 감면, 거부, 실제 징수, 취급비, 실입고를 따로 기록한다. 공공 경작의 민간 수확 감소는 세금 부과 이전에 발생한다. 따라서 보호선이 같아도 주민 식사에 영향이 있다.

| 단계 | 검산 |
|---|---|
| 수확과 국경 교역 | 민간 기초 + 총수확 − 생산 중 식량 사용 − 공공 귀속 + 국경 민간 순수입 − 식량 운임 = 과세 직전 민간 식량 |
| 징수·구호·국내 배송 | 징수는 민간에서 총액 차감, 공공에는 취급비를 뺀 금액 입고. 구호는 정부에서 민간으로 한 번 이전. 국내 민간 배송의 출고·입고 수량 일치, 운임 별도 |
| 주민 식사 | 공공 배식의 민간 입고를 더한 뒤, 실제 섭취 + 미충족 = 연초 주민 필요량. 섭취와 민간 부패를 각각 차감 |
| 공공 비축 | 기초 + 공공 수확 + 순조세 입고 + 창고 순이송 + 순원조 − 구호 출고 − 사업·배식·기타 실비 − 운임 − 부패 = 기말 |
| 주민·현금·노동 | 지역 합계가 국가 장부와 일치. 기존 출생·사망·이주·현금 결제 재생, 공공/민간 경작 노동과 점유 슬롯이 기존 농업 배분과 일치 |

국내외 민간 운송에서 식량 화물 자체의 취급 손실은 0이고, 모든 재화의 운송에 실제 식량 운임이 붙는다. 국제 원조는 별도 수량 손실이 있다. 주민들에게 지급된 공공 배식과 실제 섭취를 합하지 않는다. 게임 유지비 충족률은 기존 원장의 지급 세트 합계 / 표시된 유닛-턴 합계이며 분모가 0이면 정의되지 않는다.

## 비축 지속 여부와 자료 읽기

보관 식량의 일수는 `365 × 연말 공공 식량 / 그해 주민 필요량`이다. 151–200년 **모든 해** 1일 이상을 유지했는지와, 여기에 151년 기초 대비 200년 기말의 순인출이 없었다는 조건까지 충족했는지를 구분한다. 연도별 식량 부족률은 실제 미충족/실제 필요량, 누적·표본 결합 시에는 분자와 분모를 각각 합산한다. 5년 연속 전환 지표는 관측 후 계산하며 어떤 정책 입력에도 사용하지 않는다.

`examples/food-reserve-v1/study/seed-NN-X-regions.jsonl.gz`는 헤더의 열 이름 다음에 매년 지역 행 32개가 하나의 JSON 배열로 이어진다. `-totals.jsonl.gz`는 매년 세계 합계와 국가 8개의 행을 기록한다. 농업 기술·토양·기후 등 강도 변수는 유효 경작자 가중치의 분자와 분모를 함께 보존한다. 지역별 필드 출처는 `experiments/food_flow.py`의 `PROVENANCE`에 있다. 연초 해시와 50·100·200년 원장 해시는 시드별 JSON에 있다. 기존 두 경로는 PR #24에 저장된 해시와 비교한다.

일반 게임에서도 `python -m civsim.annual_game step <이전저장> --public-farm --out <새저장>`으로 활성화한다. 그 이후 같은 궤적에서는 선택이 유지된다. 초기 비교에서 선택하지 않은 경로는 종전 스키마를 사용한다.
