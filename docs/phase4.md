# 4.0 지역 원장과 연간 계산

국가의 식량이 충분해도 운송 가능한 지역과 거리에 따라 어떤 지역은 식량을 받지 못한다. 개발 시드 18의 2년차에 국가 3은 수요보다 685단위의 식량을 더 보유했다. 지역 12로 통하는 도로는 각각 266, 447, 350단위를 모두 운송했고, 그 지역 주민에게 591단위가 모자랐다. 같은 시점의 재고·비용·배차 기준을 유지하고 국내 도로의 용량 상한만 풀면 부족량은 0이었다. [실제 타일 이동 기록](../examples/phase4/study/cases.json) · [50년·200년 실험](phase4-results.md)

## 한 해의 원장

1. 국가 내 타일을 서로 연결된 지역으로 배분한다. 연도 0 세계에 전체 타일, 지역 중심·소속 타일, 국내 도로와 국경 통로를 저장한다. 각 지역에는 독립된 인구·현금·재고·경작 가능 면적·토양·매장량·자본 연령별 계정이 있다. [지역 배분과 검사](regions4.md)
2. 연초 재고로 기존 설비의 유지비를 내고 토양 관리와 신규 건설에 광석·도구·인력을 배정한다. 남은 인력이 지역 환경에 따라 식량·광석·도구를 생산한다. 건설 당년에는 새 설비가 가동되지 않는다. 지역 효과는 설치 지역에 귀속된다. 국가 효과 비교에서는 동일한 전국 보너스 점수를 적격 지역에 나눈다. 개간은 설치 장소에만 추가 경작 인원을 제공한다. 계획은 두 군에서 같은 지역 정보를 쓴다. [생산·투자·토양 수식](regional-production.md)
3. 인접한 외국 지역끼리만 국경 거래를 한다. 식량→광석→도구 순서로, 연초 생산 직후 수량에서 식량 목표는 인구의 9/8(정수), 광석은 인구/20, 도구는 인구/40으로 정한다. 호가는 3.0의 고정 기준가와 재고비율을 따르며 양측 호가 평균을 내림한 값에 결제한다. 구매자 현금과 도로 잔여 용량, 판매자의 현지 배급 및 식량 운송비를 모두 확인한다. `ceil(화물 수량 × 거리 / 100)`만큼 판매 지역의 식량이 줄고, 양국 현금 증감은 상쇄된다. 국내 용량 실험에서도 국경 용량과 국경 정산 순서는 동일하다.
4. 국내에서는 부족한 지역으로 도로를 따라 배차한다. 모든 재화와 양방향 차량이 같은 연간 용량을 사용한다. 중계지를 거치는 배송은 구간마다 수량을 차감하고 운송비를 올림해 출발지에 청구한다. 길이 없으면 배송도 없다. 상한 해제군도 실제 타일 경로와 구간별 식량비를 사용한다. [배차 순서와 구간별 비용](logistics4.md)
5. 각 지역 주민이 식량을 소비하고 남은 식량 일부가 부패한다. 출생은 섭취량, 사망은 연초 인구·부족량을 사용한다. 국내·국제 이주는 인접한 통행 가능 지역의 주거 여유와 비축 식량을 확인하여 배정한다. 이주 인구는 화물을 운반하지 않는다. 이 모델은 집단별 인원을 갱신한다.
6. 지역별 생산·정산·소비·이주 계정을 대조한다. 별도로 국가의 연초 잔액에 생산, 투입, 국제 거래, 운송비, 소비, 출생·사망, 국경 간 이주를 각각 기표해 기말 지역 합계와 비교한다. 현금은 국제 거래에서만 소유 지역이 바뀐다. 물량과 현금이 일치한 연도만 발행한다. [연간 엔진과 감사 함수](../civsim/regional_engine.py)

## 실행 방법

```sh
python -m civsim regional --seed 7 --years 200 --out runs/r4-seed7
python -m civsim verify runs/r4-seed7
python -m civsim analyze runs/r4-seed7 --csv runs/r4-seed7-regions.csv
python -m civsim regional --seed 7 --years 200 --logistics unlimited --out runs/r4-unlimited
```

`--investment-scope national`은 국가 범위 투자 효과, `--no-soil-care`는 유상 토양 관리 비활성화, `--close-road A-B`는 기존 국내 도로 한 곳의 완전 폐쇄다. 이 옵션의 A와 B는 오름차순 지역 ID이며 여러 번 지정할 수 있다. 폐쇄한 도로는 화물과 이주 모두에 사용할 수 없다. `--per-nation`으로 지역 수를 지정할 수 있고 영토가 작으면 타일 수가 상한이 된다. 국가 모델을 실행하려면 기존 `python -m civsim run`과 버전별 투자 옵션을 사용한다.

지역 실행 디렉터리의 `manifest.json`에 모델 4.0과 정책을, `world.json`에 초기 자원 및 공간 정보를 저장한다. `years.jsonl` 각 행에는 국가·지역별 기초·기말 상태와 생산, 운영비, 소비, 거래·운송 구간, 이주 내역이 담긴다. `verify`는 시드에서 세계와 정책을 다시 생성해 파일의 바이트 전체를 확인한다. 20시드 실험은 50·200년 누계와 원장 해시를 보존하며 상세 2년 예시는 별도로 제공한다. [시드 7 원장](../examples/phase4/seed7-two-years) · [전체 실행 명령·검증 로그](phase4-run.md)

## 검증의 범위

- 전국 자본 보너스 비교는 동일한 수의 가산점을 어디에 적용할지의 실험이다. 국가 장부에서 계산하던 3.1의 모든 투자 선택·비용을 지역 단위로 그대로 복제한 모델과의 순수한 공간 효과 비교는 별도 과제다.
- 운송은 연간 단위로 정산한다. 화물은 실제 도로 구간을 통과해 수량·거리 비용·용량을 사용하며 그 해 소비 전에 도착한다. 일별 이동 시간, 연말 운송 중 재고, 도로 건설·열화·차종별 화물 단위는 모델링하지 않았다.
- 배차는 정해진 우선순위를 따른다. 수송 전체를 최적화하지 않으므로 한 지역의 물류 개선이 다른 지역의 가용 식량을 줄일 수 있다. 생산과 국경 정산이 국내 배송에 앞선다는 연중 순서도 결과에 영향을 준다.
- 경작지는 지역 안의 유효 타일 수로 집계한다. 중심 지역에 인구가 집중되는 초기 분포, 도로 용량 및 운영비는 가정한 수치다. 실험은 20개 시드와 기본 지역 수, 200년 이내에 한정된다. 개인별 행동, 실제 역사 보정, 지도 UI는 이번 검증에 포함하지 않았다.
