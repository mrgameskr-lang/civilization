# 7.3이 사용하는 기존 국경·국가 장부

기준은 PR #30의 `a27b952`다. 원래 연간 게임은 국가 8개의 28개 쌍에 외교 상태를 보관한다. 이 중 실제 통행 가능 용량이 양수인 국경도로가 있는 쌍만 경제 원장의 인접국이다. 국내 지역 사이의 도로와 국제 도로는 서로 다른 목록이다.

| 기존 기능 | 결정을 내리거나 결과를 확인하는 시점 | 코드와 확인할 원장 |
|---|---|---|
| 관계·신뢰·긴장 | 연초에는 직전 연말 상태를 읽는다. 연말에는 실제 거래·이주·원조·통행 거절·위반을 결산해 다음 해의 관계 지표를 만든다. | [국가 쌍의 계획·결산](../civsim/diplomatic_rules.py), `diplomacy/pairs/*/opening`, `flows/directions`, `closing` |
| 양자 무역 협정 | 인접 양국이 동의하면 체결한다. 유효한 협정 아래 수출 제한이 실제 거래를 거부한 방향에 위반이 기표된다. 위반이 2년 연속이면 협정이 조기 종료된다. | [선택형 외교 규칙](../civsim/diplomacy61.py), `policy/directions`, `agreement_breach`, `breach_streak`, `diplomacy/events` |
| 국경 거래·정주 | 재고·현금·실제 국경도로에서 거래 가능한 양을 계산한 뒤 접근 정책을 적용한다. 이주는 보내는 지역과 받는 지역 양쪽의 허용량을 차례로 확인한다. | [국경 거래와 이동](../civsim/border.py), [통행 영수증](../civsim/diplomatic_flows.py), `diplomacy/physical/trade_attempts`, `migration_attempts`, `border_market/trades`, `moves` |
| 공공재정·정치 | 연초 관측과 선거·대표 집단의 반응으로 공공사업을 선택한다. 노동·창고·관리 한도에 따라 실제 사업·구호가 집행되며 그 해의 생산·주민 식사·정치 관측이 뒤따른다. | [연간 집행 순서](../civsim/supply62.py), `government`, `regions/*/production`, `politics`, `competition` |
| 민간 분쟁·협의 | 6.0C1의 민간 분쟁 관측기는 직전 결산의 양방향 거절을 읽어 분쟁 개시·지속·완화를 판별한다. 상대국은 자체 교류 실적, 신뢰와 긴장으로 협의를 수락하거나 거부한다. | [분쟁 판단](../civsim/civic_diplomacy63.py), [관측기의 입력](../civsim/civic_observer63.py) |
| 이행 약속 | PR #18의 등록부는 양 당사자의 서명을 받아 무역·출국·입국 중 한 분야의 거절 상한을 정한다. 이듬해 기록으로 이행·위반·판단 불가를 결산한다. 이 독립 실행 경로에는 실제 통행 한도나 재정 지출을 바꿀 권한이 없다. | [약속 조건](../civsim/civic_pledges64.py), [실행 연결](../civsim/civic_followup64.py) |

## 유닛·복무 명부에서 확인할 수 있는 것

복무자는 기존 주소지 인구·노동의 부분집합이다. `service62`의 당해 왕복 근무와 `unit_game`의 지속되는 편도 위치는 별도로 결산한다. `annual-unit/1`은 사용자가 명령하면 같은 국가의 인접한 한 도로에서 가능한 인원만큼의 편도 이동을 시도한다. 성공하면 출발 지역 창고에서 인원당 식량 1, 실제 국내 도로 잔여 용량에서 인원당 1을 차감한다. 자격 있는 인원·식량·용량 중 하나라도 명령 수량에 미달하면 이동 전체를 보류한다. 연말 위치는 다음 해로 넘어가며 해제·사망·이주에 맞춰 명부를 줄인다. [실제 위치 원장](../civsim/unit_economy.py) · [이동 비용 판정](../civsim/unit_board.py)

선택형 유지비는 지정한 기존 유닛 한두 명의 실제 위치에서 식량 1과 도구 1을 한 세트로 출고한다. 부족하면 미지급을 기록하며 유닛의 위치는 유지한다. 이 영수증으로 확인할 수 있는 것은 현지 게임 재고의 할당이다. 복무 명부와 위치 원장에는 국경 횡단 명령, 무기, 교전 결과, 개인별 실제 식사나 전력의 측정값이 없다. [복무·근무 회계](../civsim/service62.py) · [유지비 영수증](../civsim/unit_upkeep.py)

## 위기 대응 결과를 읽는 방법

7.3은 기존 민간 분쟁 모듈의 실질적 거절 판정을 재사용한다. 심사소는 해당 연도의 재정·복무·집단행동 노동을 확보한 뒤, 국경 양쪽에 남은 노동을 각각 1인년씩 사용한다. 국가 재정 총계에서 토양·도로 공사 인력은 `public_labor`, 기존 복무자는 `duty_workers`, 심사 인력은 `border_appeal_workers`에서 각각 확인할 수 있다. 정치 원장에는 국경 위기 자체의 지지 가감점이 없다. 바뀐 노동·생산·섭취·세금과 대표 집단 구성을 통해 기존 정치 규칙으로 효과가 전달된다.

화물 심사 승인은 해당 도로의 실제 화물 잔량과 민간 재고·구매력 범위에서 집행한다. 주민 이주는 기존 국경 지도의 인접 경로, 출발지 이주 수요와 도착지 정주 여력을 따른다. 현재 주민 이주에는 화물 도로 용량을 차감하는 규칙이 없다. 화물·주민이 공유하는 심사 건수와 화물의 물리적 적재 용량은 별도 지표다. [실물 시장과 인구 정산](../civsim/border.py) · [연간 심사 규칙](../civsim/crisis73.py)
