# 7.2 국내 이주와 농법 습득 실험

## 같은 연초에서 이주 경로 하나를 바꾼 결과

시드 2, 국가 4의 5년차 연초를 세 번 복사했다. 같은 국가의 실제 도로 16–19에서 허용하는 주민 이동만 바꿨다. 공공·민간 운송은 세 경로에서 모두 가능했다. 7.1 원장에서 선행 이주와 후속 시험이 관측된 지역을 찾아 이 사례를 선정했으므로, 빈도를 추정하는 표본은 아래 40개 세계로 구분했다. [연초 해시, 세 경로의 매년 원장 해시와 실제 영수증](../studies/diffusion72/smoke.json)

개방 경로의 5년차 영수증 `/moves/10`에 출발지 16, 도착지 19, 거리 10, 이동 23명이 기록됐다. 연말까지 받은 지식은 남았지만 15년차까지 현지 습득은 없었다. 16년차에 기존 토양 사업에서 실제 재료와 노동을 투입하고 17년차 생산식에 적용했다. 5년차만 차단한 지역은 6년차에 처음 접촉했고, 개방 경로와 같은 16년차에 유상 시험을 마치고 습득했다. 5~16년차에 이 도로의 이주만 제한한 지역은 16년차에 똑같은 시험을 지불했지만 독자 습득에 필요한 두 번째 시험이 없었다.

5년차 세계 전체 민간 국내 배송 1,594단위 및 국경 수출 1,353단위는 세 경로에서 같았다. 17년차 개방 경로의 지역 수확은 장기 차단 경로보다 45단위 많았다. 생산 원장에서 같은 투입으로 농법 항만 되돌렸을 때의 차이는 46단위였다. 이주 경로 차단은 주민의 실제 위치와 이후의 경제에도 영향을 주므로, 인구 변화와 장기 수확 차이를 농법의 직접 효과로 전부 귀속할 수 없다.

## 장기 비교 설계와 측정 단위

기준은 PR #29의 연구 활성 경로다. 비교군은 같은 연초에 전파를 함께 활성화한다. 두 군 모두 1년차에 연구를 시작하고 2년차에 공공 경작과 조건부 긴급 구호를 활성화한다. 이후 별도 개입 없이 200년까지 계산한다. 개발 시드 0~19, 독립 검증 시드 20~39의 결과를 50·100·200년 말에 비교한다. 쌍별 차이는 항상 전파 활성 값에서 7.1 기준값을 뺀 값이다.

- 인구·농법 수준·대표 집단 규모로 가중한 정부 지지는 해당 연말의 값이다. 식량 생산·식량 필요량·미충족·민간 국내 수송량·국경 수출량·유상 시험·정권 교체·연대기 사건 수는 1년차부터 해당 연도까지 누적한다. 국내 수송과 수출은 상품 단위로 송장당 한 번 집계한다. 이주 지표는 사람 수와 영수증 수를 구분한다.
- 세계별 미충족률은 해당 세계의 누적 미충족량을 총 필요량으로 나눈 값이다. 지지는 지역 대표 집단의 규모로 가중한 점수다. 각 표본 요약에서 세계 하나에는 같은 가중치를 부여한다.
- 농법의 직접 수확 효과는 같은 해·지역의 실제 투입을 유지한 `produced.food − food_without_tech`다. 두 군 사이의 식량·교역·정치·인구 차이에는 전체 역사 경로가 함께 반영된다.
- 지역별 `domestic_receipts`는 실제 국내 유입 횟수, `qualified_receipts`는 연초에 농법을 보유한 지역에서 연말까지 미습득인 지역으로 향한 국내 유입 횟수다. 국내 이주 영수증이 없다는 관측만으로 물리적 도로가 없다고 추론할 수 없다. 국외 이주·교역·협정은 이 버전에서 농법의 전파 경로가 아니다.
- `contacts`는 지역당 첫 접촉 1회, `transfers`는 이전 접촉을 활용한 실제 습득, `independent`는 현지 유상 시험 두 번으로 독자 습득한 지역을 센다. 이미 노출된 지역에서도 두 번째 독자 시험이 먼저 완성되면 독자 습득으로 기록한다.

이 엔진은 이주민 개개인의 직업이나 교습 여부를 관찰하지 않는다. 지식의 출처는 이주 영수증과 출발지의 연초 숙련도로 판정한다. 한 번 기록한 접촉은 이 지역에 남는다. 지식을 잊거나, 이주민 수에 비례해 더 빨리 습득하거나, 국가 간에 농법을 전달하는 모형은 이번 실험의 검증 범위 밖이다. 정부의 유상 시험 선택과 경제·이주의 경로가 함께 변하기 때문에 교류량별 관찰 표는 교류 강도의 인과 추정치로 해석할 수 없다.

## 세계별 반례

시드 16에서는 59년차 지역 11이 지역 8에서 들어온 농법을 습득했다. 200년까지 네 지역이 전파로 습득했고, 이들 지역에서 실제 투입을 고정해 계산한 누적 수확 편익은 20,317단위였다. 그러나 같은 세계의 7.1 경로와 비교한 독자 습득은 6지역 감소해, 기말의 전체 습득 지역이 오히려 2곳 적었다. 전파 활성 경로의 누적 수확은 5,648단위 적고, 식량 미충족은 2,800단위 많았으며, 기말 인구는 404명 적었다. 전체 정부 교체 횟수 차이는 0회였다. [지역별 기술 사건](../studies/diffusion72/long/events.csv) · [시드별 경제·정치 대조](../studies/diffusion72/long/paired.json)

검증 표본의 200년차 인구는 17개 세계에서 늘고 3개에서 줄었다. 누적 수확은 19개에서 늘고 1개에서 줄었지만 미충족률은 4개에서 악화됐다. 시드 32에서 전파 습득은 4곳, 총 습득 지역 차이는 +3곳이었으나 기말 인구는 636명, 누적 수확은 45,950단위 적었다. 교체 횟수는 9회 감소했다. 반대로 시드 31은 기말 인구가 647명, 누적 수확이 42,512단위 늘었지만 누적 절대 미충족도 472단위 늘었다. 세계별 정치·교역·인구의 차이에는 동일 연초에서 전파 규칙을 켠 이후 변한 모든 경제·정치 경로가 포함된다.

## 실행과 보존 검산

8개 작업으로 40개 시드 × 2개 경로 × 200년인 16,000 세계년을 실제 실행했다. 시드 0과 20의 7.2 게임 저장을 새 세계에서 다시 재생해 추가 400개 연간 해시와 최종 상태·연대기를 대조했다. 이 작업을 포함한 장기 실행 시간은 1,000.640초였다. 7.1 대조군 40개의 시작·기말 상태, 200년 명령 원장, 연대기 해시가 PR #29 보존값과 일치했다. 별도로 7.1 국가별 960개 시점의 기존 열을 전부 대조해 같은 값을 확인했다. 시드 0·20 외의 7.2 경로에는 독립 두 번째 200년 재생을 수행하지 않았다. ## 재현 명령

연구와 전파를 모두 끈 경로도 별도로 40시드 × 200년, 총 8,000 세계년을 재실행했다. 앞서 공개된 기초 상태·기말 상태·저장·연대기 해시 160개와 시드별 사건 수 40개가 모두 일치했다. 7.0 시드 0·20에서는 한국어 연대기와 발췌, JSON도 보관 파일과 바이트 단위로 같았다. [두 기능을 끈 40세계의 해시](../studies/diffusion72/no-research.json) · [파일 재생 검증](../studies/diffusion72/compatibility.json) · [독립 장부 검산](../studies/diffusion72/accounts.json)

저장소 최상위에서 실행한다. 출력은 새 경로에 쓴다.

```console
python -X utf8 -m experiments.diffusion72 smoke --out replay72/smoke.json
python -X utf8 -m experiments.diffusion72 study --workers 8 --out replay72/long
python -X utf8 -m experiments.diffusion72_results replay72/long --out replay72/summary.json
python -X utf8 -m unittest tests.test_diffusion72_study
```
