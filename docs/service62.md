# 6.0B2 평시 복무의 주민·노동·식량 회계

지역 주민이 한 해 동안 공공 근무에 배정되면 주소지 명부에 남고, 그 주소지의 공사·민간 생산에서 근로자 한 명이 빠진다. 도구와 식량을 실제 지급하고 국내 도로 이용분까지 차감해야 타 지역 근무지에 출근할 수 있다. 여기서 가동 인원은 식량과 근무용 도구를 모두 받은 인원이다. 계수는 이 가상 세계에서 정책을 비교하기 위한 명시적 가정이다.

## 연초 국가 총원

각 지역의 가용 근로자 W는 `인구 // 2 − 집단행동으로 이미 철회된 근로자`다. 고정형 C는 국가 W 합계의 24‰에 해당하는 자리를 계획한다. 적응형 D는 아래 조정을 24에 더한 뒤 0~80‰로 제한한다. 모든 결정은 **올해 생산·수출·입고 전에** 내린다. 경제 입력은 연초 민간·공공 재고, 산업 활동은 직전 작물, 외교·정치 입력은 직전 관측과 연초 집권세력이다.

| 입력 | 24‰에 더하는 값 | 해석 |
|---|---:|---|
| 연초 인접쌍 중 최대 긴장 T | T // 20 | 직전 관측에서 긴장이 높으면 국가 총원 수요가 증가 |
| 인접국과 직전 위반 방향 수 V | 6 × min(4,V) | 실제 접근 의무가 이행되지 않은 방향 수 |
| 인접국별 긴장 × 자국 수입 중 그 상대국 비중 | 최댓값을 1000으로 내린 뒤 다시 40으로 나눔 | 관계 충격과 이미 관측된 교역 노출이 함께 있을 때 반영 |
| 인접쌍 평균 관계 L | −sgn(L) × min(8, ⌊abs(L)/50⌋) | 양의 관계는 수요 감소, 음의 관계는 증가. 인접쌍 0개일 때 기여 0 |
| 산업집단의 국내 도로 요구 | +산업 신호 // 80 | 당해 공공 근무에 대한 국내 수요의 대리변수 |
| 농업·소비 집단의 구호 요구 | −(농업 신호 // 100) − (소비 신호 // 100) | 생산·영양을 우선하는 집단의 기회비용 |
| 지난 식량 부족률 | −(부족 천분율 // 12) | 부족 상황에서 민간 노동 유지 |
| 연초 공공 식량 부족률 | −(부족 천분율 // 100) | 목표 재고 P//64에서 실제 창고 식량을 뺀 양이 양수일 때, 목표 대비 천분율 |
| 참고 인원에 대한 식량 기회비용 | −min(12, 비용 천분율 // 4) | 생산 투입에서 빠지는 노동의 사전 추정 |
| 연초 여당 강령 | clip(도로 가중치 − 구호 가중치, −6, 6) | 기존 5.0C 정당의 공개 가중치. 과도정부는 0 |
| 집단별 인원으로 가중한 현직 지지 S | sgn(S−500) × min(4, ⌊abs(S−500)/125⌋) | 지지 500은 중립. 관측 인원이 0명일 때 조정 0 |

P는 현재 국가 인구다. 참고 인원은 `(P // 2) × 24 // 1000`이다. 이를 직전 생산·식량에 적용한 `reference_foregone_food = 지난 작물 × 참고 인원 // (지난 식량 필요량 // 2)`을 구한다. `foregone_share_permille = min(1000, 1000 × reference_foregone_food // (지난 필요량 + 현재 민간 식량))`다. 이전 관측이나 분모가 없으면 이 비용은 0이다. 조건이 같은 두 정부의 작물 수확량만 달라져도 사전 기회비용과 적응형 총원 목표가 달라질 수 있다. 실제 등록 뒤에는 참고 인원 대신 실제 연간 근무자를 넣은 `opportunity_food_estimate`도 남긴다. 두 값은 직전 평균 작물 생산을 이용한 추정량이다. 실제 식량·광석·도구 생산량 변화는 기후·농지·재고·원료·노동 배분을 포함한 엔진의 생산 장부와 대조군에서 따로 측정한다.

국가별 목표는 `ΣW × 목표 천분율 // 1000`이다. 이를 W에 비례해 주소지별로 나누고 분수 잔여가 큰 지역부터 남은 정수 자리를 채운다. 동률은 작은 지역 ID가 먼저다. 기존 명부에서 목표·가용 인원을 넘는 주민을 해제한 뒤, 모자라는 자리에 지역별로 최대 `ceil(W/96)`명을 등록한다. 소속 기록은 `연초 명부 + 신규 등록 − 해제 = 당해 근무자`로 검산한다. `recruit=False` 포크는 새 등록만 0으로 고정하고 기존 근무자·해제·공사·생산 규칙을 적용한다.

## 근무지, 도로, 공공 비용

공공사업과 B1 국내 창고 이전을 먼저 집행한다. 그 뒤 남은 각 **주소지** 공공창고 식량 중 `min(근무자, 보유 식량)`을 그곳 주민의 식사로 따로 둔다. 이 식량은 이후 국경 원조·무역·과세·국내 운송에 사용할 수 없다. 근무지의 지역 가중치는 거주자가 있을 때 `인구 + 4 × 영토 타일 수 + 2 × max(0, 인구//4 − 연초 민간 식량)`이다. 거주자가 없으면 0이다. 국가의 실제 근무자 수를 이 가중치의 최대 잔여법으로 나눈 수가 지역별 근무지 목표다. 국경 상대의 방향이나 위치는 이 배분에 넣지 않는다.

국내 실제 도로를 거리, 양 끝 지역 ID 순서로 검토한다. 주소지에 남는 근무자와 이웃 근무지에 모자라는 자리가 동시에 있어야 파견할 수 있다. 수신지가 추가로 취급할 수 있는 인원은 `max(0, 12 × 현지 도구 − 이미 주재한 인원)`이다. 이동량에는 이 상한, 출발지에서 식사를 확보하고 아직 출근하지 않은 인원, `남은 국내 도로 용량 // 2`, `100 × 출발지 잔여 공공 식량 // (2 × 실제 거리)`를 모두 적용한다. 배정은 인접한 한 도로만 사용한다.

주민 q명이 거리 d를 왕복하면 같은 길 용량 2q와 주소지 공공 식량 운임 `ceil(2 × q × d / 100)`을 쓴다. 원장에는 실제 타일 경로, 인원, 왕복 사용량·운임, 집행 당시 여유를 기록한다. 주소지는 바뀌지 않는다. 파견된 사람은 모두 주소지에서 식사를 확보했으므로 근무지 식사 지급 인원은 `주소지 지급식 수 − 출근 인원 + 유입 인원`이다. 식사 지급 인원과 `현지 도구 × 12`의 최솟값이 가동 인원이다. 사용한 도구는 `ceil(가동 인원 / 12)`만큼 현지 공공창고에서 소모한다. 한 나라의 근무지 인원 합은 주소지 근무자 합과 같다. 가동 천분율은 `1000 × 가동 인원 합 // 근무자 합`이고, 근무자 0인 국가는 분모 0 관례에 따라 0으로 표기한다.

국내 민간 수송이 끝나면 따로 둔 개인 식량을 각 주소지의 민간 식사 계정에 한 번만 넣는다. 일반 소비식의 연간 필요량은 계속 **주민 1명당 1단위**다. 식량 10을 공공창고에서 지급한 지역의 주민이 이미 충분히 먹을 수 있었다면 총섭취량은 그대로이고 민간 식량이 남을 수 있다. `used.food`는 공공창고 차감 합계로 개인 식사 지급과 운임을 포함한다. 국가 민간·공공 재화를 합칠 때 식량 지급은 같은 주소지의 계정 간 이전이며, 실제 추가 소모는 운임이다. `used.tools`는 실제 근무지의 소모량이다.

## 연말 명부와 재현

왕복 근무는 같은 해에 끝난다. 일반 출생·사망·국내외 이주를 먼저 주민 원장에 한 번 게시한다. 주소지 근무자 S명 중 사망 처리하는 수는 `S × 실제 지역 사망 // 연초 인구`다. 남은 근무자 중 이전한 인원은 `(S − 복무 중 사망) × 실제 전출 // (연초 인구 + 출생 − 사망)`이다. 분모 0이면 해당 차감은 0이다. 두 수는 일반 인구 사건의 부분집합이며 총사망이나 이주에 재합산하지 않는다. 전출자는 기존 명부에서 빠지며 수신지에서 신규 등록하기 전에는 수신 명부에 없다. 전입·출생만으로 자동 등록되지 않는다. 개인 식별자가 없는 정수 비례 배분이므로 소규모 명부에는 반올림 잔차가 남을 수 있다.

기록은 `service.regions`의 주소지 명부·근무지·공공창고 차감, `service.moves`의 왕복, `service.countries`의 연초 관측·목표·기말 합으로 나뉜다. 새 등록을 보류하면 노동·물자·식사·정책이 연말까지 각자 달라질 수 있다. `audit_service`는 원래 주소지·명부·국가 관측·사전 창고·도로·인구 원장에서 다시 집행하고, 발표된 왕복 합과 실제 도로 잔여량도 따로 확인한다.
