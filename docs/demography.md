# 인구와 이동

연초 인구 1명은 연간 식량 1단위를 필요로 한다. 각 국가는 생산과 무역을 마치고 식량을 소비한다. 인구 모듈은 실제 섭취량으로 출생·사망을 계산한 뒤 모든 국가의 수치를 고정하고 이주를 배정한다. 출생자와 연말 이주자는 다음 해부터 새 거주지의 식량 수요와 노동 공급에 반영된다.

## 출생과 사망

연초 인구를 `P`, 소비한 식량을 `F`, 부족분을 `D = P - F`라고 한다. 아래 나눗셈은 각각 최종 단계에서 소수점 아래를 버린다.

| 계산 | 규칙 |
| --- | --- |
| 출생 | `(28 × F) // 1000` |
| 사망 | `(12 × P + 110 × D) // 1000` |
| 이동 전 인구 | `P + 출생 − 사망` |

1,000명이 식량 500단위를 섭취하면 14명이 태어나고 67명이 사망해 이동 전 인구가 947명이 된다. 출생률과 사망률은 가상 세계의 가정값이다. 연령 구조, 가구별 식량 분배, 출산 시차와 이전 연도 소수 인원은 계산에서 생략한다. 따라서 작은 집단에서는 버림으로 출생·사망이 장기간 0명일 수 있다.

## 국경 간 이동

1. 국가의 정주 가능 인구를 `영토 타일 수 × 65`명으로 잡는다. 이동 전 인구가 이를 초과한 만큼을 과밀 인구로 센다.
2. 이주 압력은 식량 부족분과 과밀 인구 중 큰 값이다. 이주 희망자는 `압력 // 12`명이며 이동 전 인구가 상한이다.
3. 올해 수요를 모두 충족한 국가의 수용 여력은 빈 정주 공간과 소비 후 남은 식량 중 작은 값이다. 남은 식량 1단위는 1명을 받을 수 있다는 신호다. 실제 식량 소비는 매년 소비 단계에서 한 번만 장부에 기록한다.
4. 송출국은 인구 대비 압력 `(1000 × 압력) // max(P, 1)` 내림차순, 수용국은 처음 계산한 수용 여력 내림차순으로 정렬한다. 동률은 국가 ID 오름차순으로 처리한다. 각 송출국에 대해 희망 인원과 수용국 잔여 여력 중 작은 값만 이동시킨다. 여력이 소진되면 다음 목적지로 넘어간다. 국가 목록의 저장 순서는 결과에 영향을 주지 않는다.

모든 경로 배정이 끝난 뒤 각 국가에 `기말 인구 = 기초 인구 + 출생 − 사망 + 유입 − 유출`을 적용한다. 세계 전체로 합치면 유입과 유출이 상쇄된다. 연간 기록의 `countries`에 인구와 식량, 압력, 수용 여력, 유입·유출이 남으며, `moves`의 출발국·도착국·인원으로 각 국가의 이동 장부를 대조할 수 있다.

현재 모든 국가 사이에 이동이 가능하다. 거리, 이동 비용, 국경 통제, 이주민의 휴대 재산은 후속 정책 모듈의 확장 지점이다. 정렬은 국가 수 N에 대해 O(N log N)이다. 각 이동이 송출 희망 인원이나 수용 여력 중 하나를 소진하므로 실제 배정은 O(N)이다.
