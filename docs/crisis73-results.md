# 7.3 국경 위기 실험

## 비교 방법

두 경로 모두 PR #30의 같은 시드에서 1년차 농법 연구·전파, 2년차 공공 경작·긴급 구호를 선택한다. 처리군은 여기에 1년차부터 자율 국경 위기 규칙을 활성화한다. 개발 시드 0~19와 독립 검증 시드 20~39의 50·100·200년말을 분리해 읽는다. 이전 기준군의 초기 상태, 연간 원장 전체의 저장 해시, 기말 상태, 연대기 해시를 대조한다. 처리군 시드 0과 20의 200년 저장을 별도로 재생한다.

먼저 개발 세계에서 실제 위기와 비용을 지불한 대응이 일어나는 시점을 찾아 같은 연초를 복제한다. 정상 집행과 해당 연도 대응 보류의 실제 원장, 정책, 생산·주민 이동·교역을 대조한다. 연초에 과거 피해가 없었던 세계와 해당하는 교류 경로가 없는 국가 쌍도 점검한다. 이 소규모 시험을 통과한 뒤에만 장기 비교를 실행한다.

거부된 교역은 기존 엔진이 해당 거래 시도에서 물리적으로 취급 가능하다고 산정한 수량 중 정책상 거부한 양이다. 출국 거부와 입국 거부는 각 이동 시도 영수증의 인원으로 나눠 센다. 같은 주민이 다른 경로에서 다시 시도할 수 있으므로 누적 거부 인원은 고유 주민 수를 나타내지 않는다. 관계·신뢰·긴장은 두 국가의 공동 상태이며 한 쌍을 한 번 센다. 인구, 지지, 숙련 지역 수는 기말의 상태다. 생산·미충족·교역·이주·실제 비용은 관측 연도까지의 누계다. 세계별 부족률은 누적 미충족 식량을 누적 필요량으로 나눈다. 세계별 정부 지지는 대표 집단 규모로 가중한 지지 점수다.

특정 국경의 관측 결과는 같은 연초 대조에서 직접 확인된 범위로 해석한다. 두 경로의 200년 결과에는 외교·경제·정치·기술이 서로 영향을 준 후속 변화가 들어 있다. 위기가 없는 세계·국가 쌍, 대응을 보류한 사례, 수확이나 주민 생활이 악화된 사례를 별도로 센다.

## 같은 연초에서 심사소를 열거나 보류한 결과

개발 시드 순서대로 1~25년 안에서 실제 비용을 지불한 심사소를 찾고, 물자나 주민이 실제로 추가 통과한 첫 사례를 채택했다. 시드 0의 1년차는 관측할 전년도 거부가 없었다. 실제로 위기 0, 심사 노동 0이었고 7.2 대조군과 국가 결산·주민 이동·국경 거래가 같았다. 3년차에는 0·2국과 2·3국에서 첫 위기가 나타났고, 2·3국의 위기는 4년차에 고조됐다.

시드 0의 6년차를 두 경로로 복사했다. 국가 2·3은 직전 5년차에 거부된 이주 시도의 인원 합계 69를 관측했다. 정상 경로에서는 두 정부가 지역 9·15를 잇는 도로에 각 1인년을 배정했다. 보류 경로에서는 그해의 심사 집행만 보류했다. 두 경로의 연초 세계, 양국의 국경 제한 기본값, 해당 연도의 위기 수준 2는 같았다. [복제한 연초, 실제 시도·송장·생산 원장](../studies/crisis73/smoke.json)

|---|---:|---:|
| 심사 노동 | 2인년 | 0 |
| 지역 9 / 15의 민간 생산 노동 | 1,003 / 414 | 1,004 / 415 |

심사소가 열린 경로에서는 세계 전체의 국외 이주가 3명 늘고 국경 교역량 차이는 0이었다. 세계 수확은 8단위 줄었고 미충족 식량은 3단위 늘었으며 기말 인구는 1명 적었다. 양국의 7년차 국경 위기는 정상 경로에서 1단계로 내려갔고, 전년 집행을 보류했던 경로에서는 2단계를 유지했다. 7년차 국가 2→3 승인 원조량은 265와 266이었고, 양방향의 수출·이주 제한율은 같았다. 원조 승인량은 실제 수혜량과 따로 읽어야 한다. 7년차 정상 경로에서는 국가 3·6과 국가 4·5가 각각 심사소에 2인년을 지급했지만, 선정된 도로에서 해당 연도 심사 시도는 두 곳 모두 0이었다. ## 40개 세계의 국경 위기와 비용

다음은 표본별 20개 세계에서 누적한 수치다. 시작은 이미 해소된 쌍에서 새 위기가 나타나도 다시 한 건으로 센다. 유지된 해에는 전환 사건을 추가하지 않는다. 1·2단계로 마친 한 국가 쌍의 1년을 활동 1쌍·년으로 집계했다. 화물·주민은 해당 심사 시도에서 일반 규칙보다 더 통과한 실물 수량·인원이다. [표본별 합계와 사례](../studies/crisis73/summary.json)

검증 세계의 50년차에는 위기 8건이 진행 중이었다. 200년차까지 해소한 382건의 평균 활동 기간은 3.34년, 최장은 23년이었다. 개발 세계에서는 평균 3.49년, 최장 26년이었다. 검증 표본의 활동 1,274쌍·년 가운데 695쌍·년은 노동을 지급했고, 218쌍·년은 새 거부가 없었고, 361쌍·년은 양측 선택이 일치하지 않았다. 실제 집행은 없으면서 지방의 생산 노동만 차감하는 경로는 없다.

40개 세계 모두 한 쌍 이상에서 위기가 발생했다. 국가 쌍으로 나누면 개발 표본의 실제 인접 245쌍 중 67쌍, 검증 표본의 252쌍 중 87쌍에서 200년 동안 위기가 한 번도 없었다. 위기가 있었지만 심사소를 한 번도 공동 집행하지 않은 쌍은 각각 19·24쌍이었다. 심사소가 열린 적이 있어도 200년 누계 실제 추가 통과가 0인 쌍도 각각 97·99쌍이었다. [국가 쌍별 수치](../studies/crisis73/long/pairs.csv)

검증 시드 23은 29개 심사소에 총 58인년을 썼지만, 심사 시도에서 추가 통과한 화물·주민이 모두 0이었다. 200년 누적 수확은 기준보다 44,342단위, 기말 인구는 759명 적었다. 국외 이주는 105명 늘었다. 시드 32에서는 누적 수확이 75,509단위, 기말 인구가 585명 증가했지만 절대 미충족 식량은 4,674단위 늘었다. 검증 20세계 중 기말 인구가 증가한 세계는 9개, 감소한 세계는 11개였다. 개발에서는 각각 11·9개였다. 두 표본 모두에서 주민 생활이나 외교가 일관되게 개선되지는 않았다.

## 실행과 원자료

두 경로의 16,000 세계년과 7.3 시드 0·20의 독립 저장 재생 400년을 실행했다. 8개 작업으로 장기 비교·재생·출력까지 756.563초가 걸렸다. 40개 7.2 기준 세계는 기존 시드별 200개 연간 해시가 포함된 저장과 시작·기말 상태·연대기 해시가 일치했다. 독립 집계에서는 국가 시점 1,920개, 양국 시점 6,720개, 연대기에 대응하는 상태 전환 2,554건과 실제 원장 해시를 대조했다. 다른 38개 7.3 세계에 대해서는 두 번째 200년 재생을 수행하지 않았다. 국가별 위기 기준이나 심사 처리 한도의 민감도도 이 실험의 측정 범위 밖이다. [실제 실행 기록](../studies/crisis73/long/execution.json) · [집계 검산](../studies/crisis73/reconciliation.json)

저장소 루트에서 실행한다. 새 출력 경로를 사용한다. 장기 비교 명령은 자체적으로 작은 실제 시험을 먼저 실행한다.

```console
python -X utf8 -m experiments.crisis73 smoke --out replay73/smoke.json
python -X utf8 -m experiments.crisis73_examples --out replay73/followup.json
python -X utf8 -m experiments.crisis73 study --workers 8 --out replay73/long
python -X utf8 -m experiments.crisis73_results replay73/long --out replay73/summary.json
python -X utf8 -m experiments.check_crisis73 replay73/long --out replay73/reconciliation.json
python -X utf8 -m experiments.replay_crisis73_legacy --out replay73/legacy.json
python -X utf8 -m unittest discover -v
```
