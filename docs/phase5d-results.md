‘기존 승인 내용 변경’은 정부가 집단행동을 접수하기 직전의 사업·대상·수량·예산과 실제로 승인한 안을 대조한 횟수다. ‘최종 재량사업 집행’은 해당 정부가 최종 사업의 재화를 실제로 보내거나 수납한 횟수다. 기존 안을 그대로 집행한 경우도 포함한다. 접수에 사용한 행정 슬롯과 실물 감면은 별도 장부에서 집계했다.

납부 거부를 선택한 81개 집단·연도 중 실제 미납이 한 재화라도 1단위 이상인 경우는 12건, 법정 감면이 양수인 경우는 19건이었다. 동일 사례가 두 조건을 함께 만족할 수 있다. 거부 선언 시점에는 이후 생산·거래가 정할 실제 납부 대상이나 정수 반올림 결과가 확정되지 않는다.

사전 통치 지지는 연초 결정에 사용한 직전 지역·집단 지수다. 대상은 실제 사업 변경의 지정 집단 또는 법정 감면 대상으로 표시된 집단이며, 별도 수혜 플래그는 실현된 배급·공사·감면·요구에 맞는 조치에 따라 정해진다. 차년말 비교는 200년차 행동을 빼고 같은 지역·집단의 차기 지수를 연결했다. 후속 경로와 구성이 달라질 수 있으므로 이 표는 정부 대응 후의 관측 변화다.

## 같은 연초의 개발 표본 개입

원장에 자연 발생한 각 행동에서 한 사례를 정했다. 청원은 실제 사업 변경·감면 대상으로 지정된 사례를 우선하고, 항의·파업은 차감 노동이 가장 큰 사례, 납부 거부는 미납액(식량×8+광석×4+도구×12)이 가장 큰 사례를 선택했다. 이후 동률은 참여 인원, 이른 연도, 낮은 시드·지역 순으로 풀었다. 따라서 이 사례들은 모집단 평균 효과를 추정하는 표본이 아니다.

**청원 · 시드 0 · 44년차.** 국가 0의 지역 0에서 소비자 집단 369명이 참여했다. 같은 연초에 이 집단의 행동만 억제해 참여를 0명으로 바꾸고, 다른 모든 집단의 연초 행동·참여·노동 차감이 같음을 확인했다. 두 경로에서 정부는 모두 승인할 사업을 변경했다.

두 경로 모두 구호를 승인했다. 식량 지출 한도는 각각 68단위, 실제 주민 배급량은 각각 59단위였다. 청원 접수에 쓴 해당 국가의 행정 슬롯은 실제 경로 18개, 억제 경로 6개였다. 청원은 이 사례에서 행정 비용을 늘렸고 배급량과 당해 말 집단 지지는 같았다.

**납부 거부 · 시드 9 · 65년차.** 국가 0의 지역 1에서 농업 집단 115명이 참여했다. 같은 연초에 이 집단의 행동만 억제해 참여를 0명으로 바꾸고, 다른 모든 집단의 연초 행동·참여·노동 차감이 같음을 확인했다. 실제 경로의 정부는 현물세 감면을 승인했다. 억제 경로의 정부는 기존 계획을 유지했다.

두 정부가 승인한 토양사업의 예산 한도는 광석 2단위, 도구 2단위, 노동 4인년으로 같았다. 식량세 영수증에서 이 집단의 실납은 억제 경로 75단위, 실제 경로 48단위였다. 감소한 27단위는 법정 감면 18단위와 감면 후 실제 미납 9단위로 나뉜다. 실제 경로에서 해당 집단의 연말 지지는 5점 높았고, 두 경로의 국가 식량 부족량은 같았다.

**항의 · 시드 18 · 78년차.** 국가 5의 지역 20에서 광공업 집단 1,226명이 참여했다. 같은 연초에 이 집단의 행동만 억제해 참여를 0명으로 바꾸고, 다른 모든 집단의 연초 행동·참여·노동 차감이 같음을 확인했다. 두 경로에서 정부는 모두 기존 계획을 유지했다.

실제 경로에서 노동 77인년이 추가로 빠져 지역 광석 생산이 30단위 감소했다. 두 경로에서 지역 식량·도구 생산, 국가의 미섭취 식량, 해당 집단의 연말 지지는 같았다.

**파업 · 시드 18 · 79년차.** 국가 5의 지역 20에서 광공업 집단 1,221명이 참여했다. 같은 연초에 이 집단의 행동만 억제해 참여를 0명으로 바꾸고, 다른 모든 집단의 연초 행동·참여·노동 차감이 같음을 확인했다. 두 경로에서 정부는 모두 기존 계획을 유지했다.

실제 경로에서 노동 407인년이 추가로 빠져 지역 광석 생산이 155단위 감소했다. 두 경로에서 지역 식량·도구 생산, 국가의 미섭취 식량, 해당 집단의 연말 지지는 같았다.

두 경로를 만든 뒤 원래 세계의 연초 SHA-256이 보존되는지, 실제 경로 원장이 정상 연간 실행과 동일한지 검사했다. 단년 차이는 해당 행동으로 바뀐 정부의 대응·배송까지 포함한다. [개입 원장](../examples/phase5d/study/forks-dev.json)

## 재현과 범위

5.0C의 C군 고정 세율·대표 선거·내각에서 시작한다. 기초 재고·현금·인구·내각·행동 기억의 해시를 짝지었고 기능 해제 원장의 50·100·200년 접두 SHA-256을 기존 5.0C C군과 대조했다. 각 관찰 시점에서 세계 인구·현금, 세금 부과→감면→미납→실납, 민간과 정부 각각의 재화 균형, 실제 노동 차감과 집단별 차감 합계를 검사했다. 행동 회차는 같은 집단이 같은 요구로 같은 행동을 이어가는 기간이다. 수용·휴식·무행동은 참여인년 0이다. 배급 격차는 지역 필요 식량으로 가중한 지역별 충족률과 자국 평균 충족률의 절대차다.

```console
python -B -m experiments.phase5d --sample dev --out examples/phase5d/study/dev --workers 8
python -B -m experiments.phase5d --sample holdout --out examples/phase5d/study/holdout --workers 8
python -B -m experiments.phase5d --sample dev --out ../../work/phase5d-replay-dev --workers 8 --verify-against examples/phase5d/study/dev
python -B -m experiments.phase5d --sample holdout --out ../../work/phase5d-replay-holdout --workers 8 --verify-against examples/phase5d/study/holdout
python -B -m experiments.collective_forks5d --study examples/phase5d/study/dev --out examples/phase5d/study/forks-dev.json
```

규칙 동결 커밋은 `614f0e9`다. 개발 시드 0~19와 검증 시드 20~39의 두 군을 각각 200년간 실행해 16,000세계연도와 240개 관찰점을 얻었다. 기능 해제 원장의 보관 해시 120개가 일치했다. 첫 실행 경과시간은 개발 301.514초, 검증 285.327초였다. 표본당 8개 프로세스를 사용했고 두 표본과 다른 검증이 동시에 실행됐다.

새 프로세스에서 전체 16,000세계연도를 다시 실행했다. 두 표본의 240개 관찰점과 전체 18개 과학 결과 파일이 바이트 단위로 일치했다. 재실행에는 개발 416.571초, 검증 399.350초가 걸렸다. [개발 실행 검증](../examples/phase5d/study/replay-dev.json) · [독립 검증 실행 기록](../examples/phase5d/study/replay-holdout.json)

각 표본의 `events.csv.gz`에 발생한 모든 행동 집단·연도의 조건, 참여, 회차 길이, 대응, 사후 지표, 재화별 기준 부과·감면·미납·실납이 있다. `actions.csv`는 무발생 조합까지 포함한 유형별 집계다. `responses.csv`는 정부 대응, `regions.csv`·`countries.csv`는 지역·국가별 결과, `runs.csv`·`paired.csv`는 세계별 수준과 짝 차이다. 지수는 모형의 관측 규칙에서 계산한 값이며, 참여자 개인을 추적하거나 현실의 실제 행동 확률을 추정하지 않는다.
