# 1차 엔진 실행 및 검증

기준 실행은 Windows, CPython 3.12.14, 시드 42, 48×32 타일, 8개국, 50년이다. 기후 계수, 소모량, 단가와 인구는 정수로 계산한다. 아래 수치는 저장된 기록에서 집계했다.

## 한 해의 기록을 읽는 예

10년차 세린은 주민 13,228명, 식량 1,305단위, 현금 3으로 시작했다. 식량 11,749단위를 수확했고 이 해에는 무역이 체결되지 않았다. 총 13,054단위를 먹어 174단위가 부족했다. 모든 주민을 먹인 국가들과 함께 시장에 참여했어도 세린의 구매력에는 한계가 있었다. 세린의 식량 호가는 9였고 가장 싼 공급 호가는 3이어서 두 호가의 평균 단가 6에도 한 단위를 살 수 없었다.

출생은 `28 × 13,054 // 1000 = 365`명이고, 사망은 `(12 × 13,228 + 110 × 174) // 1000 = 177`명이다. 벨로라로 14명이 이주해 연말 인구는 `13,228 + 365 − 177 − 14 = 13,402`명이다. 자료는 연간 원장 10번째 줄의 국가 ID 2, 시장 기록, 이동 경로에서 확인할 수 있다. [연간 원장](../examples/seed-42/years.jsonl)

## 실제 실행한 검증

- `python -m unittest discover -v`로 37개 테스트를 실행해 모두 통과했다. Windows 로컬 실행 시간은 2.595초였다. [실행 로그](test-results.txt)
- 지도 분할·자원 집계·기후 범위, 세 부문의 손계산 생산량·투입 상한, 현금 한도에서의 부분 체결 및 재화·현금 보존, 식량 부족·부패, 출생·사망·동시 이주, 0명 국가를 검사했다.
- 4개 시드에서 50년간 독립적으로 재화별 세계 잔액과 국가 인구를 대조했다. 잔액·이동·사건·계산 입력을 바꾼 경우 검사가 실패하는지도 확인했다. 연도 중복·건너뜀, 실패한 연도의 상태 되돌림, 중단된 저장, 기존 실행 보호도 검사했다.
- 별도 프로세스에서 기본 실행을 재생성했다. 두 실행에서 초기 지도, 메타데이터, 50줄 연간 원장과 400행 분석 CSV가 각각 바이트 단위로 일치했다.
- 샘플 원장의 SHA-256은 `9814b3c0409a7fcf4f65cc07a09f2d2b562ad1251857dcc6d8504b85272c7f11`이다. `python -m civsim verify examples/seed-42`로 확인할 수 있다.

**미측정 범위**는 1,000년 이상 장기 실행, 수백 개국의 최대 메모리와 다중 프로세스 처리량, 실제 역사·경제 통계에 대한 타당성이다. GitHub Actions에서도 운영체제별 테스트와 샘플 재생을 실행하도록 구성했다. 원격 실행의 최신 결과는 워크플로에서 확인할 수 있다. [CI 실행 기록](https://github.com/mrgameskr-lang/civilization/actions/workflows/tests.yml)

## 성능과 병목

같은 시드로 구성별 5회 실행한 경과 시간의 중앙값이다. 초기화는 지도·국가 생성, 연간 계산은 원장 검사를 포함한 50회 전이, 전체는 새 초기화부터 모든 JSON 파일 저장까지다. 세 열은 별도 측정치이며, 출력 용량은 기본 파일 세 개의 합이다.

| 지도 | 국가 | 초기화 | 연간 계산 50회 | 저장 포함 전체 | 출력 크기 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 48×32 | 8 | 3.312 ms | 17.425 ms | 47.192 ms | 829,696 B |
| 96×64 | 8 | 13.149 ms | 17.813 ms | 71.525 ms | 1,180,554 B |
| 48×32 | 32 | 3.677 ms | 61.959 ms | 123.834 ms | 2,915,963 B |
| 96×64 | 32 | 13.389 ms | 64.669 ms | 152.911 ms | 3,345,782 B |

8개국에서 타일 수를 4배로 늘리면 초기화 시간이 약 4배가 된다. 국가별로 집계된 자원을 쓰므로 이 비교에서 연간 계산 시간 차이는 작았다. 같은 48×32 지도의 국가 수를 4배로 늘리면 연간 계산 시간이 약 3.6배가 됐다. 기본 구성 프로파일에서 자체 시간 상위는 스냅샷을 사전으로 복사하는 `_asdict_inner`와 JSON 인코더였다. 시장은 재화별로 매수·매도국을 정렬하고, 이주는 송출·수용국을 정렬한다. 양자별 운송 조건이 추가되면 이 비용은 다시 측정해야 한다. [측정 원본 및 cProfile 상위 함수](../examples/benchmark.json) · [측정 코드](../benchmarks/benchmark.py)
