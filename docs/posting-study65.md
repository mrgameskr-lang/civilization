# 주소지와 행정상 소속의 비교

40개 기존 세계의 200년 기록을 개발 시드 0~19, 검증 시드 20~39로 나누고 같은 경로의 50·100·200년을 관측한다. A는 PR 18이 사용한 경제이고 A_fixed는 기존 6.0B2 C의 고정 정원 경로다. B는 A_fixed의 연간 결산이 끝난 뒤 실제 왕복 송장을 근거로 명부에 행정상 소속을 기재한다. 세 조건이 참조하는 실제 경제는 두 개다.

평가 대상은 명부상 타지역 소속 인원과 이월·기재·감원·사망·전출의 정합성이다. 근무지까지 실제로 이동하거나 장기 체류한 사람을 식별하는 자료는 생성하지 않는다. 신규 배치 실패·추가 이동비·새 도로 사용량은 미측정이다. 식사·도구·기존 왕복비는 원래 경제의 실물 결산에 귀속한다. 같은 결산에서 명부 기재 하나만 보류하여 소속과 주소지 합이 어떻게 달라지는지 확인한다. 실제 지출과 식사는 두 명부에 동일하다.

## 200년의 결과

40개 세계의 200년 말 등록자 56,820명 중 주소지와 다른 지역이 서류상 소속으로 남은 사람은 10,866명(19.12%)이다. 모든 세계에서 새 기재와 송장 인원 일부 또는 전부의 미기재가 모두 관측됐다. 40세계 누적 송장 인원 35,520명회 중 17,588명회를 타지역 소속으로 기재했다. 한 사람이 여러 해의 송장에 나타날 수 있다. [세계별 집계와 검산](../examples/phase6c1-m1/outcomes.json)

고정 정원 경제에서 200년까지 기존 식사 지급은 개발 255,347식·검증 303,191식, 도구 사용은 27,613개·32,110개, 기존 왕복에 든 식량은 7,024식·8,078식이었다. 이 물량은 A_fixed와 B에서 같다. 실제 독립 경제인 A와 비교하면 A_fixed의 200년 말 인구 합은 개발에서 4,275명, 검증에서 7,649명 적었다. 200년 누적 필요 식량과 부족량도 작았다. 이 차이는 두 기존 경제 경로의 비교이고, 명부 도입의 당해 식사·인구 차이는 같은 결산을 공유하므로 두 표본 모두 0이다. ## 명부와 원장의 연결

각 행에는 주민의 주소지와 행정 소속 지역을 따로 둔다. 직전 기말 잔액에서 감원 인원을 비례 차감한 뒤 새 등록자는 주소지의 소속으로 들어간다. 확정된 왕복 송장을 순서대로 읽고, 아직 주소지 소속인 등록자만 그 송장의 상대 지역 소속으로 기재할 수 있다. 주소지가 이미 같은 인원을 여러 송장에 중복 기재하지 않는다. 이후 주민 원장에서 이미 집계한 사망·전출 인원 중 등록자에 해당하는 몫을 각 소속에서 차감한다. 이들은 지역 인구 변동에 다시 더하거나 빼지 않는다. [명부 갱신식](../civsim/postings65.py)

각 주소지·소속 칸에서 `기초 − 감원 + 신규 등록 + 소속을 받은 기재 − 다른 소속으로 넘긴 기재 = 연중 명부`, `연중 명부 − 등록자 사망 − 등록자 전출 = 기말`을 검산한다. 주소지별 모든 소속 인원의 합은 실제 고정 정원 경제의 기말 등록자 수와 일치해야 한다. 한 해의 말에 남은 명부는 다음 해 초에도 그대로 나타나야 한다.

개발 시드 0의 2년차 첫 송장에서는 주소지 19의 등록자 9명 중 1명을 16번 지역 소속으로 기재했다. 그 한 건만 보류한 복사본에서는 9명 모두 19번 소속이다. 두 장부에서 주민의 주소지별 합과 이미 지급한 식사·도구·왕복 운임은 같다. 3년차 주소지 5에는 새 소속 기재가 없었지만 전년의 4번 지역 소속 3명이 이월됐다. 검증 시드 20의 6년차에는 주소지 6에서 4번 지역을 참조하는 옛 송장에 1명이 있었으나 주소지 소속자로 남은 인원이 0이어서 새 기재가 생기지 않았다. 송장 대상자 1명과 명부상 신규 기재 0명은 별개의 관측이다. [개발 시드 0의 두 명부](../examples/phase6c1-m1/dev/seed-00/cases.json) · [검증 시드 20의 두 명부](../examples/phase6c1-m1/holdout/seed-20/cases.json)

## 파일 단위

| 표본 안의 파일 | 포함된 값 |
|---|---|
| `runs.csv`, `regions.csv` | 시드·조건·50/100/200년별 세계와 지역 누계. `closing_*`, `private_*`, `public_*`은 기말 잔액이다. 명부가 없는 A·A_fixed의 명부 열은 공란이다. |
| `seed-NN/economic-regions.csv.gz` | 지역·연도별 A와 A_fixed의 실제 주민 수, 가계 현금, 세 재화 재고·산출, 등록·감원과 기존 식사·도구·왕복비. B의 경제 행은 A_fixed의 같은 행을 참조한다. |
| `seed-NN/affiliations.jsonl.gz` | B의 200개 연간 명부. `home`은 주소지, `post`는 서류상 소속이다. 송장에 연결한 명부 인원과 감원·사망·전출을 별도로 보존한다. |
| `seed-NN/cases.json` | 최초 기재 보류의 두 장부, 이미 적힌 소속을 이월한 사례, 기존 왕복 송장 인원을 모두 새로 기재할 수 없었던 사례. |
| `execution.json` | 입력 자료 해시, 과학 파일별 해시, 실제 계산한 경제·명부 연도 수와 작업자 수·소요시간. |

시점까지 누적한 `carried_other_affiliation`의 단위는 인년이다. 감원 후 그해 기초 다른 지역 소속으로 남은 인원을 센다. 신규 소속 등록은 `ledger_assignments`, 확정된 원래 송장 중 그해 기재에 쓰이지 않은 인원은 `unentered_invoice_people`다. `closing_other_affiliation_home`은 연말에 주소지 밖의 소속으로 기재된 수를 주소지에, `closing_other_affiliation_office`는 동일한 수를 소속지에 배분한다. 두 값을 합산하면 같은 사람을 이중으로 세게 된다.

## 검산과 재실행

본 실행에서 경제 16,000세계연도(2경로×40시드×200년), 행정 명부 8,000세계연도(1경로×40시드×200년)를 계산했다. A 120개와 A_fixed 120개의 초기 상태와 누적 경제 원장 해시가 기존 자료와 일치했다. A는 PR 18이 보관한 D 경제의 검증값을, A_fixed는 같은 버전이 참조한 6.0B2 C를 사용한다. B의 경제는 A_fixed와 해시가 같다. B의 명부 체크포인트 120개는 실제 압축을 푼 연도별 명부 줄바꿈까지 포함한 SHA-256으로 각각 다시 검산했다. [검산에 사용한 과거 경제 해시](../examples/phase6c1-followup/compatibility.json)

별도 판독기는 매 지역의 실제 민간 기초 재고에서 생산·사용·세금·식사·운송비·순수출입·재분배를 거쳐 기말 재고를 계산했다. 공공창고는 지역 간 구호 이체가 나라 안에서 상쇄되는 국가 단위로 세금·공사·원조·구호·손실·기존 식사와 도구·왕복비를 대조했다. 32지역×3재화×16,000세계연도인 1,536,000개 민간 잔액과 8국×3재화×16,000세계연도인 384,000개 공공 잔액이 모두 일치했다. 판독 결과도 새 프로세스에서 다시 계산해 요약 파일 전체 바이트를 대조했다. [판독 코드](../experiments/posting_summary65.py) · [요약 반복 확인서](../examples/phase6c1-m1/replay-analysis.json)

개발·검증에 각각 5개 작업자를 배정해 동시에 실행했다. Python 3.12.14에서 개발 원본은 450.838초, 검증 원본은 455.771초가 걸렸다. 확인서를 제외한 표와 압축 원자료는 개발 13,691,900바이트, 검증 13,671,472바이트다. 독립 반복은 사전에 고른 개발 시드 0과 검증 시드 20에서만 200년 전부를 재생했다. 각 단일 작업자에서 81.954초·82.829초가 걸렸다. 두 시드의 경제 체크포인트 12개와 명부 체크포인트 6개, 세계·지역 결과 행 전체, 시드별 과학 파일 3개씩 6개의 전체 바이트가 원본과 같았다. 지역별 원본 CSV 및 사례 파일의 재생 바이트 비교는 시드 0·20에서 실시했다. B 정상 진입점의 40개 시드 별도 해시 대조는 [호환성과 반복 검산](phase6c1-m1.md)에 구분했다. [개발 실행](../examples/phase6c1-m1/dev/execution.json) · [검증 실행](../examples/phase6c1-m1/holdout/execution.json) · [시드 0 반복](../examples/phase6c1-m1/replay-dev.json) · [시드 20 반복](../examples/phase6c1-m1/replay-holdout.json)

원본 실험은 저장소 루트에서 아래 명령으로 실행했다. 이미 게시된 디렉터리는 보호하므로 새 본실험에서는 다른 출력 경로를 사용한다.

```text
python -B -m experiments.posting_study65 --sample dev --workers 5 --out examples/phase6c1-m1/dev
python -B -m experiments.posting_study65 --sample holdout --workers 5 --out examples/phase6c1-m1/holdout
```

표본 반복은 다음과 같이 새 디렉터리에서 실행한다. 각 반복의 `execution.json`을 발표한 `replay-dev.json`과 `replay-holdout.json`에 보존했다.

```text
python -B -m experiments.posting_study65 --sample dev --workers 1 --out fresh-seed0 --verify-sample-against examples/phase6c1-m1/dev
python -B -m experiments.posting_study65 --sample holdout --workers 1 --out fresh-seed20 --verify-sample-against examples/phase6c1-m1/holdout
python -B -m experiments.posting_summary65 --study examples/phase6c1-m1 --out fresh-outcomes.json
python -B -m experiments.posting_summary65 --study examples/phase6c1-m1 --verify-against examples/phase6c1-m1/outcomes.json --out fresh-replay.json
```
