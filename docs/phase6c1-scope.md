# 6.0C1 경제 원장과 민간 외교 관측의 검증 범위

기준은 PR #16의 `5d686a52987f5eb3e7329584ee787690d7db149d`다. 경제 측 기준군 A는 이 커밋의 평시 자율 정책 D다. 기존 고정 정책 C와 자율 정책 D의 차이는 과거 확정 원장의 회계 분석으로 다룬다. 신규 선택지는 민간 분쟁 관측(`observe`)과 양자 협의(`consult`)다. 전시 정책 B·C·D, 위협에 따른 주둔 선택, 전쟁 준비 시간, 전투 시스템에 연결하는 병력 데이터 구조는 이 PR의 실험 범위 밖이다.

개발 시드 0~19와 검증 시드 20~39를 별도 집계하며 200년 경로의 50·100·200년 시점에서 결산한다. 모두 6.0B2에서 이미 공개된 표본이다. 협의 규칙과 집계 조건은 시드 0의 개발 점검 후 두 표본의 공식 실행 전에 고정했다. 검증 표본을 새로 추출하지는 않았다.

- **주민·창고 결산**은 주소지 인구, 식량 필요·섭취·부족, 정부 비축과 민간 재고, 나라별 현금을 확인한다. 명부의 공공 식사 지급은 주민 식사로 한 번만 들어간다. 단체에 지급하지 않은 식사가 곧 개인의 결식을 뜻하지 않는다.
- **갈등 원장**은 두 나라가 직전 연말에 확정한 거래·이동 거절과 협정 위반을 읽는다. 분쟁이 처음 관측된 해, 계속된 해, 거절이 사라져 완화된 해를 구분한다. 양측의 증거가 없는 해에는 결측으로 기록한다. 협의 성립은 요청국의 요구와 상대국의 수락을 모두 필요로 한다.
- **단년 개입**은 같은 연초 상태와 같은 직전 경제 원장을 두고 협의 허용과 보류를 비교한다. 협의 기록을 경제 모델에 역입력하지 않으므로 무역·인구·신뢰·재정의 정책효과를 여기서 추정할 수 없다.
- **재현성**은 기존 경제 원장 전체의 누적 SHA-256, 실제 지도·민간/창고/국가 수지·도로 잔량에 대한 독립 감사, 저장된 자료와 독립 실행의 대응을 각각 검사한다. 새 자료는 `examples/phase6c1/` 아래에만 게시한다.
