# 5.0C 선거 기제의 고정 경로 진단

## 사전 지정한 비교

시드 0~19와 20~39를 각각 재생한다. 모든 시드에서 5.0C C군의 고정세·200년·32지역 경제 경로를 원래 엔진으로 실행하고 누적 연도 원장의 SHA-256을 기존 연구 파일과 대조한다. 각 모의 정부가 접하는 인구·재고·영양·집단 선호·정부 지지 지수·재정 후보는 같은 해 원래 경로의 값이다. 대안 내각은 자신의 선거 결과를 다음 해로 이어간다. 새 정책에 따른 생산·소비·지지의 되먹임은 이 조건부 비교에서 제외한다.

다음 일곱 조건은 새 진단 수치를 보기 전에 정했다. 한 번에 한 조건만 바꾼다.

| 조건 | 설정 |
|---|---|
| 기준 | 4년 임기, 21석, 5.0C 강령 및 집권 성과 조정 |
| 짧은 임기 / 긴 임기 | 각각 2년 / 8년. 최초 선거는 각각 3년 / 9년차 |
| 소의회 / 대의회 | 각각 5석 / 101석. 양쪽 모두 기존 최대잔여법과 최다 의석 내각 규칙 사용 |
| 비축·도로 강령 교환 | 상호부조 정파의 비축 계수 4와 도로 계수 1을 교환한다. 그 외 계수와 행의 합 12는 동일하며 변경 강령을 선거와 재정 결정에 모두 적용한다. |
| 성과 조정 제거 | 집단 선호×강령의 일치도만 비교한다. 여당에 붙던 `(지지−500)//4`는 투표와 내각 지지 기반에서 모두 0 |

연간 지지는 모든 국가·연도의 실제 참여점을 분모로, 선거 득표는 각 조건에서 투표가 열린 해의 참여점을 분모로 집계한다. 가용 참여점은 직전 관측 인구×1000, 실제 참여점은 직종 인원×해당 집단의 최고 강도(최소 강도 25)이다. 부족·비축 같은 신호와 집권 성과 조정의 기여는 실제 선거에서 같은 유권자가 여당 가감점을 받지 않았을 때의 표와 대조한다. 이때 다른 정파와의 동점에 따라 정수 표가 분할될 수 있다.

진정한 정권교체는 과도정부의 첫 설치를 제외한다. 현재·퇴임 내각이 같은 기초 재정 후보에서 내리는 행동·대상을 비교한다. 두 결과가 같으면 유보만 가능한 경우, 채택된 행동·대상이 두 정파의 정치점수 단독 최고점에 모두 포함되는 경우, 나머지로 분해한다. 마지막 경우 적어도 한 정파에서 다른 후보의 더 높은 정치점수를 경제점수가 상쇄한다. 비교 단위는 국가·연도·행동·대상이며, 같은 행동의 다른 지역도 변경에 포함한다.

무참여 회차는 관측 인구 0과 인구가 있어도 최고 강도가 25 미만인 경우를 나눈다. 이전 정부의 정파와 공식 의석이 보존되는지 확인한다. 새로 배분된 의석 0과 기존 의석 잔류는 서로 다른 장부 항목이다.

## 상호부조에 모인 참여점

검증 표본의 C군에서 선거일 상호부조 비중은 **83.10%**였다. 같은 집단의 투표 강도와 참여점을 유지하고 여당 성과 조정만 끄면 **94.88%**다. 상호부조 강령은 구호에 5, 비축에 4, 다른 세 행동에는 각각 1을 부여한다. 전체 참여점의 94.75%는 구호 또는 비축을 최고 요구로 표시한 집단에서 나왔다. 집권 성과 조정으로 상호부조에 22,609,367점이 더해지고 1,282,542,476점이 빠져 순 1,259,933,109점 낮아졌다. 개발 표본에서도 같은 조정 전 94.99%, 조정 후 82.98%였다. | 정책 종류 변경 | 156 | 163 |
| 정책 종류 유지, 대상만 변경 | 135 | 112 |

검증에서 정책이나 대상이 달라진 비율은 275/1,873(14.68%)였다. 유지된 1,598건 중 1,577건에서는 선택이 경제점수로도 최고였다. 공동 정치 최고에는 여러 후보의 동점과 정치점수 0의 동점이 포함된다. 개별 사례의 모든 허용 후보와 두 정부의 점수는 각 시드 JSON의 `examples`에 있다.

- 시드 20, 17년, 국가 3에서는 유보만 남았다. 구호 후보 4개 모두 조달 가능한 기존 부족이 없었고 도로 4개는 물자·노동 조건이 막혔다. 토양의 양의 경제점수 후보는 토양 조건을 충족하지 못했고, 조건을 충족한 토양 후보 3개 모두 −64였다. 비축도 경제점수가 양수인 후보가 없었다.
- 시드 20, 9년, 국가 0에서는 같은 7개 후보를 보면서 두 정파 모두 지역 0–1 도로를 택했다. 후임 상호부조의 구호 점수는 경제 80 + 정치 207 = 287, 도로는 경제 752 + 정치 6 = 758이었다. 높은 정책 선호가 큰 경제점수 차이를 뒤집지 못했다.
- 같은 시드와 해의 국가 2는 절제에서 상호부조로 교체되며 지역 8의 토양(경제 344 + 정치 32)에서 구호(경제 64 + 정치 953)로 바뀌었다. 73년차의 같은 국가는 농지관리에서 상호부조로 바뀌며 토양 사업지를 지역 8에서 9로 바꿨다.

## 무참여 선거

검증의 105/7,840회(1.34%)와 개발의 93/7,840회(1.19%)는 모두 관측 인구가 있었다. 검증 무참여 회차 전체의 가용점은 1,694,246,000점이었다. 이 105회 모두 인원이 있는 모든 집단에서 최고 강도가 25 미만이었고, 34회는 국가 전체 최댓값이 24였다. 선출 정부 105개가 그대로 집권했고 새로 배분된 의석은 0, 그 전부터 보유한 공식 의석은 국가·회차 합계 2,205석이었다. 개발의 해당 의석 합계는 1,953석이다. 양 표본 모두 무참여 때문에 과도정부에 남은 사례는 0이었다. 시드 20, 53년, 국가 0은 관측 주민 8,481명, 최고 신호 24여서 상호부조 정부와 기존 의석 배분(5, 2, 14, 0)을 유지했다.

## 재실행

검증 계산은 원천 연도를 모두 다시 시뮬레이션하고 저장 결과를 바이트 단위로 대조한다. 각 표본의 모든 5.0C C군 원장 해시 20개와 일치해야 한다. 의회 구성과 정치·경제 순위는 진단 모듈이 직접 계산해 실제 5.0C 국가 원장과도 대조한다. [재현 코드](../experiments/election_diagnostics5d.py)

```console
python -m experiments.election_diagnostics5d --sample dev --out examples/phase5d/elections/dev.json --workers 3 --verify
python -m experiments.election_diagnostics5d --sample holdout --out examples/phase5d/elections/holdout.json --workers 3 --verify
```

첫 실행과 독립 반복에서 개발 JSON SHA-256은 `45c5c90f6f0790cc148f89b21f9cff8b331af26c99d4cd7d2b91c0ebce5a6485`, 검증은 `dffa648dea73789ed3928899f5c1f29b4c22f0b644b65c6a941fcdb75904b148`로 각각 일치했다. 반복 실행 시간은 3개 프로세스 기준 개발 208.81초, 검증 189.63초였다. 두 표본은 병렬로 실행했다.

## 부록 실물 경제까지 다시 실행한 비교

앞서 지정한 일곱 제도를 개발 시드 0~3에서 각각 200년 실행한다. 한 정부가 내린 결정이 그해 공사·조세·구호·운송·생산·소비·인구를 거쳐 다음 해 정치 신호와 선거에 반영된다. 세율은 C군 고정세를 사용한다. 각 경로의 시작 상태와 50·100·200년차 누적 원장 해시를 남긴다. 기준 경로에는 보관된 C군 해시를 적용한다. 별도 프로세스 안에서 실험 조건을 적용하고 해당 조건의 계산과 연간 감사에 같은 임기·의석수를 전달한다. 실험 밖에서 실행하는 5.0C의 프로그램 파일과 기본 설정은 그대로다.
