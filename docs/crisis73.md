# 7.3 민간 국경 위기와 공동 통행 심사

시드 0에서 국가 2와 3 사이의 이주 시도 중 5년차에 69명이 통행을 거절당했다. 6년차에 두 나라가 지역 9와 15를 잇는 도로에서 공동 심사를 선택했다. 지역 15에서 9로 이주할 수 있었던 11명 중 일반 심사로 통과한 인원은 8명, 공동 심사를 통해 추가로 통과한 인원은 3명이었다. [직전 해의 거절과 두 경로의 송장](../studies/crisis73/smoke.json)

## 전년도 결산에서 올해의 위기까지

실제 용량이 양수인 국경도로가 있는 두 나라를 한 쌍으로 다룬다. 판단 근거는 직전 연도에 결산된 양방향 통상·이주 거절, 협정 위반, 긴장이다. 이 값은 6.0 외교 원장의 `opening.last`에 이월되어 있고 6.3 민간 분쟁 모형의 피해 판정식을 공유한다. 이전 상태가 없는 쌍은 0단계에서 시작한다. [기존 체계 조사](crisis73-existing.md) · [연간 흐름도](https://www.tldraw.com/f/0bUzL9_Y5-sq8tpY7HMM6?d=s9yXXrVTr3uLKUYiCWlL2b)

| 직전 연도에 관측된 사실 | 당해 단계 |
|---|---|
| 협정 위반이 있거나, 한 방향에서 거래 또는 이주 거절이 실제 기회의 ¼ 이상이며 1단위 이상이거나, 거절이 있으면서 긴장이 1,000점 중 125점 이상 | 한 단계 상승, 최대 2 |
| 양방향에 거절과 위반이 없음 | 한 단계 하락, 최소 0 |
| 그 밖의 소규모 거절 | 기존 단계 유지 |

0→1은 시작, 1→2는 고조, 2→1은 완화, 1→0은 해소다. 예년과 같은 상태가 계속되면 연대기에 전환 사건을 싣지 않는다. 국경 통행 거절은 시도별 거절 물량·인원의 합이다. 거절된 물자나 주민이 다른 경로에서 다시 시도하면 두 시도에 모두 포함될 수 있다. 실제 통과한 양은 결제된 송장과 주민 이동 원장에서 따로 센다.

## 양국의 선택과 집행 비용

1. 각 쌍에서 거리가 가장 짧은 양수 용량의 국경도로를 심사 후보지로 쓴다. 동률이면 용량이 큰 도로, 다음으로 지역 ID 순이다. 양국은 `0 < 위기 단계`, 국내 식량 부족 지표 250‰ 미만, 자국 쪽 도로 끝에 남은 노동 1인년 이상일 때 심사를 고려한다. 기존 공공사업·집단행동·복무의 노동 수요를 먼저 반영한다.
2. 국가별 우선순위 점수는 **양방향 거래 거절량 + 양방향 이주 거절 인원 + 자국으로 들어오는 거래의 거절량 + 자국에서 나가는 이주의 출입국 거절 인원 + 4 × 상대 방향 협정 위반 건수**다. 이는 게임 내 우선순위 가중치다. 금액이나 후생 추정값으로 사용하지 않는다. 각국은 점수가 양수인 후보에서 단계, 점수, 낮은 상대국 ID 순으로 한 곳을 고른다.
3. 같은 쌍을 양국이 선택하면 도로 양 끝에서 노동 1인년씩을 민간 생산에서 차감한다. 두 사람이 담당하는 연간 재심 한도는 합계 4다. 기존 거래 순서에 따라 화물 1단위 또는 이주 1명이 처리량 1을 쓴다. 처리할 송장이 없어도 배정한 노동은 그해에 돌아오지 않는다.
4. 재심은 지정된 도로에서 **실제로 통행 가능했지만 일반 정책 한도에 걸린 수량**에만 적용한다. 거래는 원래 재고, 현금 결제, 운임과 잔여 화물 용량을 사용한다. 이주는 기존의 실제 출발 인원과 수령지 정주 여력을 사용한다. 기존 이주 모형은 사람을 화물 도로 용량에서 차감하지 않는다. 별도 화폐 예산이나 창고 출고를 만들어 심사비로 계상하지 않는다.

양국 관계는 현행 외교 결산이 실제 거래·이주·거절을 읽어 갱신한다. 선거와 지지는 기존 주민·재정·정치 원장에서 이어진다. 심사소를 열었다는 이유로 지지나 신뢰 점수를 가산하는 규칙은 없다. 지속 중인 2단계에서도 새 피해와 자원 여력이 다르면 정부의 선택이 달라질 수 있다.

## 플레이와 검증

```console
python -m civsim.annual_game new --seed 0 --out runs/crisis73/start.json
python -m civsim.annual_game step runs/crisis73/start.json --research --diffusion --crisis --out runs/crisis73/year1.json
python -m civsim.annual_game step runs/crisis73/year1.json --reserve-policy emergency --out runs/crisis73/year2.json
python -m civsim.annual_game show examples/crisis73/seed0-year12.json
python -m civsim chronicle examples/crisis73/seed0-year12.json --format json
```

`--crisis`는 단독으로도 선택할 수 있고 한 번 켠 뒤에는 다음 해로 이어진다. `--hold-response`는 활성 경로에서 해당 연도의 심사 집행만 보류하는 대조용 명령이다. 판단 근거, 위기 단계와 양국의 선택은 함께 기록된다. `annual-game/7` 저장은 명령·연간 해시·연말 상태를 대조해 재생한다. 원장에서 확인할 위치는 다음과 같다.

| 확인하려는 사실 | 연간 장부 |
|---|---|
| 연초 단계와 이전 해의 거절 근거 | `crisis/pairs`, `diplomacy/pairs/*/opening/last` |
| 국별 점수·선택·차감한 노동 | `crisis/pairs/*/choices`, `workers`, `regions/*/production` |
| 재심 처리 전후의 수량 | `diplomacy/physical/trade_attempts`, `migration_attempts`의 `ordinary_passed`, `appeal_granted` |
| 실제 거래·이주 및 외교 결산 | `border_market/trades`, `moves`, `diplomacy/pairs/*/closing` |
