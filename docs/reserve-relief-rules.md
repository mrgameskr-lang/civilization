# 비축 목표와 비상 구호의 회계 규칙

PR #25의 `c2d2ea38292e62ca2e4bb3c20ad92ca868e4b1cc`를 기준으로 한다. 8개국 32개 지역의 도로·창고·인구와 기존 식량 생산 함수를 그대로 쓴다.

| 실험군 | 공공 경작의 입고 목표 | 추가적인 주민 구호 |
|---|---|---|
| A | 기존 민간 중심 경작 | 기존 승인 구호 |
| C | 지역 연초 인구 `P // 8` | 기존 승인 구호 |
| D7 | `floor(P × 7 / 365)` | 기존 승인 구호 |
| D14 | `floor(P × 14 / 365)` | 기존 승인 구호 |
| E | C와 같은 `P // 8` | 기존 구호 정산 후 남은 자원으로 조건부 집행 |

시드마다 1년차 결산까지 같은 상태를 복사한다. 2년차에 각 경로의 규칙을 활성화한다. 이전 실험과 같은 표시·이동 명령, 유닛 유지비 우선순위, 기후를 사용한다. 기존 주민 구호 우선 경로 B는 PR #25 호환성 확인용으로 별도 재생한다. D7·D14는 **수확 시 목표**다. 운송·지출·부패가 이어지므로 연말에 해당 일수가 보장되지는 않는다.

각 지역 농업의 총수확이 `F(a)`일 때 공공 경작은 최대 `a//8`명의 실제 경작 노동과 그들이 점유한 토지 슬롯을 사용한다. 공공 몫 `F(a)−F(a−k)`가 창고와 목표 여유 안에 드는 인원만 배정한다. 민간 몫은 `F(a−k)`이다. D는 목표만 바꿨고, E도 공공 경작에서 추가 작물을 만들지 않는다. 모든 실험의 식량세 보호선은 `P + P//8`이다. [기존 작물 수식](food-reserve-rules.md)

## E의 집행 순서

1. 수확 귀속, 국경 거래·원조, 세금 입고, 기존 창고 지출, 기존 승인 구호를 해당 경로의 순서대로 정산한다. 이미 가구에 지급하기 위해 출고한 배식량도 지역별로 읽는다.
2. 추가 신청량은 `max(0, 연초 주민 − 현재 민간 식량 − 이미 지급되어 식사 전 들어올 배식)`이다. 기존 구호 입고분은 현재 민간 식량에 들어 있다. 당해 이후 민간 배송, 최종 식사, 사망, 다음 해 수확은 의사결정에 쓰지 않는다.
3. 접수는 국가 안에서 신청량/인구가 큰 지역부터 처리한다. 동률이면 절대 신청량, 그다음 지역 ID 순이다. 지역별 수령 한도는 인구가 있으면 `max(1,P//16)`, 없으면 0이다. 여기서 이미 받은 기존 구호를 차감한다. 승인은 신청량, 지역 잔여 한도, 기존 국가 구호 처리량 중 남은 양의 최솟값이다. 헛승인으로 후순위 지역의 처리량이 사라지지 않도록 실제 수령 때만 처리량을 쓴다.
4. 현지 창고에서 먼저 지급한다. 부족하면 같은 나라에서 실제 도로로 연결되고 그때 양의 잔여 용량이 있는 경로를 기존 물류 규칙으로 탐색한다. 현지 출고의 운임은 0이다. 다른 지역에서 `q`를 발송하면 각 구간에 `q`의 도로 용량, `ceil(q × 구간 거리 / 100)`의 식량 운임이 든다. 출발 창고에서 화물과 운임을 함께 차감한다. 송장을 나누면 운임도 송장별·구간별로 올린다.
5. 추가 구호는 실물 창고 잔액과 기존 처리 인력을 쓰는 상시 승인 규칙이다. 기존 재량 사업 예산과 별도의 현금 재원은 없다. 추가 구호의 신청·승인·발송·수령·운임은 `emergency_relief`에서 따로 기록한다. 그 후 남은 도로와 민간 재고로 민간 배송을 실행하고, 가구의 실제 섭취·미충족·부패·인구 변동을 정산한다.

추가 지급되지 않은 신청량은 지역 취급 한도, 국가 처리량, 재고, 가용 도로, 운임 순서의 회계 분해로 남긴다. 여러 제약이 동시에 작용할 때는 그 단계에서 실제로 배제된 수량만 센다. 정책이 없던 경로에는 사후적으로 가상 승인을 넣지 않는다. 원래 구호의 계획량은 연초의 후보·요청, 승인량은 실제 선택된 사업, 출고·입고는 송장의 수량이다. 한 지역이 최종적으로 부족했더라도 다른 지역의 재고가 그곳에 도달할 수 있었는지는 별도 증거가 필요하다.

## 대조 지표

- 지역이 최종적으로 먹지 못한 양을 구호 직전의 현지 비축 유무 및 같은 나라 타지역 비축과 연결한다. ‘현지 잔고와 동시 발생’에는 이미 다른 용도가 예정된 경우, 행정 한도에 도달한 경우도 포함될 수 있다. 최종 섭취량은 출고량과 별도로 기록한다.
- 세계·국가의 비축 일수는 `365 × 기말 공공 식량 / 그해 주민 필요량`이다. 151–200년에 매년 1일분을 유지했는지, 추가로 151년 기초 대비 200년 기말 순인출이 없었는지 측정한다. 세계 합계가 1일분이라고 모든 지역에 배송 가능하다는 의미는 아니다.
- 누적 부족률은 `Σ미충족 / Σ필요`다. 누적 절대 필요량·섭취·미충족을 함께 기록한다. 지역 간 운송과 내부 구호의 화물을 세계 순생산으로 더하지 않는다.
- 도로 열은 지역에 접한 구간의 용량 합계다. 동일 국내 도로가 양끝에서 두 번 보이므로 국가·세계 용량 합계를 구할 때 한 번만 센다. 식량 운임과 주민 소비, 창고 부패도 각각 별도 열이다.

일반 플레이에서는 `python -m civsim.annual_game step <기존저장> --reserve-policy 7-day --out <새저장>`을 쓴다. `14-day`와 `emergency`도 선택할 수 있고, 활성화한 정책은 이후 저장과 재생에서 이월된다. 기존 게임의 `--public-farm`은 C를 그대로 재현한다. [프로젝트 식량 흐름도](https://www.tldraw.com/f/0bUzL9_Y5-sq8tpY7HMM6)
