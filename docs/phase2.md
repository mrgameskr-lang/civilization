# 2차 경제·인구 실험

농지 수용 한도를 넘긴 인력을 광업·제조업으로 옮기면 20개 시드 모두에서 산업 생산이 증가했다. 기본 결제 순서에서 평균 최종 인구는 79.2명 증가했으나 시드별 변화의 중앙값은 0명이었다. 현금 집중은 소폭 심해졌다. 기본 규칙은 1.0으로 유지하고, 재배치와 결제 순서 변경은 2.0에서 선택할 수 있게 했다.

## 실험 설계와 단위

- 48×32 타일, 8개국, 시드 0~19, 50년. 각 시드에서 노동 규칙 2종과 재화 결제 순서 6종을 교차해 **240회** 실행했다. 시드별 12개 초기 세계의 전체 타일·국가 상태 해시가 일치하는지 실행기가 검사했다. 1회 실험 행렬은 12,000개 연도, 96,000개 국가·연도다.
- 기준은 `idle`과 식량 → 광석 → 도구다. 호가, 비축 목표, 인구·이주·토양·기후·초기 자금 규칙은 모든 조합에서 동일하다. 기준과 같은 노동 규칙에서 결제 순서만 바꾼 대조군도 포함했다.
- 생산과 거래는 식량·광석·도구의 **물량을 각각** 합산한다. 식량 한 단위는 1인 연간 배급량이다. 한 체결의 거래대금은 수량×단가로 한 번 센다. 현금 고갈은 **연말 잔액 0**, 고갈에 가까운 상태는 **연말 잔액 ≤ 해당 국가 초기 현금의 1%**로 정의했다. 후자에 전자가 포함된다.
- 집중도는 세계 안에서 측정한다. 최대 보유국 점유율은 최대 현금÷세계 총현금, HHI는 8개국 점유율 제곱의 합이다. 균등하면 HHI는 0.125, 전액이 한 나라에 있으면 1이다. 결과표는 독립적인 20개 세계에 동일 가중치를 준 평균이다.
- 두 설정의 효과는 **같은 시드 안에서 B−A**를 계산한다. 각 결제 순서의 재배치 효과 6종과, 두 노동 정책에서 기본 순서 대비 순서 효과 5종씩을 비교했다. 17개 지표 × 16개 비교를 제공한다. 이상값은 시드별 차이에서 선형 보간 사분위수의 1.5 IQR 울타리 밖에 있는 경우다. 동률이 많아 IQR이 0인 지표에서는 작은 차이도 표시된다. 이 표시는 통계적 유의성을 뜻하지 않는다. [비교표](../examples/phase2-seeds-0-19/comparisons.csv) · [사분위수 API](https://docs.python.org/3/library/statistics.html#statistics.quantiles)

## 버전과 노동 수지

농업 최초 배정이 A, 토지 수용 한도가 C라면 농업 가동 인원은 `min(A,C)`, 초과분은 `max(A−C,0)`이다. 1.0에서는 기존 원장의 `labor.farm − active_farmers`로 유휴를 복원한다. 2.0 재배치에서는 초과분의 절반을 내림해 광업에, 나머지를 제조업에 보낸다. 연중 부문 전환 비용은 0으로 가정했다. 광맥이 고갈되거나 가공할 광석이 부족하면 인원이 추가되어도 생산은 원료 한도에 걸린다.

2.0 원장은 최초 배정, 농업 가동 한도, 배정 전후 유휴, 부문별 이동과 최종 인원을 저장한다. 검사기는 연초 인구·식량·토지에서 배정을 독립적으로 재구성한다. 결제 순서는 연초의 가용 자금을 어떤 재화에 먼저 쓸지, 수출대금이 어느 재화의 구매 전에 들어올지를 바꾼다. 2.0 매니페스트에 노동 규칙과 결제 순서가 저장된다. 1.0은 기존 매니페스트·지도·원장 형식을 유지한다. [규칙 코드](../civsim/rules.py) · [생산·거래 코드](../civsim/economy.py)

## 국가별 현금이 모이는 경로

1.0의 최대 현금 보유국 평균 점유율은 초기 **17.73%**, 5년차 **22.22%**, 10년차 **27.41%**, 25년차 **43.15%**, 50년차 **84.18%**였다. 50년차에는 20개 세계 중 18개에서 한 국가가 현금의 절반 이상을 보유했다. 이때 최대 보유국 20곳 모두가 식량의 누적 순수출대금을 얻었다. 시드 18의 미레아는 초기 40,515에 식량 순수출대금 263,604를 더해 304,119를 보유했다. 세계 현금의 99.997%다.

160개 국가·시드 조합 가운데 25개가 적어도 한 번 연말 잔액 0에 도달했다. 처음 0에 도달한 시점의 중앙값은 21년차였다. 이 25곳 모두에서 식량 순매입이 최대 현금 유출 항목이었고, 23곳은 순식량대금만으로 초기 현금 전액의 감소를 설명할 수 있었다. 처음 0이 된 후 관측이 끝난 50년차까지 초기 현금의 1%를 넘게 회복한 곳은 없었다. 전체 8,000개 국가·연도에서 685건이 정확히 0이었고 3,067건이 1% 이하였다. 각 국가의 초기·기말·최저 현금, 첫 0의 연도, 재화별 순유입액을 이용해 직접 대조할 수 있다. ## 결제 순서의 효과

같은 노동 규칙의 식량 → 광석 → 도구 결과를 기준으로 한 **평균 차이**다. 각 열의 두 수치는 유휴 유지 / 재배치 순이다. 식량을 먼저 두고 나머지 순서만 교환했을 때는 관측 지표가 같았다. 가장 큰 평균 차이도 개별 세계에서 나타나는 차이를 숨길 수 있다.

| 결제 순서 | 최종 인구 Δ | 누적 식량 부족 Δ | 총거래대금 Δ |
| --- | ---: | ---: | ---: |
| 식량 → 광석 → 도구 | 0 / 0 | 0 / 0 | 0 / 0 |
| 식량 → 도구 → 광석 | 0 / 0 | 0 / 0 | 0 / 0 |
| 광석 → 식량 → 도구 | −0.10 / −0.25 | +3.90 / −1.60 | −2.10 / +1.65 |
| 광석 → 도구 → 식량 | −0.10 / +0.20 | +10.50 / +1.05 | −43.20 / −4.70 |
| 도구 → 식량 → 광석 | 0 / +0.30 | +6.70 / +2.30 | −40.75 / −6.35 |
| 도구 → 광석 → 식량 | −0.10 / +0.20 | +10.50 / +1.05 | −43.20 / −4.70 |

- **먼저 사느라 구매력이 줄어든 경우.** 유휴 유지·시드 6·8년차 아르덴은 결제 전 현금 1,067, 식량 10,744단위, 인구 12,516명이었다. 기본 순서에서는 단가 6에 식량 177단위를 샀다. 광석 → 도구 → 식량에서는 도구에 200을 먼저 쓰고 식량 144단위만 샀다. 해당 연도 부족량이 1,595에서 1,628로 늘었다.
- **먼저 팔아서 구매력이 생긴 경우.** 유휴 유지·시드 17·29년차 벨로라는 현금 3으로 시작했다. 기본 순서에서는 식량 결제 후에 광석 8단위를 팔아 72를 받았다. 광석 → 도구 → 식량에서는 같은 72를 먼저 받아 식량 12단위를 단가 6에 샀다. 해당 연도 부족량은 1,233에서 1,221로 줄었다.

## 이상값과 반례

- **시드 13**은 최종 인구 및 식량 부족의 짝지은 차이에서 IQR 이상값이었다. 재배치로 로벤이 16~18년차 도구 구매 46개를 절약해 19년차 기초 현금이 322 늘었다. 그해 식량 수입이 347에서 400으로 늘고 부족은 152에서 99로 줄었다. 이후 50년 전체에서 세계 식량 부족은 2,525단위 감소했고 최종 인구는 438명 늘었다. [시드 13의 2.0 원장](../examples/phase2-seeds-0-19/seed13-reallocated/years.jsonl)
- **시드 0**은 인구 개선의 반례였다. 아르덴은 17~21년차 광석 추가 구매로 현금 306을 더 썼다. 22년차 같은 단가에서 식량 수입이 1,699에서 1,648로 줄었다. 50년 전체의 부족량은 86단위 늘고 최종 인구는 1명 줄었다.
- **시드 9**는 광석·도구 생산 증가 폭이 작은 쪽의 이상값이었다. 광석 37,569, 도구 18,785단위를 추가 생산했는데도 50년 식량 생산과 거래량, 최종 인구는 같았다. **시드 7**에서는 인구가 246명 늘면서도 최대 현금 보유국 점유율이 1.788%p 상승했고 연말 잔액 0인 국가·연도가 14건 늘었다.

## 재현 및 검증

CPython 3.12.14에서 기존 37개와 새로 추가한 23개 자동 테스트가 모두 통과했다(60개, 4.457초). 재화·현금·인구 보존과 1.0 원장 재생에 더해, 농업 초과 인원의 홀수 분할, 원료 부족, 유휴 인력 장부 변조, 현금 제약 아래 결제 순서 효과, 2.0 설정·재현성, 실험 결과 중복 저장 방지를 검사했다. [실행 로그](phase2-tests.txt)

아래 명령은 저장소 루트에서 실행했다. `python`은 로컬의 CPython 3.12.14 실행 파일을 나타낸다. 이미 포함된 결과를 재현할 때는 `--out`에 새 경로를 지정한다.


## 해석 범위와 다음 실험

산업 생산량을 늘리는 목적에는 재배치가 일관되게 작동했다. 인구 증가와 현금 분산은 시드별 방향이 달랐다. 재배치된 인력의 숙련·이전 비용, 신용·소득 재분배 또는 동시 결제를 추가하는 실험, 50년 이후의 자원 고갈과 실제 역사 자료에 대한 보정은 수행하지 않았다. 다음 비교에서는 초기 자금만 바꿔 구매력 효과를 분리하고, 광맥 잔량과 구매 수요를 고려해 재배치 인원을 정하는 규칙을 같은 초기 세계에서 시험할 수 있다.
