# 3.1 투자 정책 실험 결과

사전에 지정한 주 비교는 200년차 `combined-multi`와 3.0 실물 투자(`control`)다. 홀드아웃 20개 시드에서 평균 기말 인구 차이는 **-6,934.6명**, 평균 누적 부족량 차이는 **-110,450.0단위**, 합산 인년 기준 부족률 차이는 **+0.189%p**였다. 아래 모든 차이의 방향은 새 정책에서 비교 대상을 뺀 값이다. [사전 실험 계획](phase31-protocol.md)

## 실험 설계

48×32 지도·8개국·동일한 노동 재배치와 무역 순서를 유지하고, 체감효과 사용 여부, 규모 보정 사용 여부, 단일·다중 건설을 완전 교차했다. fixed-single 조합은 기존 3.0 원장을 그대로 생성한다. 규모 보정은 설비 수혜 범위와 운영비를 함께 조정한다. 다중 건설은 동일한 연초 자재와 노동 한도에서 한 국가가 최대 3건을 선택한다. [정책 수식과 회계 정의](investment31-rules.md)

개발 시드 0~19에서 최초 20개 세계를, 정책 규칙을 고정한 후 홀드아웃 시드 20~39에서 새 20개 세계를 실행했다. 한 시드의 여덟 실험군은 동일한 초기 타일·국가 원장 해시를 갖는다. 각 200년 경로의 앞 50·100·150년을 중간 관측 시점으로 사용했다. 50년에서 200년까지 네 관측은 동일한 경로에 속한다.

## 악화 사례와 해석 범위

개발에서는 기말 인구 감소 19/20개, 누적 부족량 증가 0/20개, 인년당 부족률 증가 18/20개였다. 인구 차이가 가장 낮은 시드는 0(-12,410명)였다. 부족률 차이가 가장 높은 시드는 0(+0.436%p)였고, 같은 시드의 누적 부족량은 -62,458단위, 인구는 -12,410명이었다.

홀드아웃에서는 기말 인구 감소 20/20개, 누적 부족량 증가 0/20개, 인년당 부족률 증가 20/20개였다. 인구 차이가 가장 낮은 시드는 32(-10,953명)였다. 부족률 차이가 가장 높은 시드는 32(+0.355%p)였고, 같은 시드의 누적 부족량은 -60,599단위, 인구는 -10,953명이었다.

가격·수명·설비 수혜 범위는 가정값이다. 직접 한계편익은 한 해의 생산 투입을 고정한 값이다. 200년간 누적된 인구·무역·환경 변화는 실험군 전체 경로에서 관찰했다. 표본에는 역사적으로 보정한 실측 국가가 없고, 같은 시드의 네 기간을 독립 표본으로 사용할 수 없다.

## 실행 기록

각 표본은 160개 경로와 32,000개 세계 연도 전이로 이루어진다. 200년차까지 동일 현금 및 잔여 매장량 대사를 통과했다. 실행기는 개발·홀드아웃 시드의 중복과 두 실행의 모델 소스 해시 차이를 검사한다. 원장의 SHA-256은 연간 표준 JSON 바이트를 스트리밍해 계산한다. 운영체제별 소스 개행 차이는 소스 파일 해시에 영향을 줄 수 있다.

개발 45.712초, 홀드아웃 49.983초. Python 3.12.14, 작업 프로세스 6개. 모델 SHA-256 `4d6c30d623925ca3a70b31d8b0bc9f5dc85e1909557dcb236079dd9f404e9479`. [개발 execution.json](../examples/phase31/investment/dev/execution.json) · [홀드아웃 execution.json](../examples/phase31/investment/holdout/execution.json)
