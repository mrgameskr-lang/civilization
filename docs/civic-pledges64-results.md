# 민간 외교 약속과 다음 서명

## 사전 비교

이 연구는 PR 17에서 이미 공개한 개발 0~19와 검증 20~39의 같은 세계를 읽는다. 경제 활동과 분쟁·협의 결정은 과거 원장에 고정한다. 각 시드의 28개 국가쌍을 200년 추적하고 50·100·200년을 측정한다. 이미 공개된 검증 표본에서 나온 결과의 재현성을 확인하는 설계다.

각각의 관측·협의 원장에 약속 기능을 끄거나 켠다. 관측만 한 경로에서는 기존 협의조차 성립하지 않았으므로 양국의 서명이 필요한 약속을 맺을 수 없는지 확인한다. 협의 경로에서는 수락과 후속 약속의 양국 서명을 따로 센다. 약속을 한 해의 합의, 이듬해 도착한 이행 기록, 증거 부족으로 판단할 수 없는 이행, 200년 시점에 기한이 지나지 않은 약속을 구분한다.

협의·약속 허용 경로를 각 연초에 복사한다. 복사본에도 동일한 경제 증거와 당해 협의 결정, 이전 약속의 이행 평가가 들어간다. 후속 서명 판단에서 이행 이력의 가중치만 가려 어느 국가가 결정을 바꾸는지 비교한다. 세계 전체 집계와 함께 개별 국가, 두 서명이 모두 필요한 국가쌍, 약속의 종류와 판단 사유를 기록한다.

### 서명과 결산 시점

양측이 협의를 수락하면 응답국의 교역 거절, 출국 거절, 입국 거절 중 직전 연도에 거절된 기회의 비율이 가장 높았던 항목을 제안한다. 양국이 서명하면 각자 이 항목에서 직접 담당하는 거절량을 직전 연도 수준 이내로 유지하겠다고 약속한다. 교역·출국에는 출발국을, 입국에는 도착국을 책임 당사자로 기록한다. 조건을 선택할 때는 비율을 사용하며, 이행 여부는 실제 시도 기회가 있었는지 확인한 뒤 거절 건수의 상한으로 판단한다. [약속 선택·평가 규칙](../civsim/civic_pledges64.py)

예를 들어 3년차 서명은 2년차의 확정된 수치를 상한으로 쓴다. 3년차 실적은 4년차 연초에 평가한다. 당사자의 해당 경로에 시도가 없었거나 방향별 기록이 비어 있으면 그 당사자의 결과는 미확정이다. 한쪽이라도 위반하면 약속 전체는 위반으로, 한쪽이 미확정이고 확인된 위반은 없으면 전체도 미확정으로 집계한다. `pending`은 체크포인트에 막 서명해 아직 평가해 볼 연도가 도래하지 않은 약속이다.

서명자는 자신이 실제로 통과시킨 기회와 상대국의 거절 여부에 각각 1점을 더하고, 자신이 통과시킨 기회보다 거절 기회가 많으면 1점을 뺀다. 같은 상대국·같은 약속 종류의 최근 이행 결과가 이번 또는 직전 연초에 확인됐다면 준수에 1점을 더하고 위반에 1점을 뺀다. 양국 점수가 각각 양수여야 약속이 생긴다. 경제 증거만 보면 둘 다 서명할 상황에서 이력 때문에 한쪽이 멈추면 `defer`를 기록한다. 개별 서명 의사, 양측 서명 완료, 다음 연도의 실제 이행 평가를 별도 원장에 남긴다.

## 같은 연초에서 이력만 가린 결과

같은 연초의 양국 증거와 약속 이행 평가를 유지한 채 후속 서명 판단에서 과거 이력 점수만 가렸다. 224,000쌍·년 중 실제 이력을 반영해 공동서명 여부가 바뀐 경우는 344건이었다. 이력이 서명을 가능하게 한 경우가 17건, 원래 양측 서명이 가능했던 제안을 보류하게 한 경우가 327건이었다. 국가별 서명 의사는 378번 바뀌었고, 국가별 서명 점수는 1,740번 달라졌다. 이미 두 나라 모두 서명할 상황이라면 한쪽 점수만 올라도 공동서명 결과는 같다. [개발 개입 누계](../examples/phase6c1-followup/pledges/dev/forks.csv) · [검증 개입 누계](../examples/phase6c1-followup/pledges/holdout/forks.csv)

| 표본·시점 | 이력이 공동 서명을 가능하게 함 | 이력 때문에 공동 서명을 보류 | 국가별 서명 의사 변경 |
|---|---:|---:|---:|
| 개발 50년 | 9 | 165 | 189 |
| 개발 100년 | 9 | 168 | 194 |
| 개발 200년 | 9 | 171 | 197 |
| 검증 50년 | 8 | 147 | 172 |
| 검증 100년 | 8 | 152 | 177 |
| 검증 200년 | 8 | 156 | 181 |

- **위반 후 보류.** 개발 시드 0의 6년차에 1국은 전년 교역 거절 상한 41에 대해 실제 61을 기록했다. 4국은 해당 방향 시도 0회로 미확정이었다. 다음 서명에서 4국의 경제 점수는 1이었다. 1국의 확인된 위반을 반영하면 0이 되어 4국이 서명하지 않았고, 이력을 가린 같은 연초에는 두 나라 모두 서명했다. [두 판단의 원자료](../examples/phase6c1-followup/pledges/dev/same-opening-cases.json)
- **상대의 위반이 있어도 새 합의가 성립한 사례.** 개발 시드 4의 34년차, 2국은 상한 0에 실제 거절 0·기회 35로 준수했다. 3국은 상한 54에 거절 89·기회 177로 위반했다. 2국의 새 점수는 3국의 위반으로 2에서 1로 내려갔지만 여전히 서명했다. 3국의 새 점수는 2국의 준수로 0에서 1이 되어 서명했고, 이력을 가리면 3국의 서명이 없어 공동 합의가 성립하지 않았다. [해당 시드의 서명·판정 원자료](../examples/phase6c1-followup/pledges/dev/party-events.csv.gz)
- **점수만 달라진 사례.** 검증 시드 20의 6년차에 1국과 3국이 받은 상대 이력 가중치는 각각 −1과 +1이었다. 최종 점수 1·2와 이력을 가린 점수 2·1은 모두 양수였다. 과거 이행 정보를 확인했어도 이 합의의 성립 여부는 달라지지 않았다. [검증 사례 원장](../examples/phase6c1-followup/pledges/holdout/same-opening-cases.json)

새 합의가 통행이나 교역을 바꾸는 되먹임은 연결하지 않았다. 네 경로가 참조한 경제 전체 원장 해시, 기말 인구·현금, 식량 필요·섭취·부족과 이전 연도까지 관측한 국경 교역액·이주량은 120개 시드별 경제 체크포인트에서 일치했다. 이 비교로 확인할 수 있는 효과는 고정된 경제 증거에 대한 후속 서명 변화까지다. 17 대 327을 장기간 이력을 완전히 제거한 세계의 누적 차이로 읽으면 안 된다. 각각은 실제 약속 이력에서 출발해 그 연초 한 번만 판단을 바꾼 결과다.

## 원자료와 재현

| 파일 | 내용 |
|---|---|
| `annual.jsonl.gz` | 각 시드·연도에 `observe`, `observe_on`, `consult`, `consult_on` 4줄이 있으며 줄당 28개 국가쌍을 담는다. off 줄은 PR 17과 바이트가 같다. on 줄에는 기초·기말 이력, 양국의 서명 계산, 약속 조건, 만기 판정이 있다. |
| `runs.csv`, `pairs.csv`, `countries.csv` | 누적 세계·국가쌍·개별국 지표와 미도래 약속. 세계 표의 `register_sha256`은 시드·경로별로 그 연도까지 누적한 원장의 해시다. |
| `party-events.csv.gz` | 서명 기회의 국가별 경제 점수·이력 점수·실제 서명과 이력을 가린 서명, 만기 때의 책임 방향·상한·실제 거절·기회 수·판정 사유를 구분한다. |
| `forks.csv`, `same-opening-cases.json` | 같은 연초의 개별·공동 서명 변화 누계와 시드별 사례. 각 종류에서 원장 순서상 처음 관측된 사례의 양쪽 기록을 보존한다. |
| `source.json`, `execution.json` | PR 17 경제 및 협의 원장의 참조 해시, 실험의 과학 파일 해시와 실행시간. |

두 표본을 단일 Python 프로세스 하나씩 병행 실행했다. Python 3.12.14에서 개발은 47.340초, 검증은 47.178초가 걸렸다. 두 조건과 기존 관측·협의 두 경로를 합쳐 원본 32,000세계연도, 독립 반복 32,000세계연도다. 새 프로세스와 새 디렉터리에서 동일하게 계산한 결과 개발은 32.778초, 검증은 32.648초였고 체크포인트 480개와 표본별 8개씩 총 16개 과학 파일 전체가 바이트 단위로 일치했다. 확인서를 제외한 파일 용량은 개발 12,701,289바이트, 검증 12,731,301바이트였다. 같은 입력으로 참여국 수를 늘리면 국가쌍 수와 원장 직렬화·압축량이 함께 늘어난다. [개발 원본](../examples/phase6c1-followup/pledges/dev/execution.json) · [개발 반복](../examples/phase6c1-followup/pledges/replay-dev.json) · [검증 원본](../examples/phase6c1-followup/pledges/holdout/execution.json) · [검증 반복](../examples/phase6c1-followup/pledges/replay-holdout.json)

별도 판독 과정에서 완전 원장으로 체크포인트 해시 480개를 재계산했다. 320개 시드·국가의 200년 기말 집계는 국가별 서명·판정 행과 다시 대조했다. 원본은 다음 두 명령으로 생성했다. 출력을 이미 내려받은 저장소에서는 기존 경로를 보호하므로 재실행 시 새 경로를 지정한다. [개발 원자료](../examples/phase6c1-followup/pledges/dev/runs.csv) · [검증 원자료](../examples/phase6c1-followup/pledges/holdout/runs.csv)

```text
python -B -m experiments.civic_pledge_study64 --sample dev --out examples/phase6c1-followup/pledges/dev
python -B -m experiments.civic_pledge_study64 --sample holdout --out examples/phase6c1-followup/pledges/holdout
```

아래 명령은 기존 자료로부터 개발·검증 출력, `outcomes.json`, `replay-analysis.json`에 대응하는 새 파일을 생성한다. 마지막 명령은 새 Python 프로세스에서 요약을 재생성하고 발표된 `outcomes.json`과 전체 바이트를 비교해 확인서를 작성한다. [원자료 판독·요약 생성기](../experiments/civic_pledge_study64.py) · [확인서 생성기](../experiments/check_pledge_summary64.py) · [발표된 확인서](../examples/phase6c1-followup/pledges/replay-analysis.json)

```text
python -B -m experiments.civic_pledge_study64 --sample dev --out fresh-dev --verify-against examples/phase6c1-followup/pledges/dev
python -B -m experiments.civic_pledge_study64 --sample holdout --out fresh-holdout --verify-against examples/phase6c1-followup/pledges/holdout

```
