# 개간을 선택했다면 어떤 결과가 달라졌을까

개발 시드 0~19에서 개간 후보가 모든 조건을 충족했지만 농업 장비가 선택된 상태 20개를 찾았다. 같은 상태에서 한 번의 결정을 바꾸자, 20개 모두 **개간이 건설 유보보다 유리했고 농업 장비가 개간보다 유리했다**. 초기 3.0 정책에서 개간 선택이 드물다는 관측을 해석하기 위해 실시한 조건부 실험이다. [분기별 원자료](../examples/phase31/decisions/choices.csv)

## 동일 상태에서 달라진 선택

각 시드에 대해 3.0 기본 투자 경로의 51~200년을 순서대로 조사했다. 순편익·기초 자재·노동·보유 한도 조건을 모두 만족하는 개간 후보가 다른 후보에 밀린 최초 국가·연도를 뽑았다. 같은 해가 여러 국가에 해당하면 국가 ID가 가장 낮은 곳을 택했다. 모든 시드에서 51년에 조건이 충족됐다. 농업 장비와 개간은 20개 상태 모두에서 실행 가능했고 광공업 설비는 한 곳에서도 조건을 충족하지 못했다.

각 상태에서 원래의 농업 장비 건설, 개간 건설, 당해 건설 유보의 세 경로를 실행했다. 첫해 한 국가에서 선택 가능한 후보만 제한했다. 비용이나 점수를 조작하거나 자원을 추가하지 않았다. 기초 재고와 노동에서 건설비를 지급하고, 독립 회계 검사를 통과한 연도만 집계했다. 52~59년에는 세 경로 모두 통상적인 3.0 정책, 무역, 인구 이동을 적용했다. 건설 유보 경로에서도 52년부터는 다시 투자할 수 있었다.

## 결과

아래 수치는 시드별로 같은 상태의 유보 경로를 뺀 뒤 20개 차이를 산술평균한 값이다. 5년 예측 점수는 원래 의사결정에서 계산한 값이며, 나머지 열은 실제 분기된 시뮬레이션 결과다.

| 첫해 결정 | 5년 예측 순편익 | 가동 가능 5년 후 누적 순생산가치 차이 | 59년까지 누적 순생산가치 차이 | 51~59년 세계 누적 식량 부족 차이 | 59년 세계 인구 차이 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 농업 장비 | 5,244 | +5,493.6 | +8,901.8 | −684.25 | +101.1명 |
| 개간 | 3,148 | +3,181.2 | +5,185.6 | −425.00 | +62.7명 |

개간을 원래 선택인 농업 장비와 직접 비교하면 59년까지 대상국 누적 순생산가치는 평균 **3,716.2 감소**했다. 각 상태에서의 감소폭은 1,608~6,624였다. 세계 누적 식량 부족은 평균 259.25 증가했고, 세계 기말 인구는 38.4명 줄었다. 세 지표 모두 20개 상태에서 차이의 방향이 같았다.

순생산가치는 대상국에서 생산한 재화별 수량에서 건설·유지·농업 마모·제조 투입을 뺀 뒤 식량 8, 광석 4, 도구 12로 평가했다. 건설에 배정한 노동은 이미 당해 실제 생산을 줄이므로 이 결과에서 노동비를 다시 빼지 않았다. ‘가동 가능 5년 후’는 건설년인 51년부터 56년 말까지의 값이다. 예측은 수요 상한까지의 재고 평가와 고정 노동 단가를 사용해, 두 금액의 차이를 그대로 예측 오차라고 해석하기는 어렵다.

분기 경로에는 후속 건설·무역·인구의 반응이 들어간다. 한 해의 투입을 고정하고 특정 종류 설비의 효과만 끄는 직접 기여도 지표와는 관측 기간과 질문이 다르다. 이 비교로 평가할 수 있는 대상은 개발 시드에서 확인한 **실행 가능했지만 선택되지 않은 개간 후보**다. 홀드아웃, 광공업 투자 또는 모든 시점의 임의 투자 결정에 대한 추정치는 이 표의 범위를 벗어난다.
