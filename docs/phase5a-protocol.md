# 5.0A 공공재정 비교 계획

기준은 [PR #7](https://github.com/mrgameskr-lang/civilization/pull/7) 커밋 `37935d78954b5c11de697257a8d38a4cb7a1d3c9`다. 4.0의 48×32 타일 지도, 8개국·32개 지역, 용량 제한 민간 운송, 설치 지역 투자 효과와 기존 유상 토양 관리를 공통 조건으로 둔다. 각 정부는 자국 내 실물 창고에만 재화를 보유한다. 모든 시드에서 시작 비축과 도로 개량분은 0이다. 국가 전체 재고는 민간 재고와 정부 소유 실물의 합이다.

정부는 연초 상태와 직전 연도의 식량 부족·인구 변화·생산·토양 변화·도로 사용량만으로 계획한다. 공공사업은 기존 창고의 재료와 출발지의 운송비를 지불하고 집행 지역에서 민간에 남는 노동력을 줄인다. 연간 순서는 공공사업, 민간 생산, 국경 거래, 현물 징수, 공공 구호, 민간 국내 배송, 지역 소비·이주, 창고 보관 손실이다. 개량 도로의 추가 용량은 이듬해부터 제공한다. 공공·민간 배송은 그해 실제 도로의 양방향 공용 용량을 순차 사용한다. 화폐는 국경 쌍방 정산에서만 소유자가 바뀐다.

## 표본과 지표

- 개발 시드 0~19와 독립 검증 시드 20~39를 구분한다. 네 군은 정부 없음, 구호 중심, 도로·토양 중심, 통합 정책이다. 검증 표본 실행 전 정책 점수·비용·상한을 고정한다.
- 주 비교는 동일 시드의 **통합 정책 − 정부 없음, 200년**이다. 50·100년은 같은 경로에서 집계한다. 각각의 특화 정책도 동일한 무개입군과 대조한다. 무개입의 전체 민간 원장이 4.0 기준과 일치하는지 검사한다.
- 인구와 식량 부족의 절대량 및 합산 부족률, 민간·국경·공공 운송비, 재화별 징수·정부 잔액, 토양, 도로 용량과 실제 사용량, 공공 집행과 노동을 추적한다. 생활 수준은 지역별 연간 배급 충족률로 관측하고 인년 가중 격차를 보고한다. 한 국가 내부의 격차와 모든 지역 간 격차를 따로 집계한다.
- 잔액과 현금 보존은 각 연도에 검산한다. 평균·시드별 효과와 지역에서 악화된 사례를 함께 공개한다. 가상 재난이나 가격 충격은 추가하지 않는다. 대비 정책은 실제로 징수·보관한 재고와 부족 시 집행 결과로 평가한다.
