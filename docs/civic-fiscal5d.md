# 집단행동에 따른 노동·예산·현물세

5.0D의 두 경로는 같은 초기 세계, 대표 선거, C 정권과 고정세율을 쓴다. 행동을 끄면 5.0C의 C 연간 기록을 그대로 생성한다. 켜면 직전 연말에 관측한 직업집단의 요구·참여가 이번 해에 사용할 노동력, 심사 여력, 예산 순위와 징수액을 바꿀 수 있다.

## 한 해의 순서

1. 지역 기초 인구의 절반(내림)이 노동 공급이다. 시위·파업 참가자가 이번 해 포기한 노동량을 먼저 차감한다. 남은 노동 안에서 공공사업을 실시한 뒤 민간 토양관리, 투자 건설, 농업·광업·제조업에 배분한다. 지역마다 행동 이탈 인력 + 공공사업 실투입 + 민간 토양관리 + 민간 건설 + 생산 배당 인력 = 기초 인구//2다. 생산 배당에는 유휴 인력도 들어간다. 이탈 노동이 한 단위 늘 때 생산량이 반드시 한 단위씩 줄지는 않는다.
2. 각국 내각이 기존 후보와 예산으로 선택한 사업을 먼저 기록한다. 청원·시위·파업·납부 거부 중 인원이 가장 많은 지역·집단의 요구를 재검토한다. 동률이면 지속기간, 낮은 지역 ID, 농업·산업·소비 순이다. 허가·예산·지역 조건을 충족한 후보 중 원래 경제점수가 양수이고 수량이 있는 사업만 선택할 수 있다. 보류 후보에는 양수 점수 조건이 없다. 요구가 뒤집을 수 있는 점수 차는 `min(512, 참가자×8//32)`다. 이전 사업과 새 사업의 종류·위치·경제점수·예산·수량은 국가 응답의 `before`와 `after`에 남는다.
3. 청원을 처리할 때 집단마다 참가자 32명당 1칸(올림)을 국가의 기존 구호 처리 한도에서 차감한다. 여러 청원은 누적되고 전체 처리 한도를 초과해 소진할 수 없다. 같은 해 배급량은 남은 처리 한도·공공창고 식량·구호 예산·물리적 도로의 남은 수송량에 제한된다. 청원으로 점유한 처리 여력이 원래도 유휴였다면 실제 배급량은 그대로일 수 있다.
4. 세금은 국경 거래 후, 국내 배급·민간 운송 전에 실제 지역 민간 재고와 창고 잔여 용량에 대해 사정한다. 징수에 쓰는 직업집단은 행동을 결정할 때의 구성으로 고정된다. 식량은 농업, 광석·도구는 산업에 귀속하며 해당 생산집단 인원이 0이면 소비집단에 귀속한다. 같은 물량을 중복 부과하지 않는다. 유예된 사정액과 거부액은 원래 민간 창고에 남는다.

## 정부 결정과 집행

| 원장 값 | 승인 내용 | 실제 효과 확인 |
|---|---|---|
| `maintain` | 내각의 기존 결정을 유지 | 요구가 있어도 후보 자격·예산·점수 차 등으로 변경을 유보한 경우와 요구가 없는 경우가 포함된다. 기존 사업은 예정대로 집행될 수 있다. |
| `defer` | 내각이 잡아 둔 사업을 국가 보류 후보로 변경 | 이번 해 그 재량 사업 예산·인력은 사용하지 않는다. 원장에 이전 사업과 새 보류가 함께 남는다. 개별 도로의 정기 유지보수는 계속 가능하다. |
| `reprioritize` | 다른 자격 있는 사업에 단일 재량 예산을 재배정 | 목적 지역의 공공사업·배급·추가 비축 영수증으로 확인한다. |
| `tax_adjust` | 가장 큰 납부 거부 집단의 지역·직업에 한해 정규 현물세의 25%를 올 한 해 감면 | 수량 내림 및 법정 사정액·귀속에 따라 실제 감면이 0일 수 있다. 사업 보류를 함께 승인한 경우에는 이 값이 우선한다. |
| `compromise` | 다른 재량 사업을 선택하면서, 납부 거부 집단의 지역·직업 정규세를 12.5% 감면 | 사업이 실제 집행됐는지와 대상 집단의 실제 감면량이 양수인지를 따로 검산한다. |

집단별 감면·거부·실납부의 단위는 재화다. 재화별 정규 사정액을 S, 추가 비축 사정액을 X, 해당 집단의 감면을 C = ⌊S×감면율/1000⌋라고 하자. 직업집단 인원이 N이고 실제 납부 거부 인원이 R이면 정규 거부액은 ⌊(S−C)×R/N⌋, 추가 거부액은 ⌊X×R/N⌋다. 거부가 없거나 집단 인원이 없으면 각 거부액은 0이다. 실징수는 S+X−C−두 거부액이고, 실제 납부된 추가 비축 식량에 대해서만 32단위당 1단위(올림)의 처리 손실이 발생한다. 정규세는 이 손실이 없다. 세입 원장의 `baseline_levy`는 실제로 승인한 최종 사업에 따른 법정 사정액이므로, 대체된 예산 아래의 가상 비축액을 포함하지 않는다.

### 개발 시드 5, 58년, 국가 0

지역 0 농업집단은 1,568명 중 114명이 토양 사업을 청원했다. 지역 1에서는 농업집단 480명 중 67명이 납부를 거부했다. 같은 58년 기초 상태에서 두 행동을 각각 하나씩 제외하고 정부 결정부터 국내 이동·소비까지 다시 계산했다. 양쪽 분기에서 재실행한 실제 기록은 정상 경로와 동일한 SHA-256을 냈다.

| 동일 기초 상태의 처치 | 실제 | 지역 0 청원만 제외 | 지역 1 거부만 제외 |
|---|---:|---:|---:|
| 원안 구호 91단위 대비 승인 | 토양 | 구호 유지 | 토양 |
| 청원 처리 칸 | 4 | 0 | 4 |
| 실제 국가 구호 식량 | 0 | 90 | 0 |
| 토양 사업의 광석 / 도구 / 노동 | 2 / 2 / 4 | 0 / 0 / 0 | 2 / 2 / 4 |
| 정비 타일 / 지역 토양지수 상승 | 12 / 4 | 0 / 0 | 12 / 4 |
| 지역 1 농업의 식량세 사정 / 감면 / 거부 / 납부 | 45 / 5 / 5 / 35 | 45 / 11 / 4 / 30 | 45 / 0 / 0 / 45 |
| 지역 0 식량 생산 / 식량 부족 | 8,223 / 2,246 | 8,188 / 2,217 | 8,223 / 2,246 |

이 사례에서 청원은 국가의 실제 배급 90을 대체하고 토양을 개선했다. 같은 해 해당 지역의 생산은 35 늘고 부족도 29 늘었다. 지역 1의 납부 거부를 단독으로 제외하면 사업·배급 결과가 같아도 식량세 납부는 35에서 45로 늘어난다. 반대로 청원만 제외하면 세금 감면율이 타협의 12.5%에서 단독 감세의 25%로 바뀐다. 따라서 청원에 따른 분기 차이에는 사업 배분과 감면율 변화가 함께 들어 있다. 이 비교는 해당 해의 결과만 측정한다.
```sh
python -B -m unittest tests.test_civic_fiscal tests.test_collective_integration tests.test_public_works5 tests.test_government5 tests.test_appropriation_audit5 -q
python -B -m experiments.compromise5d --out examples/phase5d/compromise.json
```
