# 6.0A 사전 실험 계획

기준은 PR #11 `a4721bd`의 집단행동 활성·고정세·대표 선거 모형이다. 48×32 지도, 8개국, 국가당 4지역과 외부 의존성이 없는 Python 엔진을 유지한다. 0~19는 개발, 20~39는 독립 검증으로 구분한다. 같은 시드에서 네 경로를 200년 연속 실행하고 50·100·200년 결과를 비교한다. 별도 프로세스에서 전부 반복한다.

| 군 | 외교 관측·행동 |
|---|---|
| A | 5.0D 활성 경로의 기존 초기 세계 및 연간 원장 |
| B | 28개 국가 쌍의 국경·교역·이주와 관계만 관찰. 나머지 원장은 A와 동일해야 함 |
| C | B와 같은 관측, 양측이 승인한 기간제 무역 협력 및 종료. 실제 도로 용량 안에서 거래 실행 순위가 바뀔 수 있음 |
| D | C에 현물 식량 구호의 양측 의사, 수출·입국의 별도 제한 및 해제를 추가 |

연초 결정에는 직전까지의 관계·역사, 개방 상태, 완료된 거래·부족·집단 선호, 연초 창고와 지도상 연결을 쓴다. 당해 수확·소비·이동은 결정 뒤에 기록한다. 구호는 기존 공공 창고에서 지급하며 국경 용량, 거리별 식량 운임, 취급 손실을 지불한다. 협정 체결·이행·무기회·미이행·기간 만료·조기 종료를 구분한다. 상대국이나 양방향 국경에 일괄로 효력을 부여하지 않는다. 식량 구호에 따른 국내 반응은 실제 지역별 공여·수령, 직전 집단 요구 및 실현된 경제 상태에 근거한다.

일차 비교는 관측의 중립성(B−A), 협력 우선권(C−B), 구호와 두 통제의 추가 효과(D−C)다. 국별 인구·식량 부족(필요량 분모)·현금·상품별 수출입·상대국·국제 이주, 국경별 처리 용량, 관계·신뢰, 지원·거절·불이행, 국내 지지·불만을 기록한다. 경제 및 외교 행동이 없거나 결과가 악화된 경우도 그대로 보고한다. 구호 송장에서는 공여자 출고·수혜자 입고·운임·취급 손실을 각각 검산한다.

단년 개입은 개발 표본의 자연 체결 또는 실제 국경 제한 중에서 해당 체결 하나를 보류하거나 한 방향의 제한 하나만 해제한다. 같은 연초·다른 외교 결정·도로·재고를 지키고 당해 물자·돈·인구를 재계산한다. 이 비교와 장기 경로의 연관성을 구별한다. 새 정책 계수는 독립 검증 결과를 열기 전에 고정한다.
