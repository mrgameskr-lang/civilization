# 민간 외교분쟁 관측과 협의

## 비교 설계

개발 시드 0~19와 독립 검증 시드 20~39의 6.0B2 D 국경경제를 고정한다. 세계별 8개 국가의 28개 국가쌍을 모두 200년 추적한다. 각 해의 판단에는 직전 연말까지 확정된 양방향 원장만 사용한다. 첫해에는 이전 관측이 없다. 마지막 200년차 경제 활동은 결산 검산에 포함하고 외교 판단에는 199년차까지의 결산을 쓴다.

두 경로에서 같은 경제와 같은 분쟁 관측식을 사용한다. `observe`는 협의를 보류하고 `consult`는 양국의 의사에 따라 협의를 제안하고 수락하거나 거절한다. 동일 연초 개입에서는 협의를 허용한 경로를 결정을 내리기 직전에 복사하여 해당 연도에만 협의를 보류한다. 원본과 복사본의 외교 상태와 경제 입력이 같은지 모든 국가쌍에서 확인한다. 이후 여러 해에 걸친 두 경로의 차이와 동일 연초 개입의 차이는 따로 집계한다.

독립 재실행에서는 두 집단의 50·100·200년 해시, 연간 국가쌍 원자료, 개입 원자료와 사례를 새 프로세스에서 다시 생성해 바이트 단위로 비교한다. 이전 연구에서 발표한 경제 경로의 해시를 인용하고, 파일별 해시와 국가수지 대조로 이번 연구가 사용하는 경제 데이터의 출처를 확인한다. 신규 경제 전체 원장의 연도별 독립 재생은 별도 검산한다. 각 체크포인트의 인구·섭취·부족은 과거 경제 경로에서 얻는다. 협의 자체가 재화·이주·소득을 바꾸는 효과는 이 설계에서 추정할 수 없다.

분모에는 비인접 국가쌍도 남긴다. 0·1·2개 방향이 관측된 횟수를 따로 저장하고, 실제 국경을 맞댄 국가쌍에서는 어느 한쪽만 빠져도 검산을 중단한다. 양방향 결산이 없는 해의 미관측값은 무분쟁·무거래로 해석하지 않는다. 외교 상태가 활성인 관측 연도와 해당 연도에 시작한 새 분쟁을 구분한다.

6.0B2에서 두 표본의 경제 결과를 이미 공개했다. 이번 연구에서는 정책을 고정하고 같은 두 표본에서 검산했다. 아직 공개되지 않은 새로운 세계에서 이 가설의 예측력을 평가하려면 새 시드를 사용해야 한다.

## 관측 결과

40개 세계 모두에서 분쟁이 한 번 이상 시작됐고 협의가 한 번 이상 수락됐다. 200년간 수락 2,424건과 거절 45건을 관측했다. 같은 연초에 제안을 보류하면 수락된 2,424쌍·년의 협의 상태가 달라졌다. 실제 경제 입력이 고정되어 있어 두 경로의 분쟁 시작·지속·완화와 인구·식량·현금은 모두 같았다. [집계와 사례](../examples/phase6c1/diplomacy/outcomes.json)

수치는 각 시점까지의 누계다. 제안한 해마다 한 건을 세므로 같은 분쟁에서 여러 번 수락할 수 있다. 보류 정책에서는 수락·거절 건수가 모두 0이다. 새 분쟁은 합계 671건, 완화는 669건이며 각 표본에서 1건이 200년 말에 이어졌다. 분쟁 시작에는 접근 협정 위반, 관측된 통행·화물 거절 중 해당 방향 시도량의 4분의 1 이상, 또는 긴장 지수 125 이상에서의 실제 거절이 필요하다. 분쟁 완화에는 거절이 관측되지 않는 두 해가 연속으로 필요하다. [민간 외교 판단식](../civsim/civic_diplomacy63.py)

실제 국경이 맞닿은 국가쌍은 개발 245개, 검증 252개다. 그중 개발 75개와 검증 90개는 분쟁이 한 번도 시작되지 않았다. 거절이 한 번도 없었던 세계는 개발 6개와 검증 10개다. 비인접 국가쌍 개발 315개·검증 308개는 이 자료에서 양방향 신호를 관측할 수 없었다. 1~200년 경제 결산에는 인접쌍의 양방향 기록이 각각 49,000·50,400건 있었고 단방향만 남은 쌍·년은 양쪽 모두 0이었다. 판단 가능한 자료의 마지막 연도는 199년이므로 표의 관측 분모는 각각 48,755·50,148이다. 모든 표본의 첫해 28쌍은 미관측으로 기록됐다. ## 같은 연초의 수락·거절과 이듬해 관측

개발 시드 0의 2년차에 0국에서 2국으로 176명이 실제 이동했고 출국 거절량은 59였다. 거절 비율은 기록된 기회 235건 중 59건이다. 반대 방향에서는 식량 262와 도구 8이 실제 거래됐다. 이 자료를 읽는 3년차에 2국이 먼저 협의를 요청했고 0국이 수락했다. 보류한 복사본도 같은 자료에서 같은 분쟁의 시작을 기록했다. 협의 허용 시에만 협의 상태가 열렸고, 다음 해 양쪽의 분쟁 상태는 계속 활성으로 남았다. 거절량은 동일인의 재시도 가능성이 있는 경로별 기회 수량이다. [개발 표본의 두 원장](../examples/phase6c1/diplomacy/dev/fork-cases.json)

같은 세계의 17년차에는 3국에서 6국으로 들어가는 입국이 한 차례 거절됐다. 이어진 18년차에 3국이 협의를 제안했지만 6국은 그 전해 상대국으로 실현한 교역이나 이주가 없어 거절했다. 보류 복사본과 마찬가지로 협의는 열리지 않았고 19년차에도 분쟁은 이어졌다. 독립 검증 표본에서도 시드 21의 29년차에 7국의 요청을 받은 6국이 같은 이유로 거절했다. [검증 표본의 두 원장](../examples/phase6c1/diplomacy/holdout/fork-cases.json)

수락 2,424건 중 검증 표본 마지막 해의 1건은 후속 관측이 없다. 나머지 2,423건과 거절 45건은 이듬해 모두 분쟁이 지속됐다. 제안은 거절 등 구체적인 불만이 있을 때 발생하고, 완화에는 연속 두 해의 조용한 관측이 필요하다. 이 선택·기간 규칙과 고정 경제가 수락 뒤의 관측 결과를 제약한다. 이 횟수로 협의가 실제 갈등을 오래 끌거나 해소한다고 추론할 수 없다. 같은 연초에 직접 바뀐 값은 협의 개시 여부였다. [전체 후속 관측](../examples/phase6c1/diplomacy/outcomes.json)

## 원자료와 재현

| 파일 | 재현 가능한 내용 |
|---|---|
| `annual.jsonl.gz` | 시드·연도·정책별 한 줄, 줄마다 28쌍. 직전 양방향 원자료, 관측 가능성, 양국의 불만·제안·거절 사유와 연초·연말 상태를 포함한다. |
| `runs.csv`, `pairs.csv` | 50·100·200년의 세계·국가쌍 누계. 세계 표에는 기존 D 경제 원장과 새 외교 원장의 SHA-256, 인구·식량·현금이 있다. |
| `fork-checkpoints.csv`, `same-opening.csv.gz`, `fork-cases.json` | 모든 국가쌍의 연초 보류 개입 누계, 실제 제안을 하거나 기말 상태가 달라진 해의 원본·개입 비교, 시드별 최초 수락·거절의 두 상세 원장. |
| `source.json`, `execution.json` | 6.0B2 원본 13개 파일의 SHA-256과 관측 방향 분포, 신규 과학 파일 해시·측정시간. |

개발·검증 두 표본의 원래 D 체크포인트 120개에서 초기 지도·상태 해시와 해당 시점의 국가경제 합계를 대조했다. 8,000세계연도마다 국가 수지와 방향별 국경 결산의 수출입·이주·거절·원조·운임·손실을 독립 검산했다. 외교 관측과 협의의 원본 16,000세계연도에 이어 새 프로세스에서 16,000세계연도를 다시 실행했다. 224,000쌍·년의 같은 연초 비교도 전수 반복했다. 240개 외교 체크포인트와 14개 과학 파일의 전체 바이트가 모두 일치했다. 별도의 원자료 판독기도 압축 원장으로부터 체크포인트 240개의 해시를 직접 다시 계산했다. [독립 판독기](../experiments/analyze_civic63.py)

각 코호트는 단일 프로세스에서 실행했고 두 코호트는 CPU를 공유했다. Python 3.12.14에서 개발은 원본 35.726초·반복 40.113초, 독립 검증은 원본 36.490초·반복 40.175초였다. 과학 파일 7개의 용량은 개발 6,736,398바이트와 검증 6,821,769바이트다. 프로그램은 매해 28쌍의 근거·상태를 두 정책에서 직렬화하고 압축하며, 보류 복사본을 별도로 계산한다. 더 큰 국가 수에서는 추적할 쌍의 수가 국가 수의 제곱에 비례해 늘어난다. [개발 실행](../examples/phase6c1/diplomacy/dev/execution.json) · [개발 반복](../examples/phase6c1/diplomacy/replay-dev.json) · [검증 실행](../examples/phase6c1/diplomacy/holdout/execution.json) · [검증 반복](../examples/phase6c1/diplomacy/replay-holdout.json)

원자료 판독도 별도 프로세스에서 한 번 더 실행해 발표한 `outcomes.json`과 전체 바이트가 같은지 확인했다. 국경 자료 검산·실험 및 민간 외교 규칙의 집중 자동 테스트 11개가 통과했다. [판독 반복 확인서](../examples/phase6c1/diplomacy/replay-analysis.json)

저장소 루트에서 아래처럼 재현할 수 있다. `dev`를 `holdout`으로 바꾸면 두 번째 표본을 실행한다. `fresh-dev`와 `checked-outcomes.json`은 새 경로여야 한다.

```text
python -B -m experiments.civic_disputes63 --sample dev --out fresh-dev --verify-against examples/phase6c1/diplomacy/dev
python -B -m experiments.analyze_civic63 --study examples/phase6c1/diplomacy --out checked-outcomes.json
```
