# 5.0B 지역의 경제 이해와 정부의 정당성

한 해의 식량 부족과 공공사업 경험이 이듬해 정부의 우선순위를 바꿀 수 있다. 기본 경제는 5.0A 통합 재정이다. 정부는 같은 시점의 후보별 편익·비용·재고·운송 가능량을 계산하고, 실제로 허용된 후보 중에서 행동 및 대상 지역을 고른다. 정치 우선순위를 켜면 권고가 달라진 해에만 실제 경제 경로가 갈라질 수 있다. [의사결정과 반응 수식](political-rules.md) · [실험 계획](phase5b-protocol.md)

## 시간과 장부의 경계

1. 연초에는 직전 해까지 누적된 지역 집단별 기억을 읽는다. 초기 세계의 집단별 소속은 첫 생산 원장이 생길 때까지 미분류다. 최초 지지 지수는 500/1000이다.
2. 5.0A가 후보를 만들고 경제 점수로 선택한다. 정치 규칙은 경제 후보별 **별도 점수**와 추천을 기록한다. `--feedback off`에서는 경제적 선택이 그대로 집행되고 정치 지표는 관측만 한다. `--feedback on`에서는 정치적 우선순위를 반영한 선택을 집행한다.
3. 5.0A가 세금, 공공 자재와 노동, 공사·구호·민간 배송, 식량 소비와 인구 이동을 기표한다. 승인된 안과 집행된 양은 각각의 원장에 기록한다. 제약을 충족하지 못한 사업은 정치 점수에 관계없이 집행할 수 없다.
4. 마감된 원장에서 실제 노동, 지역별 부족, 부담, 수혜를 읽는다. 농업 / 광공업 / 나머지 소비자 대표의 인원 합은 그해 기초 지역 인구다. 해마다 소속을 새로 산출하고 기억은 장소와 집단에 남긴다. 대표 간 귀속과 정책 평가 점수는 모형의 가정이다.
5. 지역·정부·국가의 경제 보존식과 예산·정치 승인·상태 갱신을 검사한 뒤 연도를 게시한다. 한 해의 실패가 다음 해의 재정과 정당성 상태를 따로 바꿀 수 없도록 함께 반영한다. [연간 결합](../civsim/politics.py) · [승인 감사](../civsim/appropriation_audit.py)

## 실행 및 재생

시드 0의 동일한 연초를 복제한 한 해 비교에서, 도로 신설 대신 구호 84단위를 승인하자 기존 민간 배송 70단위가 밀려 주민 섭취는 14단위 늘었다. 다른 해에는 토양 사업 대상만 바꿔 세계 식량 부족이 2단위 늘었다. 집단 지지에 반영되는 수혜는 실물 수령과 사업 경험이며 순섭취·순후생의 측정값과 구분해야 한다. [같은 연초에서의 두 승인 실험](political-forks5.md)

```sh
python -m civsim politics --feedback off --seed 7 --years 50 --out runs/5b-shadow7
python -m civsim politics --feedback on --seed 7 --years 50 --out runs/5b-feedback7
python -m civsim analyze runs/5b-feedback7
python -m civsim verify runs/5b-feedback7
```

상세 실행은 새 디렉터리에 연도 0 스냅샷, 버전과 피드백 설정, 연간 JSONL을 쓴다. 각 해의 `politics.regions`에는 지역의 기초·기말 상태가, `politics.countries`에는 그해의 경제·정치 권고가, `government.accounts[].decision`에는 실제 승인안이 있다. 재생은 초기 상태와 모든 연도의 정규 JSON 바이트를 대조한다. 기존 5.0A 원장을 생성하는 명령은 `python -m civsim government`이다.

정당성은 경제 경험에 대한 모형상의 반응이다. 같은 지역 안의 분배를 가구별로 관찰한 자료, 소득·자산에 따른 계급, 실제 여론조사나 선거로 보정한 계수는 사용하지 않았다. 검증 범위와 성과는 [실험 결과](phase5b-results.md)와 [실행 로그](phase5b-run.md)에 있다.
