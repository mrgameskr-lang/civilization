# 같은 연초에서 확인한 내각 교체와 세율의 효과

개발 시드 0에서 실제 선거로 집권 정파가 바뀐 두 해를 선택했다. 정해진 선거 결과는 양쪽에 기록하고 그해 재정의 승인권만 당선 내각 또는 직전 내각에 한 해 동안 부여했다. 13년 차 국가 1에서는 당선 내각의 구호가 부족을 29식 줄였다. 17년 차 국가 0에서는 당선 내각의 구호로 2식을 배급했지만 토양 사업을 포기해 부족이 18식 늘었다.

| 시드 0의 같은 연초에서 비교 | 직전 내각이 집행 | 당선 내각이 집행 |
|---|---|---|
| 13년, 국가 1 | 절제파의 도로 신설. 지역 6에서 4로 광석 6개·도구 4개 수송, 운임 2식, 노동 6인년 | 구호파의 지역 4 구호. 지역 6 창고에서 29식 배송, 운임 4식 |
| 당해 수확 / 부족 | 8,248 / 1,042 | 8,248 / 1,013 |
| 기말 창고 식량 / 차년도 국가 도로 용량 | 33 / 1,350 | 4 / 1,302 |
| 17년, 국가 0 | 농업 보전파의 지역 0 토양 사업. 광석 2개·도구 2개·노동 4인년으로 토양 지수 3 회복 | 구호파의 지역 0 구호. 지역 3 창고에서 2식 배송, 운임 1식 |
| 당해 수확 / 부족 | 10,724 / 1,523 | 10,704 / 1,541 |
| 기말 창고 식량 / 차년도 국가 도로 용량 | 11 / 1,202 | 8 / 1,202 |

13년 차 국가 1의 구호파는 21석 중 16석을 얻었다. 도로의 경제 점수 536, 구호의 경제 점수 200에서 시작했다. 직전 내각의 도로 승인 합산 점수는 551, 새 내각의 구호 승인 합산 점수는 570이었다. 기초 창고에는 식량 33식이 있었고, 당해 식량 정기세는 4식이었다. 구호 집행이 29식 모두 추가 섭취로 이어진 동안 주민의 민간 반입은 두 경우에 413식으로 같았다. 세계 부족은 3,467식에서 3,438식으로 줄었다. 도로가 이듬해 제공할 48칸의 효과는 이 한 해에서 관측할 수 없다. [13년 원장](../examples/phase5c/forks/election-13.json)

17년 차 국가 0에서 구호파는 21석 중 19석을 얻었다. 기초 창고 식량은 4식이었다. 당선 내각이 실제로 낸 2식의 구호와 운임 1식은 현지 가용 재원에 맞았다. 지역 0은 직전 내각의 토양 사업을 집행하면 6,116식을 수확하고 당선 내각의 결정 아래서는 6,096식을 수확했다. 두 경우의 민간 식량 반입은 537식으로 같아 구호 2식을 포함해도 주민 섭취가 18식 줄었다. 세계 부족은 8,314식에서 8,332식으로 늘었다. [17년 원장](../examples/phase5c/forks/election-17.json)

## 선거 결과와 사업을 고정한 13년 차 세율 비교

위 13년 차와 동일한 기초 상태·당선 내각을 복제해 여덟 국가의 정기세만 각 집권 강령에 맞게 바꿨다. 모든 국가의 사업 승인, 공사, 민간 생산, 국경 거래 기록 전체가 일치했다. 다음 표는 세계 평균으로 보이지 않는 국가별 차이를 보여준다. 괄호 안 수입은 순서대로 정기세로 징수한 식량·광석·도구이며, 두 열은 각각 고정세와 강령세의 실제 기표액이다.

| 국가 / 강령 | 고정세 수입 | 강령세 수입 | 기말 공공 식량, 고정 → 강령 | 주민 부족, 고정 → 강령 |
|---|---:|---:|---:|---:|
| 0 농업 보전 | 22 / 4 / 9 | 14 / 4 / 10 | 21 → 13 | 349 → 342 |
| 1 구호·비축 | 4 / 1 / 2 | 6 / 1 / 2 | 4 → 6 | 1,013 → 1,015 |
| 2 농업 보전 | 110 / 10 / 10 | 110 / 10 / 10 | 1,157 → 1,157 | 296 → 296 |
| 3 구호·비축 | 0 / 0 / 0 | 0 / 0 / 0 | 0 → 0 | 1,598 → 1,598 |
| 4 재정 절제 | 60 / 6 / 6 | 60 / 6 / 6 | 394 → 394 | 0 → 0 |
| 5 농업 보전 | 46 / 5 / 5 | 46 / 5 / 5 | 291 → 291 | 0 → 0 |
| 6 농업 보전 | 51 / 8 / 8 | 44 / 8 / 8 | 321 → 315 | 7 → 7 |
| 7 농업 보전 | 45 / 5 / 5 | 45 / 5 / 5 | 414 → 414 | 175 → 175 |

국가 1의 지역 6에는 국경 거래 뒤 식량 1,606식 중 1,528식이 보호되어 초과분이 78식이었다. 고정세 `78//16 = 4`와 구호파 세율 `78//12 = 6`의 차이 2식이 지역 6의 민간 재고에서 같은 지역 창고로 옮겨갔다. 이미 승인한 구호 29식은 양쪽 모두 지역 4에 도착했다. 뒤이어 지역 6에서 4로 갈 민간 배송은 215식에서 213식으로 줄고 운임은 두 경우 모두 28식이었다. 따라서 이 나라에서는 주민 미섭취량 2식과 기말 정부 재고 2식이 함께 증가했다.

세계 전체의 식량 정기세는 338식에서 325식으로 줄었고, 추가 비축 징수 333식과 취급 손실 11식은 같았다. 구호 배송은 204식에서 203식, 공공 운임은 29식에서 30식, 보관 손실은 227식에서 226식으로 바뀌었다. 기말 공공 창고의 식량은 2,602식에서 2,590식, 주민 부족은 3,438식에서 3,433식으로 줄었다. 이 숫자는 여덟 국가가 동시에 강령세를 적용한 1년의 결과다. ## 재현과 검산

시드 0의 C군 고정세 경로를 각각 12년과 16년 연속 실행했다. 한 해 분기 전의 전체 정치 기억·내각·지도·경제 원장의 해시가 분기 뒤에도 같은지, 정상 경로의 실제 당선·고정세 기록이 해당 분기와 바이트 단위로 같은지 검사했다. 두 내각 사이에서 다른 국가의 승인은 같다. 각 분기에 대해 여덟 나라의 창고를 기초 잔액부터 재기표하고, 원래의 지도와 직전 공사 영수증에서 모든 도로 용량과 실제 송장을 검증하고, 공개한 공공 노동과 실제 민간에 남은 노동의 합을 재검산했다. 일반 시뮬레이션은 하나의 처리군을 유지한다. 분기는 이 1년만 관측하고 버린다. 이 사례는 개발 표본에서 선택한 것으로 빈도나 장기 평균효과를 추정하는 근거가 되지 않는다. [실험 코드](../experiments/competition_forks5c.py) · [저장된 분기의 재생 검사](../tests/test_competition_forks5c.py)

다음 명령은 출력 파일이 존재하지 않는 경로에서 실행할 수 있다. 동결본 검증에서는 같은 계산을 작업용 디렉터리에서 실행해 아래 파일로 발행하고, 테스트가 다시 계산한 모든 필드를 저장본과 대조했다.

```sh
python -B -m experiments.competition_forks5c election --seed 0 --year 13 --owner 1 --out examples/phase5c/forks/election-13.json
python -B -m experiments.competition_forks5c election --seed 0 --year 17 --owner 0 --out examples/phase5c/forks/election-17.json
python -B -m experiments.competition_forks5c tax --seed 0 --year 13 --owner 1 --out examples/phase5c/forks/tax-13.json
python -B -m unittest tests.test_tax_policy5c tests.test_competition_forks5c -v
```
