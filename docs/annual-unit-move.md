# 실제 지역과 창고를 사용하는 연간 유닛 이동

시드 0의 2년 차, 국가 1의 기존 주소지 명부에서 1명이 **지역 5에서 지역 4로** 이동했다. 사용한 국내 도로의 ID는 `(4,5)`다. 지역 5 공공창고가 식량 1을 지출했고, 연말과 3년 차 연초에 이 1명이 모두 지역 4에 있었다. 같은 연초에 명령을 보류한 경로보다 연말 창고 식량과 도로 잔량이 각각 1 작았다. 두 경로의 민간 배송과 주민 섭취는 모든 지역에서 같았다. [입력·출력 및 32개 지역별 대조](../examples/annual-unit-v1/case/results.json)

| 시드 0, 2년 차 | 이동 | 보류 | 이동 − 보류 |
|---|---:|---:|---:|
| 지역 5 창고의 연말 식량 | 2 | 3 | −1 |
| 도로 (4,5)의 연말 잔량 | 220 | 221 | −1 |
| 지역 5 / 4의 연말 유닛 수 | 9 / 62 | 10 / 61 | −1 / +1 |
| 지역 5 / 4의 주소지 주민 수 | 869 / 5,868 | 869 / 5,868 | 0 / 0 |
| 해당 도로의 민간 화물 | 125 | 125 | 0 |
| 세계 국내 민간 식량 배송 | 1,293 | 1,293 | 0 |
| 지역 5 / 4의 주민 섭취 | 846 / 4,356 | 846 / 4,356 | 0 / 0 |
| 세계 주민 섭취 | 64,955 | 64,955 | 0 |

## 같은 저장에서 이동하거나 보류하기

Python 3.11 또는 3.12로 저장소 루트에서 실행한다. 각 `step`은 경제 전체를 1년 진행한다. `--move`의 인자는 주소지, 출발지, 도착지, 인원 순이다. 기존 저장 슬롯에 덮어쓸 수 없다.

```sh
python -m civsim.annual_game new --seed 0 --out opening.json
python -m civsim.annual_game step opening.json --out year1.json
python -m civsim.annual_game step year1.json --move 5 5 4 1 --out moved.json
python -m civsim.annual_game step year1.json --out held.json
python -m civsim.annual_game step moved.json --out next.json
python -m civsim.annual_game show next.json
```

매 저장에는 시드와 연도별 명령·결과 해시가 들어간다. 읽을 때 해당 연도까지 경제를 다시 실행해 해시를 확인한다. 저장 비용은 작고 불러오는 시간은 경과 연수에 비례한다. [저장 예제](../examples/annual-unit-v1/saves) · [게임 진입점](../civsim/annual_game.py) · [연간 원장 적용 코드](../civsim/unit_economy.py)

## 연간 처리와 회계 규칙

1. 선택형 `annual-unit/1`은 기존 고정 복무 경제 `6.0B2/C`의 명부를 쓴다. 최초 활성화 시 주소지 밖 위치는 비어 있다. PR #19의 행정 소속은 물리 위치의 근거로 사용하지 않는다. 주소지 밖에 있는 수만 `[주소지, 현재 지역, 인원]`으로 저장한다. 주소지에 있는 인원은 해당 주소지 명부 총수에서 이 합계를 빼면 구할 수 있다.
2. 기존 공사·창고 간 배송·왕복 근무·생산·국제 거래·징수를 진행한다. 전년부터 주소지 밖에 남은 유닛을 주소지의 왕복 근무에 또 배정하지 않는다. 기존 배식은 주민의 주소지 식사 회계에 속한다. 유닛 이동에 추가 노동이나 추가 식사를 배정하지 않는다.
3. 징수 후, 공공구호와 민간 배송 전에 플레이어 명령을 한 번 처리한다. 실제 같은 나라의 도로가 연결하고, 기존 명부에서 해당 위치에 남은 인원·출발 창고 식량·도로 잔량이 모두 `q` 이상일 때만 전량 승인한다. 당해 신규 등록자와 이미 왕복 근무에 배정한 인원은 주소지에서 출발할 수 있는 수에서 제외한다. PR #20과 같은 한 칸 비용 규칙을 써서 식량 `q`, 도로 용량 `q`를 차감한다. 지도상의 물리 경로는 기존 도로의 타일 배열이며 식량 단가는 이 게임에서 거리와 관계없이 한 간선당 1이다.
4. 성공한 이동은 원장의 `unit_game.receipt`와 도로의 `unit_use`, 국가 계정의 `unit_move_food`에 기록한다. 기존 왕복 영수증은 `service.moves`와 `duty_use`에 남는다. 시드 0 사례에서 도로의 기본 용량은 352, 왕복 사용량은 6이었다. 편도 이동 시점의 346에서 1을 지불한 뒤 345가 구호·민간 배송으로 넘어갔다. 민간이 125를 써 연말 220이 남았다. 운임으로 사용한 식량은 출발 창고에서 소모되며 주민 섭취에는 들어가지 않는다.
5. 연말에는 기존 명부에 기록된 해제·사망·이주만큼만 해당 그룹에서 제외할 수 있다. 개인 ID가 없으므로 주소지에 있는 명부 인원을 먼저 제외하고, 필요할 때만 방문 지역 번호가 큰 순으로 해당 지역 그룹을 줄인다. 나머지 현재 위치는 다음 연초로 이월한다. 지역별로 합산한 현원은 주소지별 명부와 같은 사람을 세는 별도 관점이다. 주민 수에는 더하지 않는다.

## 세 가지 거절 사례

| 시드 0, 2년 차 | 입력 조건 | 이동·식량 지출·도로 사용 |
|---|---|---|
| 창고가 빔 | 지역 4 → 5, 1명, 출발 식량 0 | 0 / 0 / 0 |
| 명부 초과 | 지역 5 → 4, 99,999명, 이동 가능 2명 | 0 / 0 / 0 |
| 도로 포화 | 지역 3 → 0, 1명, 잔량 0, 출발 식량 4 | 0 / 0 / 0 |

도로 포화는 통제 실험이다. 시드 0 지도의 기존 도로 (0,3) 하나의 기본 용량만 1로 줄였다. 먼저 실행된 공공 배송이 그 1을 실제로 사용했다. 각 실패는 동일 조건에서 명령을 보류한 경로와 대조했다. 실패 영수증을 제외한 연간 경제 원장 전체와 연말 세계 상태가 같았다. 거절해도 그해의 일반 경제는 진행된다. [같은 연초와 이동·보류·실패 전체 원장](../examples/annual-unit-v1/case)

## 실제 검증과 재현 명령

```sh
python -B -m unittest tests.test_annual_unit_move tests.test_annual_game_cli -v
python -B -m experiments.annual_unit_case --out new-case
python -B -m experiments.annual_unit_case --verify examples/annual-unit-v1/case
python -B -m experiments.annual_unit_study --workers 6 --out new-study
python -B -m experiments.annual_unit_results new-study --out new-summary.json
python -B -m experiments.annual_unit_results new-study --repeat-seeds 0 20 --out new-repeat.json
python -B -m unittest discover -v
```

작은 성공·실패·이월 검증 후 시드 0~19와 별도 검증 시드 20~39를 실행했다. 시드마다 2년 차에 동일한 5 → 4 이동을 한 번만 지시하는 경로와 보류하는 경로를 비교했다. 도로가 없거나 잔액이 부족해도 다른 지역이나 연도로 옮겨 재시도하지 않는다. 같은 시드의 양 경로가 첫해를 공유하므로 16,000개 경로·연도에 필요한 실제 연간 계산은 15,960번이다. 50·100·200년에 최종 인구·위치, 누적 섭취·식량 부족·국내 민간 배송 및 연간 원장 누적 해시를 남긴다. [시드별 원자료](../examples/annual-unit-v1/study)

이 실험은 단일 명령의 효과를 추적한다. 한 사람이 대표하는 그룹의 집계 위치를 검증했으며 개인의 연속 신원이나 개별 섭취 자료는 없다. 전국적인 다중 이동 정책이나 경로 최적화의 성능은 측정 대상 밖이다.

## 40개 세계의 결과

| 표본 | 2년 차 이동 성공 | 출발 식량 부족 | 50 / 100 / 200년 말 지역 4에 남은 수 | 200년 말 인구 차이 범위 | 200년간 누적 식량 부족 차이 범위 |
|---|---:|---:|---|---:|---:|
| 개발 0~19 | 16 | 4 | 16 / 16 / 16 | −27 ~ +59 | −504 ~ +114 |
| 독립 검증 20~39 | 18 | 2 | 18 / 18 / 18 | −60 ~ +128 | −716 ~ +2 |

두 표본에서 200년 말 인구 차이의 중앙값은 0명이었다. 독립 검증 시드 31에서는 민간 국내 배송이 누적 961단위 줄고 최종 인구가 60명 줄었다. 시드 27에서는 각각 814단위와 128명이 늘었다. 34개 세계에서 방문 인원이 200년까지 유지된 결과에는 명부에서 인원을 제외할 때 주소지에 있는 사람을 먼저 빼는 집계 규칙이 작용한다. 한 사람이 200년을 살았다는 의미로 해석할 수 없다. [시드별 차이 및 분포](../examples/annual-unit-v1/summary.json)

본실험은 Python 3.12.14, 작업자 6개에서 521.831초가 걸렸다. 각 연도의 전체 경제를 결산하고 원장을 재생 검산하며 해시를 계산한다. 병렬화는 시드 단위로만 했다. 단계별 시간과 최대 메모리는 별도로 계측하지 않았다. 로컬 전체 테스트는 기존 454개와 신규 20개를 포함해 474개 모두 통과했다(214.106초).
