# 6.0B1 창고 이송, 원조와 주민 식사

국내 공공창고 사이의 이송을 허용한 B는 개발·검증 양쪽에서 국경 원조를 더 많이 보냈다. 200년 누적 미발송은 각각 79,263식과 91,998식 줄었다. 이 차이에는 승인 자체의 감소 52,593식과 68,084식이 포함된다. 같은 시기 세계의 실제 섭취량은 개발에서 12,670식 줄고 검증에서 65,864식 늘었다.

각 표본은 20개 초기 세계를 두 정책으로 각각 200년간 계산했다. A는 6.0A.1 F, B는 국내 공공창고 이송을 추가한 경로다. 표의 수량은 해당 시점까지 20개 세계의 누적 합이다. 인구는 그 연말의 합, Δ는 B−A다. 같은 시드의 장기 경로에서는 출생·사망·이주·재고·정책 승인이 이미 달라질 수 있다. [연간 자료 및 측정 정의](../examples/phase6b1/study/README.md) · [독립 집계 원장](../examples/phase6b1/depot-effects.json)

## 재고 부족 신호와 집행

A에서 **출발 창고 재고만** 미발송 사유로 기록한 방향·연도는 개발 646건, 검증 676건이었다. 각각 80,769식과 92,398식이 미발송이었다. 같은 시드·연도·공여국·수혜국 조합을 B에서 찾으면 미발송은 6,811식과 6,526식으로 줄었고, 실발송은 22,656→50,467식과 27,500→49,682식으로 늘었다. 승인량이 같았던 조합은 101/646과 83/676이고, B에서 승인이 아예 없었던 조합도 67건과 81건이었다. 실제 더 보낸 경우는 507건과 526건으로, 미발송량이 줄었던 639건과 672건보다 적다.

B 자체의 미발송 조합 가운데 사유가 재고뿐이었던 것은 개발 74건·2,878식, 검증 79건·3,352식이었다. 예산과 재고가 함께 기록된 조합은 746건·6,292식과 771건·6,088식, 예산·도로·재고 세 가지는 103건·2,115식과 111건·2,110식이었다. 이 집계는 한 방향의 모든 시도에서 수집한 사유를 조합별로 한 번만 센다. 여러 국경 후보에서 서로 다르게 막힌 경우도 포함한다.

국내 창고 계획에서도 목표와 실제 이송이 달랐다. B의 비상 원조 목표 처리 3,272건·3,332건 중 해당 요청 처리 중 화물이 전혀 이동하지 않은 횟수는 개발 2,607건, 검증 2,657건이었다. 이미 확보한 물량으로 충분한 요청도 이 횟수에 들어간다. 목표보다 적은 재고로 끝난 요청은 2,254건과 2,273건이었다. 국내 재고 목표의 미충족량은 같은 곳을 여러 목적으로 재검토할 수 있으므로 국가 간 원조 미발송량에 더하지 않는다.

## 공유 도로와 민간 거래

개발·검증 200년 B에서 국내 식량 이송은 비상 원조 준비 37,344·32,405, 다음 원조를 위한 사전 비축 5,206·7,111, 국내 구호·공사 비축 156,992·174,499식이었다. 일반 국내 비축 운임으로 추가 지출한 식량은 각각 23,101·25,778식이었다. 국내 주민에게 실제 지급한 구호 식량은 +12,395·+10,398식 증가했고 그 구호 배송의 국내 도로 점유는 148,980→21,756, 170,776→20,754로 감소했다. 구호 물자가 수요지 창고에 미리 있으면 현지 지급은 도로 용량을 쓰지 않는다.

장기 A/B에서 B의 신규 공공 점유가 있는 **같은 국내 도로·연도**만 골랐을 때 민간 구간점유 감소량이 그 공공 점유보다 컸던 횟수는 개발 543/6,015, 검증 476/6,135였다. 국가·연도는 370/3,289와 330/3,334, 세계·연도는 110/1,044와 113/1,062였다. 200년 전체를 한 시드에서 합치면 두 표본 모두 0/20이다. 검증 시드 35의 47년차에는 세계 민간 구간점유가 1,270→598이고 새 공공 점유는 6이었다. 양쪽의 연초 상태가 다른 장기 경로 사례다.

## 동일 연초에서 확인한 역효과

개발 시드 0~5의 B 경로에서 각 1~50년의 실제 연초 상태를 복사해 그해의 창고 이송만 보류하고 연말까지 계산했다. 300쌍 중 공공 이송이 실제 발생한 265쌍에서 세계 민간 **순배송** 감소가 새 공공 순배송보다 큰 경우는 1건이었다. 같은 단위를 도로 **구간점유**로 바꾸면 세계 전체는 0/265건, 국가 단위는 2/938건, 도로 단위는 4/1,743건이었다. 민간 **국제 거래량만**의 감소가 국내 공공 순배송보다 큰 세계·연도는 0/265건이다. [탐색 범위와 전체 결과](../examples/phase6b1/depot-fork-screen.json)

- **시드 2, 42년.** 공공 식량 40식이 지역 31→28→30으로 이동해 두 도로를 각각 40만큼 점유하고 운임 11식을 냈다. 별도로 18→16에 26식을 보내고 운임 3식을 냈다. 공공 순배송 합계는 66식이고 구간점유는 106이다. 민간 지역 31→28 배송은 보류 시 392식에서 허용 시 352식, 30→28은 423식에서 383식으로 줄었다. **민간 순배송은 80식 감소해 새 공공 순배송 66식보다 컸다.** 국경 원조 순입고는 44→83식으로 늘고 국내 구호 64식과 민간 국경 식량 거래 266식은 같았다. 지역 28의 주민은 9,550→9,470식을 먹었다. 이 지역의 80식 감소가 세계 섭취 감소의 전부였다. [양쪽 국내·국경 송장](../examples/phase6b1/depot-case-2-42.json)
- **시드 1, 5년.** 지역 2→0 창고 이송 8식이 도로 0–2를 썼다. 그 도로의 민간 화물은 282→268로 14식 줄었다. 직접 민간 배송 2→0의 267식은 같았고, 지역 3에서 2를 거쳐 0으로 가는 민간 배송이 15→1식으로 줄었다. 같은 도로의 구호 배송도 18→0식으로 바뀌었다. 세계 민간 구간점유 감소는 78, 공공 추가 점유는 320이었다. 지역 0의 섭취는 6,082→6,018식이었다. [연초 개입 원장 요약](../examples/phase6b1/depot-effects.json)

## 재현

```text
python -B -m experiments.depot_effects62 --case-only --case 2 42 --out examples/phase6b1/depot-case-2-42.json
python -B -m experiments.depot_effects62 --scan-only --out examples/phase6b1/depot-fork-screen.json
python -B -m unittest tests.test_depot_effects62 -v
```
