# 6.0C1-M1 부분 구현 · 평시 복무자의 등록 근무지

기준은 PR #18의 `0c2c2cb843ff530ee9cf5eaf740d221c3bfbae96`이다. 기존 6.0B2의 복무 명부에는 주소지별 인원과 한 해 안에 끝나는 타 지역 왕복 근무가 있다. 이번 추가 원장은 복무자 중 몇 명이 어느 지역 근무지에 **등록돼 있는지** 이월한다. 그곳에서 숙영했다는 자료는 없다. 국가 간 분쟁이나 협의 규칙은 이 PR의 변경 대상에서 제외했다.

## 완료 인정 조건

| 사용자 조건 | 이 PR에서 확인할 수 있는 범위 |
|---|---|
| 1. 지속 주둔을 위한 실제 병력 이동 | 미구현. 기존에 집행된 왕복 근무 영수증을 소속 등록의 근거로 참조한다. 새 편도 이동은 측정하지 않았다. |
| 2. 연말 주둔지의 다음 해 유지 | 등록 근무지 이월은 구현했다. 물리적인 연말 체류는 미검증이다. |
| 3. 도로·식량 부족으로 실제 배치 실패 | 미구현. 해당 주소지에서 새로 등록할 수 있는 사람이 부족해 등록 건수가 영수증 인원보다 적은 사례는 별도 관측이다. |
| 4. 주소지 인구와 기존 복무 명부 이중 집계 방지 | 구현. 모든 등록 인원은 기존 복무자의 부분집합이며 근무지 소속 변경은 주소지의 주민 수, 노동 배정, 식량 수요를 바꾸지 않는다. |
| 5. 새 주둔에 따른 운임·노동·창고 변화 | 미측정. 기존 경제의 집행 금액과 실물 출고를 보존하며 등록 근무지 원장은 추가 비용을 부과하지 않는다. |
| 6. 기능을 끈 PR #18 해시 | A는 PR #18의 공개 실행 함수를 호출한다. 기본 경제와 기존 선택형 외교 기록에 대한 실제 재생 결과를 아래에 기재한다. |

전략적 배치 C, 보급에 따른 병력 가용성, 위기 의사결정, 6.0C2 전투용 상태 인터페이스는 미구현이다. 새 원장만으로 실제 병력의 위치, 이동 실패량, 개인별 섭취량 또는 준비태세를 산출할 수 없다.

## 세 가지 비교 표기

| 표기 | 원래 경제와 복무 경로 | 새 연말 자료 |
|---|---|---|
| A | 6.0C1 PR #18 전체 진입점. 기본 경제는 6.0B2 D 자율 평시 복무·왕복이다. 이전 협의·서명 플래그도 그대로 전달된다. | 없음 |
| A_fixed | 6.0B2 C 고정 평시 복무·왕복 | 없음 |
| B | A_fixed와 같은 지도, 주민, 복무자, 왕복 영수증 및 실물 경제 | 주소지와 등록 근무지를 연결한 연말 명부 |

A_fixed를 추가한 이유는 자율·고정 모집의 차이를 소속 등록 효과와 구분하기 위해서다. B는 새로운 평시 정원, 주민, 개인 ID를 만들지 않는다. 어떤 주민이 개별적으로 어느 근무지에 배정됐는지는 알 수 없다.

## 계산과 검산

1. 매년 주소지별로 전년 기말 인원을 읽고 해제자를 차감한다. 새 복무자는 주소지 근무지에만 등록한다.
2. 그 해 기존 경제에서 실제 지급까지 끝난 고정 평시 복무의 국내 왕복 영수증을 기표 순서대로 읽는다. 각 영수증에서 새로 등록하는 수는 `min(영수증 인원, 주소지 근무지에 아직 남은 적격 인원)`이다. 같은 해에 같은 주소지의 적격 인원을 두 번 쓰지 않는다. 이미 타지 근무지에 등록한 인원은 다음 영수증이 발행돼도 기존 소속을 유지한다.
3. 영수증 연결만 보류하는 반사실에서는 선택한 한 건의 적격 인원을 그 해 다른 영수증으로 넘기지 않는다. 실제 왕복 이동과 그 비용은 두 경우 모두 동일한 원본 결산에 있다.
4. 주소지별 사망·이주·해제 총수는 기존 명부의 값이다. 각 차감 시점의 근무지별 인원 비율로 정수 배분한다. 따라서 타지 소속자에게 별도로 사망·이주를 추가하지 않는다.
5. 각 주소지에서 `모든 근무지의 기말 등록 합계 = 기존 기말 복무 인원 ≤ 기말 주민 수`를 검사한다. 각 주소지×근무지 행의 개시·유입·유출·기말 수량, 전년 기말과 금년 개시, 사망·이주의 주소지 합계를 각각 검산한다. 주민 식량 수요는 기존 주소지 인구와 대조한다. [명부 구현](../civsim/postings65.py) · [정책별 진입점](../civsim/posting_engine65.py)
