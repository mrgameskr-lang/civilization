# 지역 생산·토양 관리와 설비 효과의 범위

지역은 영토 타일 수와 경작 가능 농지 수를 따로 보유한다. 평년에도 농지 1타일이 지원하는 농민은 최대 20명이다. 개간 설비가 가동되면 1단위당 경작 인원 24명을 더할 수 있고, 지역 전체 추가 인원은 농지 타일당 4명 이하다. 영토·농지 타일 수 자체는 연간 생산에서 변하지 않는다. 광업은 해당 지역 지하의 실제 잔여 광석만 추출하고, 제조업은 해당 지역의 광석 재고와 당해 채굴분으로 도구를 만든다.

## 한 해에 지불하는 순서

1. 지역별 기초 설비의 유지비를 **그 설비가 있는 지역의 연초 재고**에서 낸다. 농업 장비, 광공업 설비, 개간지 순으로 가동 가능 수량을 정한다.
2. 토양 관리가 켜져 있고 농지가 있으며 기초 토양이 950‰ 미만인 지역은 정비 작업을 검토한다. 작업 1회는 도구 1개·광석 1개·노동 4인년으로 농지 최대 8타일을 처리한다. 자재·인원·농지로 가능한 회복량을 먼저 구하고, 같은 정수 회복량을 달성하는 최소 작업 수만 지불한다. 회복량이 0이면 작업하지 않는다.
3. 남은 인력과 재료로 3.0 고정 효과·단일 건설 정책을 지역별로 적용한다. 농업 도구 준비량과 후보 수확은 경작 가능한 농지로 산정한다. 설비 종류별 수량 상한은 영토 타일 수를 6으로 나눈 올림값이다. 양의 5년 순편익, 농업 도구 준비분, 건설 자재·인년, 상한을 모두 만족하는 한 후보가 선택된다. 산업 설비는 농지가 적은 지역에도 건설할 수 있다.
4. 기초 노동력은 인구의 절반을 내림한 값이다. 정비 노동과 건설 노동을 뺀 인원을 기존 노동 재배치 규칙으로 3개 부문에 배분한다. 생산에는 기초 토양이 쓰이며, 새 설비와 유상 토양 회복은 다음 해부터 효과를 낸다. [생산·거래 단위](economy.md) [설비 제조·유지·상각 비용](investment-rules.md)

## 설비 효과 비교

한 지역에서 유지비를 낸 농업 설비 한 단위는 수확 배율 12‰p, 광공업 설비는 채굴·제조 능력 25‰p의 배분 예산을 만든다.

- 지역 적용에서는 배율 증가분을 보유 지역에 적용한다.
- 국가 적용에서는 같은 국가의 증가분을 종류별로 합산한다. 농업은 농지가 있고 기초 노동력이 1명 이상인 지역, 광공업은 기초 노동력이 1명 이상인 지역에 균등 분배한다. 정수 나머지는 지역 ID가 작은 순서로 1‰p씩 나눈다. 수신 자격 지역이 없으면 그해 예산을 미사용으로 기록한다. 국가 간에는 분배하지 않는다.
- 두 방식 모두 개간 효과는 설비가 있는 농지에서만 발생한다. 생산량 차이는 배율을 적용받은 지역의 인원·생산성·작황·원료 여건에서 생긴다. 현물 도구·광석·설비나 노동자를 지역 간에 이전하는 회계 항목은 없다. 이 비교군의 국가 공유는 공법·장비 서비스의 가상 적용 범위를 나타낸다.

설비 후보 평가에는 두 방식 모두 지역 자체의 유상 설비 효과만 사용한다. 동일한 기초 상태라면 유지비, 건설, 장부 취득원가와 상각은 일치한다. 다음 해부터 기초 재고나 인구가 달라지면 실제 선택도 달라질 수 있다. 지역마다 연간 1건까지 계획하므로 기존 국가 집계 방식의 국가당 연간 1건과 계획 단위가 다르다.

## 토양 상태

농지가 있으면 자연 변화는 3.0의 `6 − floor(8 × 실제 경작 인원 / 경작 수용 인원)`‰p다. 농지가 없으면 토양을 그대로 보존한다. 자연 상태는 550~1,150‰ 범위다. 유상 회복은 `floor(8 × 처리 농지 / 전체 농지)`‰p, 한 해 최대 8‰p이며, 정비로 1,000‰를 초과할 수 없다. 구매한 자재와 지불한 인력은 해당 연도의 영농·광업·제조·건설에 쓸 수 없다.

원장에는 생산 단계의 기초·기말 재고, 기초·기말 코호트와 장부가, 실제 투입·산출, 토양 관리 물량, 유지비 납부 지역의 배율 예산, 국가 총예산과 실제 귀속 배율을 담는다. 독립 검사기는 원자재·기초 인력·토양과 호스트별 유상 설비로 단계별 재고, 수확·채굴·가공, 공유 범위와 차년도 토양을 재구성한다.
