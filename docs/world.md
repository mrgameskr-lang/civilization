# 세계 초기화와 환경

`generate_world(seed, width=48, height=32, nations=8)`가 0년의 세계를 만든다. 기본값으로 좌표 1,536개와 국가 8개를 생성한다. 좌표 (0, 0)은 왼쪽 위이며 타일은 행 우선 순서로 저장한다. 소유국 번호는 0부터 시작한다.

## 영토와 자원

직사각형을 긴 변의 43~57% 지점에서 두 구역으로 나눈다. 면적에 비례해 각 구역에 국가 수를 배정하고 국가 하나가 남을 때까지 반복한다. 타일 수가 적을 때도 모든 국가에 한 칸 이상 배정한다. 각 국가는 상하좌우로 연결된 영토를 가진다.

초기화에는 시드로 생성한 독립적인 Python `random.Random` 인스턴스를 사용한다. 아래 범위의 정수 추출은 양 끝을 포함한다. 비율을 적용한 수량의 소수 부분은 버린다. 같은 엔진과 Python 버전, 시드, 지도 크기, 국가 수를 사용하면 초기 상태를 재현할 수 있다.

| 국가별 초기값 | 계산 |
|---|---|
| 정적 비옥도 | 지역 기준값 650~1,400에 타일별 편차 −140~140을 더하고 영토 평균을 취한다. 1,000이 기준이다. |
| 광석 품위 | 지역 기준값 600~1,400에 타일별 편차 −250~250을 더하고 영토 평균을 취한다. |
| 채굴 가능 매장량 | 타일별 품위의 65~145%를 합한다. 타일에는 최초 매장량을, 국가에는 채굴 후 잔량을 보관한다. |
| 인구 | 영토 타일 수 × 국가별 인구밀도 42~57명 |
| 식량·광석·도구 초기 재고 | 인구에 각각 220~550‰, 15~45‰, 10~40‰ 적용 |
| 보유 화폐 | 인구 × 3,000~6,000‰ |
| 생산성·기술 | 각각 850~1,200‰ |
| 초기 토양 상태 | 850~1,100‰ |

## 강수 계수

전 지구의 16년 주기와 지역의 26년 주기를 더한다. 각 주기는 연도에 따라 부드럽게 오르내리는 삼각파다. 전 지구 위상은 시드가, 지역 위상은 시드와 국가 번호가 정한다. 반환값 범위는 800~1,200‰이며 농업 생산식에서 사용한다.

```text
wave(p, h) = 100 − floor(200 × abs((p mod (2h)) − h) / h)
rain(seed, year, id) = 1000 + wave(year + seed, 8)
                           + wave(year + 3 × seed + 5 × id, 13)
```

기후 주기와 지질 분포는 가상의 모형 계수다. 타일별 자연환경은 초기 영토 내 차이를 제공하며, 연간 생산·채굴 의사결정은 국가 평균과 합계를 사용한다.
