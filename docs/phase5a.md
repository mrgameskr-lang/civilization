# 5.0A 정부와 지역 경제

5.0A 정부의 자산은 자국 각 지역 창고에 있는 식량·광석·도구다. 국가의 기존 `countries[].opening/closing.stock`은 지역 민간 재고의 합이다. 같은 연도의 `government.accounts[].public_close`는 정부 소유분, `combined_close`는 주민과 정부가 보유한 전체 실물이다. 국가 합계를 여러 단계에 다시 더하면 동일한 창고를 두 번 세게 된다. 국제 매매대금은 예전과 같이 거래 지역 사이에서만 이동한다.

## 한 해의 의사결정과 집행

1. 지난해 지역별 미섭취 식량, 수확, 소요, 인구·토양 변화, 간선 사용량과 올해 기초 민간·공공 보유량에서 후보를 만든다. 3년 편익을 보는 도로·토양 사업과 단기 구호·예비 비축을 고정 평가단위로 채점한다. 시드에서 오는 기후는 기존 생산 과정에만 쓰인다. [평가 수식과 동점 처리](fiscal-policy5.md)
2. 기존 개량의 유지부터 시도한 뒤 승인된 공사를 집행한다. 도로 자재는 한쪽 창고에서 반대쪽 현장으로 두 품목을 실제 배송한다. 토양 보전에는 현지 자재와 인력이 필요하다. 다음 해 도로 용량과 올해 토양 기초 상태에 각각 반영한다. [비용·감가·행정 한도](public-works5.md)
3. 지역의 민간 가용 노동은 `인구//2 − 현지 공공 작업 인원`이다. 기존의 민간 설비 가동·토양 관리·농업·광업·제조업·국경 무역을 이 가용 노동 및 실제 재고에 적용한다. 정부가 민간의 임금이나 가계 소득을 추정하지 않는다.
4. 국경 매매가 끝나면 보호 재고와 창고 공간을 확인하여 지역 민간 계정에서 같은 지역 정부 창고로 현물을 이체한다. 비상 비축의 추가 취급 손실을 따로 차감한다. 구호는 현지 우선으로 배분하고 원거리 물량은 국경을 넘지 않는 경로로 보낸다. 같은 간선에서 공사, 구호, 민간 화물이 차례로 잔여 용량을 사용한다.
5. 지역 소비, 민간 저장 손실, 출생·사망·이주를 4.0으로 계산한다. 정부 창고에는 남은 식량의 `1/12`(내림)을 보관 손실로 기표한다. 모든 단계의 감사가 성공하면 한 해를 게시한다. 각 실행의 시작 정부 재고와 도로 개량은 0이다.

## 독립 검산식

각 식은 재화별 정수이며 국내 수송의 운임은 식량이다. `구호 지급`은 수송·보관 중 소모를 제외하고 주민이 실제로 받은 양이다.

| 계정 | 기말을 재구성하는 기초 잔액의 변화 |
|---|---|
| 지역 민간 | 생산 − 민간 투입 − 소비·부패 + 국경 순수입 − 국경 운임 − 징수 + 구호 수령 + 민간 국내 순반입 − 국내 운임 |
| 지역 창고 | − 현장에서 사용할 재료의 출고 − 공사 운임 + 징수 − 취급 손실 − 구호 출고 − 구호 운임 − 보관 손실 |
| 통합 국가 | 생산 − 민간 투입 − 소비·민간 부패 + 국경 순수입 − 국경·국내·공공 운임 − 공공사업 재료 − 취급·공공 보관 손실 |
| 지역 현금 | 해당 지역의 국경 수출 대금 − 수입 대금. 세계 순증은 0 |
| 간선 | 기초 유효 용량 = 공사 화물 + 구호 화물 + 민간 화물 + 미사용 용량. 다음 해 용량 = 기본 용량 + 48 × (유지 성공분 + 신설분) |
| 노동·인구 | 공공 노동 + 민간 토양 노동 + 건설 노동 + 산업 배정 노동 = 기초 인구//2. 기말 인구 = 기초 인구 + 출생 − 사망 + 순이주 |

도로 공사는 운송장과 현장 소비를 같은 작업 번호로 연결한다. 원장 감사는 지도에서 구간 거리와 식량 운임, 출발지 재고, 도착지 사용량, 용량을 대조한다. 통합 국가 검산에서는 세금·국내 구호를 다시 비용이나 수입으로 기표하지 않는다. 수식과 실행 코드는 [연간 엔진](../civsim/government.py), [독립 회계](../civsim/government_audit.py), [현물 정책](../civsim/fiscal_policy.py), [공공 집행](../civsim/public_works.py)에 있다.

## 실행

저장소 루트에서 Python 3.11 이상으로 실행한다. `government`의 기본 정책은 `integrated`이며 `none`, `relief`, `infrastructure`도 선택할 수 있다. 4.0은 여전히 `regional`, 이전 버전은 `run`으로 실행한다.

```sh
python -m civsim government --seed 7 --years 50 --policy integrated --out runs/5a-integrated-7
python -m civsim verify runs/5a-integrated-7
python -m civsim analyze runs/5a-integrated-7 --csv runs/5a-regions-7.csv
```

`manifest.json`은 정책·버전·시드를, `world.json`은 연도 0의 지도·민간·정부 상태를, `years.jsonl`은 모든 연도별 승인·거절 후보, 세금 영수증, 출고·운송·공사·부패와 기초·기말 원장을 저장한다. `verify`는 독립 경로에 세계를 재생성해 기초와 연간 원장의 정규 JSON 바이트를 대조한다. 실험 실행은 상세 원장을 스트리밍하여 각 시점까지 누적 SHA-256과 분석 표를 보존한다.
