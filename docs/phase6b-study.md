# 6.0B 비교 실험 계획

기준 경로는 6.0A.1 F다. 여기서 원조국의 연간 허용 지출에는 선적 식량과 실제 국경 운임을 합한다. 기존 개발·검증 각 20세계의 200년 자료에서 원조 승인 후 남은 미발송은 각각 91,210·104,426식이었다. 시도한 경로들에서 출발 창고 재고만 제약 사유였던 경우 미발송량이 각각 80,769·92,398식이었다. 예산만 풀었을 때 그 순간 더 보낼 수 있었던 양은 국경 시도 기준 5,054·5,042식이었다. 다른 경로로 재시도할 수 있다. 공여국의 남는 자원, 국내 이동권한, 물리 경로, 실제 운임을 적용해야 이 중 국내 창고 이송으로 충족할 수 있는 양을 추정할 수 있다. ## 사전 비교

개발 시드 0~19와 독립 검증 시드 20~39에서 48×32 지도, 8개국·32개 지역을 사용한다. 한 세계를 200년 연속 계산하며 같은 경로의 50·100·200년을 측정한다. 각 단계의 정책·계수·측정법을 독립 검증 표본의 새 결과를 열기 전에 고정한다. B1은 기준 A와 공공창고 이송을 허용하는 B, B2는 B와 같은 물류 위에서 고정 복무 C와 연초 관측에 반응하는 복무 D를 실행한다. B2는 동일 시드·연도의 보관된 A/B 결과를 검산한 뒤 읽는다.

- 주 비교는 B−A(창고 이송), C−B(고정 복무 도입), D−C(규모 선택 규칙)다. D−B, C−A, D−A도 같은 시드에서 계산한다.
- 우선 측정값은 국경 원조의 승인·실제 선적·순입고·불이행, 당해 운임을 포함한 예산 잔액, 현지 주민의 실제 섭취와 세계·국가·지역의 식량 부족, 200년 말 인구다. 국내 재배치가 공공창고 사이에서 일어난 경우, 국경을 넘기 전에는 수혜국 원조로 세지 않는다.
- 정수 누계·기말값은 시드 안에서 차감한다. 비율은 시드별 분자·분모로 먼저 계산한다. 표본의 합산 부족률은 필요량 합이 분모다. 지급·운반·수령·먹은 양을 구분한다. 서로 다른 장기 경로의 급식 차이와 같은 연초의 단년 개입은 따로 보고한다.
- 노동은 기초 주민, 출생·사망·이동, 출신지, 실제 복무와 생산 투입을 구분한다. 국경 긴장·협정 지표는 연도/국가쌍 단위로, 정치 지지·불만은 실제 구성원 수로 가중한다.
- 평균과 함께 시드별 악화·동일·개선 수, 실제 이송·입고가 없던 경우, 공유 도로 점유 및 비용이 다른 물자나 식사를 줄인 반례를 보고한다. 선정한 단일 사례를 모집단 효과로 해석하지 않는다.

매 경로에서 연간 원장 전체의 누적 SHA-256과 초기 상태 해시를 저장한다. A의 초기 경제·정치 상태와 원장 해시를 6.0A.1 F 120개 체크포인트에 대조한다. 새 프로세스·디렉터리에서 전부 재실행하여 각 시드의 해시와 과학 파일 전체 바이트를 비교한다. 기존 세계 및 연구 파일은 각 단계의 입력으로만 사용한다.
