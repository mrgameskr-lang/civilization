# 6.0A.1 원조 예산과 기능별 효과의 실험 계획

기준은 PR #12의 `d12d0fe`다. 48×32 타일, 8개국, 32개 지역, 개발 시드 0~19와 독립 검증 시드 20~39를 사용한다. 각 시드의 같은 연초 세계를 여섯 번 생성해 200년까지 연속 실행하고 50·100·200년을 기록한다. 별도 프로세스에서 여섯 처리군을 모두 반복한다. 이전 모델 소스와 예제 전체를 보존한다.

| 군 | 공통 무역 협정에 추가하는 정책 |
|---|---|
| A | 6.0A C 원본 |
| B | 국제 원조. 기존 최단거리 운임을 이용한 제안 |
| C | 방향별 수출 제한 |
| D | 방향별 출국·입국 제한 |
| E | 세 수단 모두. 6.0A D 원본 |
| F | E 및 송장별 **발송 식량 + 실제 운임**의 국가·연도 총지출 상한 |

원조·제한·협정의 동기와 후보 조건, 연초에 쓸 정보, 식량→광석→도구 매칭 순서, 연간 물리경제 규칙은 6.0A를 따른다. 기능을 끄면 해당 행동·제안·거절·의무가 발생하지 않는다. 이후 결과는 각 세계가 자기 과거에서 관측한다. F의 Q는 공여국 연초 계획 예산이며 양국이 합의한 물량 상한도 지킨다. 각 국경도로에서 실제 거리를 d, 아직 쓰지 않은 예산을 R이라 하면 `q + ceil(q*d/100) <= R`인 최대 q는 `floor(100*R/(100+d))`이다. 실물 재고·수송 용량·수혜 창고·최소 출고량도 적용한다. 송장마다 실제 운임을 올림한다. 같은 공여국의 다음 도로와 다음 상대국은 남은 R만 쓴다.

6.0A C/D의 보관된 초기·연간 해시와 A/E를 직접 대조한다. 새 규칙에서 원조 출고·순입고·운임·취급 손실, 민간·공공 장부, 세계 현금, 인구 및 양방향 국경 용량을 재검산한다. 정수 예산을 줄이거나 거리·재고·수혜 창고를 달리하는 회귀 사례는 결과 개선 여부와 독립적으로 평가한다.

각 지표 Y에 대해 원조·수출 제한·이주 제한 단독 효과는 B−A, C−A, D−A다. 같은 시드의 결합 효과 E−A와 세 단독 효과 합의 차이를 상호작용 잔차로 보고한다. F−E는 예산 상한의 효과다. 두 요소만 적용하는 세 처리는 실험하지 않으므로 잔차를 특정 두 요소의 상호작용으로 배분할 수 없다. 비율은 시드 안의 누적 부족/누적 수요로 먼저 계산해 짝비교하며, 표본의 합산 비율을 사용할 때는 따로 표시한다. 증가·동일·감소 및 반례를 모두 기록한다.

국제 원조의 순입고·국내 배급·주민 실제 섭취를 각각 관측한다. 원조를 실제 운송한 해는 같은 연초 정책과 생산을 고정하고 그해 국제 원조 송장 전체만 없앤 뒤 민간 국경 거래부터 국내 소비까지 재정산한다. 실제 입고 지역의 섭취 차이, 다른 지역의 파급, 세계 합을 기록한다. 이 단년 측정에 장기 인구 경로 효과를 합산해 해석하지 않는다. 단일 약속의 수혜·공여 사례로 이슈 #13의 시드 0 4년차 국가 2→3을 고정하고, 같은 연초의 상한 적용과 해당 원조만 보류한 결과를 대조한다. 다른 국가의 승인·정책은 그대로 둔다. 추가 사례는 개발 시드에서만 선정한다.
