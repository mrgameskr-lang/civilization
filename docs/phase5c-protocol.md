# 5.0C 비교 계획

기준은 PR #9 커밋 `b7c2aaa`이며 집단 인원은 5.0B와 같이 실제 연간 생산 노동 및 나머지 지역 주민으로 산출한다. 정치·경제 모델 계수는 독립 검증 시드에서 신규 정치 경로를 실행하기 전에 고정한다.

| 처리군 | 선호 규칙 | 정부의 선택 | 상시 현물세 |
|---|---|---|---|
| A | 기존 5.0B | 기존 정치 피드백 | 5.0A 고정 |
| B | 경제 상태별로 분화 | 기존 정치 피드백 | 동일 |
| C | 분화 | 4년 임기 대표 선거와 집권 세력의 우선순위 | 동일 |
| D | 분화 | C + 한도 안의 음의 경제 순편익 사업 허용 | 동일 |
| E | 분화 | C와 같은 정책 재량 | 집권 강령별 세율 |

- 개발 시드 0~19와 독립 검증 20~39의 200년 경로를 각각 실행한다. 50·100년은 동일 경로의 중간 시점이다. 일차 비교는 같은 시드의 B−A(선호), C−B(경쟁), D−C(재량), E−C(세율)다. A의 경쟁 장부를 제외한 연간 기록을 5.0B 반영군 보관 해시에 대조한다. 초기 경제·정치·내각 상태는 모든 군에서 같다.
- 기존 개발 원장에서 공통 부족 신호와 집단 고유 신호의 경쟁을 먼저 진단한다. 같은 경제 관측의 선호 비교와 서로의 경제 상태가 달라질 수 있는 장기 궤적 비교를 구분한다. 구호 요구 비중, 집단별 요구 분포, 같은 지역 내 집단 사이의 선호 불일치와 분모를 보고한다.
- 각 세력의 지지·참여는 지역 집계 점수다. 최초 내각은 과도 내각이며 첫 집권, 연임, 서로 다른 당선 세력 간 교체를 나눈다. 선거 때의 교체 횟수, 집권 기간, 관찰 종료 때 진행 중인 임기, 교체가 없는 국가와 가장 긴 집권, 실제 승인과 집행을 측정한다.
- 인구·식량 부족률·지역 배급 격차·재정·세금·실제 사업의 비용을 지지와 별개로 측정한다. 재량은 후보의 원래 경제 점수를 그대로 기록하고, 물리 제약과 예산을 집행 때 다시 검사한다. 세율 효과는 E와 C의 장기 차이에 더해 같은 연초에서 세율만 바꿔 민간 부담·정부 수납을 대조한다.
- 실제 교체가 있었던 개발 시드의 연초 상태를 복제하여 당선 내각과 현직 유지의 승인·집행을 비교한다. 이 한 해의 개입은 장기 세계의 평균 효과 추정과 구별한다. 피해와 개선, 연임과 교체의 빈도는 실현된 그대로 기록한다.
