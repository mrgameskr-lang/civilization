# 3.0 자본 모형의 500년 인구와 자원 제약

개발 시드 0~19에서 세계 평균 인구는 50년 말 128,307명, 200년 말 93,853명, 500년 말 78,661명이었다. 20개 세계 모두 50년 이후 처음으로 5년 연속 인구 증가가 멈춘 시점에 8개국 전체가 채굴 가능한 광맥을 보유했다. 51년부터 토양의 연간 순손실을 막으면 200년 인구가 기준보다 평균 41,235명 많아졌다. 별도로 광맥을 추가하면 생산된 광석은 늘었지만 200년까지 각 세계의 연간 식량 생산량과 부족량은 모두 기준과 일치했다.

## 기간별 상태

기존 PR #4의 3.0 자본 정책, 농업 유휴 인력 재배치, 식량→광석→도구 결제 순서를 고정했다. 아래 인구·출생·사망은 20개 세계의 산술평균이다. 부족률은 해당 연도 20개 세계의 부족량 합을 필요량 합으로 나눈 값이다. 토양은 타일 면적으로 가중했다. 광산 가동률은 실제 채굴량 합을 노동·설비 기준 채굴 능력 합으로 나눈 값이다.

세계당 평균 경작 인원은 50년 30,386명에서 200년 28,535명, 500년 26,977명으로 줄었다. 같은 시점의 평균 연간 식량 생산량은 115,424, 82,040, 70,059였다. 사용 가능한 설치 설비의 유지비는 이 일곱 연도에 모두 지급됐다. 500년에도 연간 출생·사망 관계는 기후·재고와 함께 바뀐다. 300년부터 400년까지는 평균 인구가 소폭 증가했다. 이 관측 기간으로 무한 시간의 평형 인구를 확정할 수 없다.

## 출생·사망 임계값과 전환 연도

연초 인구를 `P`, 먹지 못한 식량을 `S`라 두면 한 국가의 자연증가는 다음과 같다. 인구가 양수일 때 내림 전 사망이 출생을 앞서는 경계는 `138S > 16P`, 즉 부족률이 **8/69 ≈ 11.5942%**를 초과할 때다.

```text
출생 = floor(28 × (P − S) / 1000)
사망 = floor((12P + 110S) / 1000)
연말 인구 − 연초 인구 = 출생 − 사망 + 순이동
```

실제 비교에는 두 정수 카운트를 사용한다. 51~500년의 72,000개 국가·연도 중 99건은 연속식의 사망 우위가 내림 후 동률이 됐다. 시드 0 세린의 163년에는 21,052명 중 2,443명분이 부족했고 출생·사망이 각각 521명이었다. 세계의 출생·사망은 각국에서 먼저 내림한 뒤 합산한다. 세계 단위 연속식과 실제 사망·출생의 방향이 정반대인 경우도 9,000개 세계·연도 중 4건 있었다. 국제 이동은 세계 전체에서 상쇄된다. 한 국가에서는 출생이 사망보다 많아도 순유출로 인구가 줄 수 있었고, 실제로 2,258개 국가·연도가 여기에 해당했다.

성장은 연말 인구가 연초보다 큰 해, 비성장은 같거나 작은 해로 정의했다. 같은 상태가 5년 연속이어야 국면을 확정한다. 시작 연도와 4년 뒤의 확인 연도를 둘 다 기록했다. 50년 말에는 20개 세계 중 15개가 마지막으로 성장 국면을 확정한 상태였고, 국가별로는 160개국 중 93개였다. 이미 비성장이던 경우에도 한 번 성장으로 복귀한 뒤 발생한 다음 전환을 집계했다.

| 51년 이후 최초 조건 | 세계 20개 최소 / 중앙 / 최대 | 국가 160개 최소 / 중앙 / 최대 |
|---|---|---|
| 사망 > 출생 | 51 / 54 / 60년 | 51 / 52.5 / 72년 |
| 5년 지속 성장→비성장 국면의 시작 | 51 / 59 / 66년 | 51 / 61 / 94년 |
| 5년 지속 비성장→성장 국면의 시작 | 51 / 61 / 76년 | 51 / 66 / 130년 |

시드 순서 0~19에서 세계의 첫 성장→비성장 시작 연도는 `60, 59, 58, 57, 55, 54, 54, 52, 52, 66, 51, 65, 63, 62, 61, 61, 60, 60, 59, 57`이다. 더 긴 구간으로 보면 세계 인구가 20년 전 이하로 내려간 첫 관측 연도는 57~82년(중앙 67년), 30년 전 이하인 첫 관측 연도는 68~88년(중앙 78년)이었다. 각 국가·시드의 최초 조건과 반복된 국면 전환은 별도 파일에서 조회할 수 있다. ## 51년부터의 단일 처치

시드마다 같은 50년 말의 인구, 재고, 토양, 미채굴 광석, 현금, 자본 연령구조를 복제했다. 세 개의 분기 각각에 한 가지 조건을 적용해 200년까지 계산했다. 시드별 대조군 대비 차이를 먼저 구한 다음 시드별 차이에 같은 가중치를 주었다. 표의 부족률은 `Σ(51~200년 부족량) / Σ(같은 기간 필요량)`의 변화다.

| 처치 | 시행·원장 규칙 | 200년 인구 평균 차이 | 개선 / 동일 / 악화 시드 | 기간 부족률 평균 차이 |
|---|---|---:|---:|---:|
| 토양 순손실 방지 | 각 해 수확·침식 계산 뒤 연초 토양보다 내려간 양만 보충한다. 자연 회복은 허용한다. 다음 해부터 수확에 영향을 준다. | +41,234.5명 | 20 / 0 / 0 | −1.723%p |
| 유한 심부 광맥 | 51년 채굴 전에 각국 초기 매장량과 같은 양을 한 번 추가한다. 이후 채굴 때마다 차감한다. | 0명 | 0 / 20 / 0 | 0%p |
| 현금 재분배 | 매년 연초 각국 현금의 20%를 정수 내림해 모으고 연초 인구 비례로 반환한다. 나머지는 분수 몫이 큰 국가, 동률이면 낮은 국가 번호 순으로 배정한다. | −1,074.75명 | 4 / 8 / 8 | +0.040%p |

**토양.** 첫 지속 비성장 시작 연도에 160개국 중 155개국의 토양이 50년보다 낮았다. 세계별 최초 광맥 고갈은 90~180년으로, 해당 세계의 첫 5년 비성장보다 모두 늦었다. 시드 6의 52년에는 토양 처치로 식량 생산이 123,687→123,947, 부족량이 11,220→11,032로 바뀌었고 양쪽 모두 식량 수입은 0이었다. 200년 인구 효과 범위는 +34,834~+45,158명이었다. 인구 증가로 분모가 커져, 누적 부족량의 절대 단위는 오히려 20개 시드 모두 증가했다(평균 +38,919명분). 시드 9의 부족률은 12.527%→11.152%였으나 누적 부족량은 2,357,827→2,429,423이었다. 토양 보충에는 비용을 부과하지 않았으므로 실제 개간·비료 정책의 비용 대비 효과로 읽을 수 없다.

**광맥.** 심부 광맥 개방은 51~200년 세계당 누적 채굴량을 평균 242,797단위 증가시켰다. 같은 시드·같은 연도의 식량 생산·섭취 필요량·부족량은 3,000개 세계·연도에서 모두 동일했다. 시드 6의 200년에는 당해 채굴량이 2,618→5,875로 늘었고 도구 생산량은 양쪽 1,134, 수확량은 양쪽 84,696이었다. 이 경로에서는 광석을 추가해도 도구 목표 재고, 설비, 경작 노동력 등의 다른 제약이 남았다. 200년 이후 심부 광맥 처치는 실행하지 않았다.

**구매력과 시장.** 기준군 51~500년의 9,000개 세계·연도 중 8,682개에서 국가 간 식량 거래량은 0이었다. 현금이 재배분돼도 수출국에는 목표 비축량을 초과하는 식량이 있어야 한다. 시드 18에서는 51년 수확이 양쪽 모두 120,293이었지만 식량 수입이 0→9,168로 늘어 부족량이 7,569→1,567로 줄었다. 200년 인구는 97,929→100,018이었다. 반대로 시드 6에서는 52년에 부족량이 먼저 11,220→11,041로 개선됐으나, 51~200년 누적 출생이 3,640명 늘 때 누적 사망은 8,480명 늘었다. 최종 인구는 102,298→97,458, 최다 보유국의 현금 점유율은 69.0%→18.1%, 누적 식량 수입은 2,863→119였다. 식량 구매·연말 재고가 다음 해의 노동 배분과 인구 수요를 함께 바꾼다. 세 처치는 각자의 총효과를 측정한다. 토양 보충과 재분배를 동시에 시행했을 때의 추가 효과는 이 설계로 추정하지 않았다.

## 원자료와 재실행

- [국가·연도 패널](../examples/phase31/stability/country_year.csv.gz)은 기준군 80,000행과 처치군 72,000행이다. 인구·출생·사망·순이동, 식량 생산·섭취·부족과 비축, 토양·기후·경작 인원, 광맥·채굴 가동률, 설치·가동 설비, 각 재화 수출입과 현금 결제를 담았다. `deposit_before_policy`, `deposit_added`, `cash_before_policy`, `cash_transfer`, `soil_model_close`, `soil_restored`로 실험 처치를 역추적할 수 있다.
- [세계·연도 패널](../examples/phase31/stability/world_year.csv.gz)은 19,000행이다. 세계 수입과 세계 수출은 같은 거래의 양면이다. 두 수치를 합하면 거래량이 중복 집계된다. 비율 열은 소수점 8자리까지 쓰며 분모가 0이면 비워 둔다.
- [기간별 상태](../examples/phase31/stability/checkpoints.csv)는 320행, [시드 내 처치 효과](../examples/phase31/stability/paired.csv)는 180행이다. `since_51_`은 51년부터 해당 연도까지의 누적치다. 전환 파일의 국가 번호 `world`는 세계 합계를 가리킨다.
- [기존 3.0과 대조한 해시](../examples/phase31/stability/prefix_hashes.csv) 40건은 20개 시드의 50년·200년 전체 정규화 연간 원장 기준이다. [매니페스트](../examples/phase31/stability/manifest.json)에는 결과 파일별 SHA-256과 실행 환경이 있다.

저장소 루트 `outputs/civilization`에서 CPython 3.12.14로 다음 명령을 실행했다. 원본 실험은 `examples/phase31/stability`, 독립 전체 재실행은 별도 작업 디렉터리에 저장했다. 결과 디렉터리는 새 경로여야 한다.

```sh
python -B -m unittest tests.test_stability31 -v
python -B -m experiments.stability31 --seeds 20 --baseline-years 500 --treatment-years 200 --out examples/phase31/stability
python -B -m experiments.stability31 --seeds 20 --baseline-years 500 --treatment-years 200 --out ../../work/stability31-replay-01
```

실제 검증에서 전용 테스트 3개가 통과했다. 전체 규모 재실행은 65.30초(벽시계)였고, 압축 파일·매니페스트를 포함한 8개 결과 파일의 바이트가 전부 같았다. 국가 패널 SHA-256은 `d2c1dd4273581e617d911ec173c0cd7869dbcb637186ebdb02ea0b7fd6df0516`이다. 개발 시드는 0~19로 고정했다. 3.1 투자 후보의 미사용 시드 평가는 별도 실험이다.
