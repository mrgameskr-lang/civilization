# 5.0D 비교 계획

기준은 PR #10의 `c220dc5`이다. 5.0C C군의 고정 현물세·대표 선거와 같은 초기 세계에서 집단행동과 정부 대응을 함께 켠 경로를 비교한다. 각 시드 0~19(개발), 20~39(독립 검증)를 200년 연속 실행해 50·100·200년 상태를 저장한다. 두 군과 독립 반복의 원장 해시, 기존 5.0C C군과 기능 해제 경로의 해시를 확인한다. 새 정치 계수는 독립 검증군의 새 경로를 열기 전에 고정한다.

집단은 전년의 관측 인원, 실제 노동·과세·식량 상태, 지지·불만, 같은 요구의 지속성과 이미 진행 중인 행동을 사용한다. 최초 청원 뒤에만 후속 행동이 가능하다. 납부할 현물이 있는 집단, 생산에 참여했던 집단 등의 요건을 따로 둔다. 금년 집행으로 처음 드러난 사실은 다음 연초 판단에 사용한다. 피로·정책 수용·요구 변화에 따른 종료가 가능하다. 정부는 접수에 행정 능력을 배분하고, 승인 가능한 재정 사업과 현물세 범위에서 대응한다. 선언만으로 수용이나 지지를 발생시키지 않는다.

집단행동의 시작·기간·참여인년·사전 조건·노동력 차감·법정 감면·미납·실제 정부 입고를 구분한다. 지지 변화와 정책 전환의 장기 동행은 관측 통계로 취급한다. 개발 표본의 같은 연초에서 활동 중인 한 집단의 행동만 억제해 실제 승인·생산·세금·부족의 단년 차이를 계산한다. 대응을 포함한 그 연도 총효과다. 국가별 경제, 선거·집권 기간, 무행동 세계 수, 개선·악화 시드를 보고한다.

별도 진단에서는 보관 C군의 실제 경제·정치 관측을 고정하고 임기 2/4/8년, 의석 5/21/101석, 상호부조 강령의 비축·도로 가중치 교환, 현직 성과 항 제거를 한 요인씩 비교한다. 각 대안의 직전 집권자는 그 대안의 선거 결과로 이어 간다. 5.0D 경제에 이 선거 변형을 동시에 적용하지 않는다. 상호부조의 참여점, 정권 교체와 승인 변화, 무참여 선거를 실제 분모·선거 상태와 대조한다.
