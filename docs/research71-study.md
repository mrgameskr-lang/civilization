# 농법 습득과 정체 비교

먼저 시드 0, 지역 28의 같은 5년차 연초에서 두 번째 시험을 집행하거나 한 해 보류했다. 시험 경로는 5년에 식량 15단위를 덜 거두고 6년에 196단위를 더 거뒀다. 6년의 실제 투입을 고정해 계산한 농법 효과는 211단위였다. 이 검산을 통과한 뒤 장기 실험을 시작했다. [농법 규칙과 단년 대조](research71.md) · [양쪽 경로의 공사·창고 영수증과 원장 해시](../studies/research71/smoke.json)

## 장기 실험 사양

개발 시드는 0~19, 독립 검증 시드는 20~39다. 각 시드에서 같은 세계를 두 번 생성하고, 연초의 전체 경제 상태 해시가 같은지 검사한다. 두 경로 모두 기존 7.0 연대기 연구와 같이 2년차부터 공공 경작·긴급 구호를 사용한다. 이동 명령은 없다. 연구 경로에서는 1년차에 농법 선택지를 활성화한다. 정책이 활성화된 이후의 개별 사업 선택은 각 정부가 수행한다.

모든 경로를 200년까지 이어서 계산하며 50·100·200년의 국가별 값을 저장한다. 장기 선택 효과는 같은 시드의 연구 경로 값에서 기존 경로 값을 뺀 값이다. 식량 부족률은 각 세계 안에서 누적 미충족량을 누적 필요량으로 나눈 뒤 경로 간 차이를 계산한다. 표본 평균에서는 각 세계에 같은 가중치를 준다.

빠른 사례는 검증 세계에서 처음으로 기술을 습득한 국가다. 동률이면 시드와 국가 번호 순으로 선택한다. 정체 사례는 200년까지 어느 지역도 습득하지 못한 검증 국가 가운데 실제 시험 횟수가 가장 많은 국가다. 모든 국가가 한 번 이상 습득했다면 가장 늦은 첫 습득 사례를 표시한다. 사례 선정에는 인구 증감이나 정책의 성공 여부를 사용하지 않는다.

```console
python -m experiments.research71 smoke --out runs/research71/smoke.json
python -m experiments.research71 study --workers 8 --out runs/research71/long
python -m civsim chronicle studies/research71/long/saves/seed-20.json --format json
```

원자료에는 국가별 기말 인구, 대표 집단의 구성원으로 가중한 정치 지지의 분자·분모, 집권 정파와 누적 정권 교체, 기술을 보유한 지역 수, 연구 투입과 각 보류 사유의 지역·연도 수가 있다. 생산·필요·부족·비용은 누적값이며 `annual_food`는 해당 연도 수확이다. 시험용 노동·물자는 기존 토양 사업의 지출 중 시험에 할당한 몫이다. 전체 공사비와 더하면 중복된다.

사례의 `chronicles.events_by_kind`에는 사건의 주 국가(`country`)로 기재된 경우를 센다. 양자 협정의 상대국(`counterparty`)으로만 등장하는 사건도 보려면 해당 시드 저장을 연대기로 열어 양쪽 국가 필드를 확인한다. 농법 습득에는 상대국이 없다.

## 실행 및 한계

Windows의 Python 3.12.14에서 `python -m experiments.research71 smoke --out studies/research71/smoke.json`을 먼저 실행했다. 이후 `python -m experiments.research71 study --out studies/research71/long --workers 8`이 750.205초 만에 종료 코드 0으로 마쳤다. 개발·검증 본 실행은 16,000세계·년이다. 연구 시드 0·20은 추가로 각 200년을 새로 재생해 매년 원장 해시, 최종 경제 상태와 연대기를 확인했다. 기존 경로의 시드 0·20은 PR #28에 저장된 400개 연간 해시와 연대기 전체가 일치했다. [실행 기록](../studies/research71/long/execution.json) · [80개 경로의 상태·원장·연대기 해시](../studies/research71/long/trajectories.json)

별도 검산기 `python -m experiments.check_research71 studies/research71/long`는 40개 세계의 초기 지도와 소유권을 다시 생성한다. 각국의 50·100·200년 장부 총 1,920행, 습득 443건의 해시·연도, 지급한 노동·광석·도구, 두 사례표를 원자료와 대조한다. 연구 시드 0·20은 공개 연대기 명령에서도 각각 200년 전체를 재생해 최종 연대기 해시까지 대조했다. 사례를 작성할 때는 시드 22·37도 200년씩 추가 재생해 시험을 실제 집행한 연도와 내각을 확인했다. [회계 검산](../studies/research71/accounting-check.json) · [기존 연대기 호환성](../studies/research71/chronicle-compatibility.json)

이 비교는 하나의 작물 생산 기술과 하나의 재정·구호 정책 조합을 200년간 관측한 결과다. `project_unfunded`로 기록된 연구 후보의 집행 실패는 이 표본에서 발생하지 않았으며, 해당 조건은 별도 단위 테스트로 검증했다. 기초 기술 계수 자체의 상승, 기술의 국가 전체 확산, 다른 재정 정책에서의 성과는 검증 대상 밖이다.
