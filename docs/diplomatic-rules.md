# 6.0A 국가 간 협정, 원조와 국경 정책

두 나라는 작년까지 확인한 수출입·식량 부족·국내 정치와 올해 초 창고를 보고 각각 결정한다. 행동이 실제 재화나 인구를 얼마나 움직였는지는 연말 영수증으로 확정한다. 국가 8개이면 매년 28쌍과 56개 방향을 기록한다. A는 5.0D를 그대로 실행하고, B는 관측만, C는 관측과 무역 협정, D는 여기에 식량 원조와 이동·교역 제한까지 적용한다.

## 결정에 사용할 수 있는 정보

국가의 인구·현금·민간 재고·공공 창고는 연초 지역 원장의 합이다. 전년 식량 수요와 미충족량, 농업 생산, 집단별 지지·불만·요구 신호는 직전 정치 관측에서 읽는다. 집단별 국가 평균은 그 집단에 속하는 실제 인원으로 가중한다. 첫해의 이전 기근·무역·이주 실적은 0이다. 전년 인구 변화는 현 연초 인구에서 전년 식량 수요를 뺀 값이다. 전년에는 주민 1명당 식량 1단위가 필요했다. 여당은 연초 현직 내각을 사용한다. 진행 중인 국내 집단행동 수도 관측 원장에 남긴다. 이 개수 자체에는 외교 점수를 배정하지 않는다.

방향 `s → t`는 상품·이주민·원조의 이동 방향이다. 해당 방향의 `import_dependence`는 **s가 t에서** 산 수입액 / s의 외국 총수입액이다. `export_exposure`는 **s가 t에** 판 수출액 / s의 외국 총수출액이다. `food_import_share`는 t에서 s로 들어온 민간 수입 식량 / s의 식량 수요다. 세 값은 모두 천분율이다. 분모가 0이면 0, 1000 초과는 1000으로 표시한다. 정책 행은 전년 실적을, `closing.last`는 당년 실적을, `closing.totals`는 누적 실적의 분자와 분모를 사용한다. 국가별 총수입·총수출·식량 수요 분모는 쌍마다 반복되므로 여러 외교 상대의 분모를 합하면 중복된다.

양국을 직접 연결하는 용량 양수인 국경 도로의 용량 합계를 K, 가장 짧은 도로 길이를 d로 둔다. 연결이 없으면 양쪽 모두 0이다. 정부는 계획을 세울 때 내륙을 포함한 자국 공공창고의 식량을 합산한다. 실제 발송에는 길에 닿은 출발 창고가 물량과 운임을 모두 부담한다. K는 운송량의 상한이고 d는 최저 운임을 계산하는 거리다. 화물 한 단위를 100타일 보내는 운임은 식량 한 단위이며 송장별로 올림한다.

## 무역 협정과 접근 의무

한 나라의 서명 점수는 다음과 같다. 모든 물량·금액은 직전 해 해당 상대와의 실적이다. P는 자국 인구, U는 자국 식량 부족량, B는 양국 총 교역 물량, W는 산업 집단의 도로 요구(천분율), w는 현직 강령의 도로 가중치(과도정부 2), L은 직전 관계 지수다. 나눗셈은 매 연산 아래 정수로 내린다.

```text
접근가치 = (수입액 + 수출액) // 8 + 4 × min(U, 수입 식량)
         + (수입 광석 + 2 × 수입 도구) × W × w // 2000
B > 0 이면 접근가치 = 접근가치 × min(K, B) // B
행정규모 = max(1, P // 2000)
예상 수출 운임 = ceil(min(수출 물량, K) × d / 100)
서명점수 = 접근가치 + L × 행정규모 // 12
         − 8 × 행정규모 − 전년 실납 수출 운임 − 예상 수출 운임 − 4 × min(U, 수출 식량)
```

인접하며 전년에 해당 쌍의 실제 거래가 한 건 이상 있고 서명점수가 양수인 정부가 제안한다. 같은 해 두 정부가 모두 동의하면 서명연도부터 5년간 협정이 유지된다. 한쪽만 제안하면 상대국의 거절을 기록한다. 만기 다음 해는 종료를 기록하고 그다음 해부터 재협상이 가능하다. 협정은 상대국의 거래 제안을 기존 같은 재화의 매칭 과정에서 우선 처리한다. 구매력·재고·가격·기존 국경 운송 용량을 함께 적용하므로 서명이 실제 체결량을 보장하지 않는다.

협정의 의무는 상대에게 약속한 거래 접근을 유지하는 것이다. 유효 협정 아래에서 수출국이 1000 미만 한도를 부과했고 거래가 성립할 조건이 갖춰진 물량을 그 한도 때문에 거부한 해에 해당 방향의 위반을 1회 기록한다. 수요나 재고가 없어 거래가 없거나, 거래 제한을 공표했어도 구속된 물량이 0이면 위반 횟수는 0이다. 어느 방향이든 실제 위반이 2년 연속 발생하면 연말 해지하고 다음 2년간 재서명할 수 없다. 액션이 없는 해는 연속 위반 횟수를 초기화한다. 동일 쌍에서 양방향 모두 위반하면 방향별로 2회, 연속 기간으로는 1년이다.

## 수출 제한, 출국 제한과 입국 수용

모두 D에서 인접국에만 적용한다. 1000은 전량 허용, 500은 절반 허용이다. 분자와 분모가 함께 기록되므로 발표와 실제 거부량을 구분할 수 있다.

- 수출 보호 가치가 `8 × min(U, 전년 상대국행 식량) × (1000 + 소비층 구호 요구) // 1000`이고, 수출 기회비용이 `8 × 행정규모 + 전년 상대국행 수출액 // 16`이다. 직전 식량 수출이 있고 보호 가치가 비용을 초과하면 해당 방향의 민간 화물 한도가 500이다. 이 조건이 적용되지 않고 상대 방향에서 직전 거래 거부가 실제 발생했으며 양국 긴장이 100 이상이면 750이다. 각 도로·방향에서 세 재화가 같은 한도를 공유한다.
- 전년 같은 방향의 실이주가 있고 자국 인구가 감소했으며 산업층 도로 요구와 농업층 불만의 합이 100 이상이면 발신국은 출국량을 750으로 제한한다. 같은 방향에 실이주가 있었고 수신국 부족률 60 이상, 소비층 불만 40 이상이면 수신국은 입국량을 500으로 제한한다. 각 기준은 해당 지역 출발 요청과 수신 지역의 수용 능력에 따로 적용한다. 국내 이주에는 두 한도를 적용하지 않는다.

## 양측 식량 원조

수신국이 필요한 식량 N은 `min(max(0, 직전 부족 − 연초 공공 식량), 수신 인구 // 32)`다. 발신국은 자국에 `P // 64 + U // 2 + P × 소비층 비축 요구 // 8000`을 남긴다. 그 뒤 공공 창고에서 쓸 수 있는 양 Q는 `min(P // 48, max(0, 공공 식량 − 남길 양))`이다. 제안 가능량 H는 `min(N, K, 100 × Q // (100 + d))`다. 예상 운임 F는 `ceil(H × d / 100)`이다.

지원 점수는 상대 부족률에서 자국 부족률을 뺀 후 신뢰와 여당의 구호 가중치, 비용을 반영한다. 신뢰 기여는 `(신뢰 − 500) // 5`, 여당 기여는 `(구호 가중치 − 2) × min(100, 상대 부족률) // 10`이다. 여기서 전년 지원 물량 대비 운임·하역 손실률(천분율)의 1/8과 F의 자국 인구 대비 천분율을 뺀다. 원조에는 조세 수입이나 현금을 추가하지 않는다.

1. 상대에게 요청 가능한 N이 2 이상이고 자국 부족률이 30 이상인 수신국이 최대 한 곳을 골라 N을 요청한다. 큰 H, 높은 신뢰, 적은 예상 운임, 작은 국가 ID 순서다.
2. H가 2 이상, 지원 점수가 양수, 신뢰가 300 이상인 발신국은 최대 한 곳에 H를 제안한다. 지원 점수에 요청을 받은 경우에만 25를 더해 비교하고 H, 작은 대상국 ID 순서로 동률을 푼다. 요청 없이도 선제 제안이 가능하다.
3. 수신국은 요청한 상대, 신뢰, 작은 발신국 ID 순으로 제안을 읽고 신뢰 350 이상일 때 남은 N 이내의 2단위 이상만 수락한다. 요청을 받고도 제안하지 않은 행위와 제안했으나 수신국이 거절한 행위는 서로 구분한다.
4. 승인량은 운송 상한이다. 실제 영수증의 `quantity`는 발송 물량, `received`는 하역 손실을 뺀 수신 창고 입고량, `cost_food`는 발신 창고의 운임이다. Q는 승인량을 산정할 때 최단거리 운임으로 계산한 계획 예산이다. 물류 단계에서는 창고마다 실제 잔고와 도로 거리로 운임을 내므로 긴 도로를 쓰거나 여러 건으로 나눠 보내면 총지출이 Q보다 클 수 있다. 개발 시드 0의 4년차 국가 2→3에서 Q는 191, 발송은 187, 실운임은 19로 발신측에서 식량 총 206을 차감했다. 미발송분은 사건으로 남으며 차기 원장에 가공 채권·채무를 만들지 않는다. 입고 후 국내 정부가 잉여·예산·구호·저장 규칙을 계속 적용한다.

## 연말 관계와 증거

### 원조를 경험한 지역의 정치 반응

공여 창고의 실제 발송량과 운임 합계를 O, 수혜 창고의 순입고를 I, 그 지역의 당해 기초 인구를 P라 한다. 같은 지역에 여러 송장이 있으면 먼저 더한다. 기존 5.0D의 실현된 경제·정치 관측 뒤에 농업·산업·소비 집단별로 다음 보정을 적용한다. 전년 말과 이번 해 모두 구성원이 있어야 한다.

```text
i = min(250, 1000 × I // max(1,P))
o = min(250, 1000 × O // max(1,P))
x = i × 전년 비축 요구 − o × max(전년 구호 요구, 전년 비축 요구, 전년 지출보류 요구)
δ = sign(x) × min(12, abs(x) // 4000)
지지 = clip(경제 결과를 관측한 지지 + δ, 0, 1000)
불만 = clip(경제 결과를 관측한 불만 − δ, 0, 1000)
```

지지 점수의 실제 차이를 노출 지역에 기록한다. 변화가 있고 당해 요구가 존재하면 갱신된 지지·불만으로 해당 요구의 압력을 재계산한다. 해당 연도의 선거와 집단행동은 연초에 이미 결정됐으므로 반응은 이후 결정에 쓰인다. 수혜국 주민이 실제 섭취한 구호는 별도 국내 원장에서 확인한다. 같은 국가 안에서도 원조 물류에 직접 노출되지 않은 지역에는 이 보정이 없다. [정치 반응 수식](../civsim/aid_opinion.py) · [지역별 수기 시험](../tests/test_aid_opinion6.py)

### 국가 쌍의 실적 갱신

국가쌍의 최초 신뢰는 500, 관계·협력·긴장·호혜는 0이다. `R(x,n)`은 분모 0이면 0, 그 외에는 0~1000으로 제한한 `1000 × x // n`이다. 아래의 조건값은 참 1, 거짓 0이다.

```text
방향별 교류 가치 V = 민간 거래액 + 8 × (실제 원조 입고량 + 실이주 인구)
당년 호혜 = R(2 × min(Vab, Vba), Vab + Vba)
당년 협력 = 180 × 실제 거래가 있었던 방향 수 + 120 × 어느 쪽이든 실이주
          + 300 × 어느 쪽이든 원조 입고 + 120 × 어느 쪽이든 실제 협정 접근 기회 전량 준수
당년 긴장 = min(1000, 300 × 교역 제한에 의한 실거부 + 200 × 이주 제한에 의한 실거부
                   + 300 × 실제 협정 위반 + 100 × 승인 원조 미발송)
신뢰 목표 = clip(500 + 당년 협력 // 3 + 당년 호혜 // 6 − 당년 긴장 // 2, 0, 1000)
갱신값 = (3 × 각각의 이전 값 + 당년 목표) // 4
관계 = clip(갱신 신뢰 − 500 + (갱신 협력 + 갱신 호혜) // 4 − 갱신 긴장 // 2, −1000, 1000)
```

협력·긴장·호혜·신뢰 모두 이 평활식을 적용한다. 관계는 지수이며 경험적으로 추정한 여론조사나 외교가치가 아니다. 화폐·식량·사람을 섞은 V는 호혜 신호에만 쓰며 재화 장부에는 전기하지 않는다. 물리 원장의 거부량은 그 시점의 후보별 기회 수량이므로 여러 경로에서 재시도된 물량·사람을 독립된 피해 인원으로 합산할 수 없다.

`opening → policy → flows → closing` 순서로 읽으면 결정과 당년 결과가 분리된다. 사건의 `source → target`은 행위자에서 상대국으로 향한다. 원조 요청은 수신 예정국→기부 예정국, 입국 제한은 입국정부→출국정부다. `quantity`에 원조 사건은 식량, 접근 위반은 실제 거부된 재화 단위, 제한 공표는 허용 천분율, 협정 체결·만료는 1건을 적는다. 한 쌍의 누적 행은 방향별 수출입 기초 물량·금액, 원조 발송·수신·운임·하역, 이주와 실거부, 제안·거절·위반을 보존한다.

동일 상태 포크의 `no_new_pact`는 당년 새로 공동 합의할 수 있었던 한 협정만 유보하며 양측의 원래 제안 의사는 남긴다. `open_trade`는 실제 제한을 선택했던 한 방향만 연다. `open_migration`은 그 이동 방향의 출국·입국 한도를 모두 연다. 포크는 원래 창고·인구·이전 협정·다른 정부 판단을 복사하고 같은 해 물리 원장을 재계산한다. 이 비교에서 장기 균형이나 독립된 출국·입국 효과를 추론할 수 없다.
