# 6.0C1 민간 국경 분쟁과 양자 협의

한 국가쌍에서 실제로 저지된 통상·이동과 기존 통상협정의 접근 의무 위반을 관측한다. 매년 첫날에 직전에 **끝난** 연도의 실적을 읽는다. 협의가 수락되면 바뀌는 값은 두 나라의 협의 상태다. 수락에 경제적 비용이나 보상을 배정하지 않으며 신뢰와 긴장도는 직전 경제 경로에서 읽은 원래 관측값을 보존한다.

## 관측 범위와 수치

8개국 기준 매해 순서를 정한 28개 국가쌍을 각각 한 번 처리한다. 입력은 6.0B2 D의 `foreign-years`에서 어느 나라가 누구에게 무엇을 보냈는지 구별하는 두 방향의 행이다. 직전 시드·연도·정책, 공여 방향의 통상협정 위반 횟수, 민간 식량·광석·도구의 실제 거래량과 거래대금, 제한된 화물량, 실제 이주자와 출국·입국에서 각각 제한된 인원, 연말 양자 긴장도·신뢰도만 읽는다.

두 방향이 있으면 완전한 관측이다. 한 방향뿐이면 그 원행을 보존하되 국가쌍의 상태를 동결한다. 양쪽 모두 없으면 증거 목록은 빈 값이며 상태를 동결한다. 이때 어느 쪽도 새 협의를 요청하거나 승인하지 않는다. 첫해에는 직전 관측이 없으므로 28개 쌍 모두 미관측이고 기초 분쟁·협의가 없다. 6.0B2 개발 시드 20개에서 실제로 발행된 200년치 D 원자료의 112,000개 국가쌍·연도 중 양방향 공개는 49,000개, 양쪽 모두 미공개는 63,000개였다. 한쪽만 공개된 입력도 별도의 회귀 사례로 검증한다.

## 분쟁 시작과 완화

한 방향의 화물 시도량은 실제 세 종류 재화의 거래량 합과 제한된 화물량의 합이다. 이동 시도량은 실제 이주자 수와 출국·입국 두 단계의 제한 인원 합이다. 두 제한 인원은 국경 결제에서 순차적으로 집계된다. 상품 단위와 사람 수는 따로 비교한다.

- 기존 조약의 접근 의무 위반이 확인되면 분쟁이 시작된다. 또한 어느 한 방향에서 실제 제한 물량이나 인원이 양수이고 해당 종류의 시도량 중 1/4 이상이 제한된 경우 시작된다. 나머지 경우에도 양자 긴장도가 125/1000 이상이고 실제 제한이 있었다면 시작된다. 곱셈으로 정수 한계를 비교한다.
- 진행 중인 분쟁은 새 실제 제한이 관측된 해에 계속되고 조용했던 관측 횟수는 0이 된다. 두 번의 완전한 양방향 관측에서 제한과 위반이 연이어 없으면 두 번째 관측에서 완화되어 종료된다. 중간의 미관측 해는 이 횟수를 늘리거나 지우지 않는다.
- 사건은 시작 `start`, 계속 `continue`, 완화 `ease`, 관측했지만 분쟁 없음 `none`, 근거 불충분 `unobserved`로 기록한다. 양방향을 완전히 관측했고 거래도 제한도 없는 해와 양방향 관측 자체가 없는 해를 구별한다.

## 제안과 동의

분쟁 중에는 양쪽이 각각 자기에게 귀속되는 증거를 판단한다. 상대방의 조약 위반은 요청 점수 2, 상대 수출 제한으로 막힌 자국 수입, 상대국의 출국 제한, 자국 출발자에게 적용된 상대의 입국 제한은 각 1이다. 실제 제한이 양수일 때만 해당 항목을 센다. 점수가 높은 쪽에 제안권이 있고 동률이면 작은 국가 번호를 우선한다. 적어도 한 항목이 있고 협의 정책이 켜진 경우에만 그 나라가 상대방에게 협의를 요청한다.

상대방의 응답은 별도로 계산한다. 자신에게서 상대에게 향한 실제 거래대금 또는 실제 이동이 양수이고, 관측 신뢰도는 400/1000 이상, 관측 긴장도는 500/1000 미만일 때만 승인한다. 응답자가 실제 교류를 중시하는 소규모 정책 모형이다. 모형 외교의 실증적 추정치로 보정한 계수는 없다. 수락과 거절에 대해 요청국·응답국·판단 항목을 모두 남긴다. 요청 점수와 `positions.consents`는 역할이 다르다. 전자는 해당국이 요청할 유인이고 후자는 그 나라가 **응답자라면** 보일 의향이다. 요청을 보낸 행위와 상대방의 실제 승인 두 가지가 있어야 `closing.consulting`이 참이 된다.

보류 `defer`는 협의 제도가 꺼져 있거나 활성 분쟁 중 새 요청 근거가 없을 때의 결정이다. `declined`는 실제 제안에 응답자가 거절한 경우다. 완전한 관측마다 당해 협의 상태를 다시 결정한다. 증거가 빠진 해에는 마지막으로 확인한 상태를 유지하고 새 결정을 기록하지 않는다.

## 사용과 검산

```python
from civsim.civic_diplomacy63 import CivicDiplomacy, audit_civic_pair

state = CivicDiplomacy(seed=0, nations=8, consult=True)
first_year = state.advance(1)
held = state.fork(consult=False)
regular = state.advance(2, previous_rows=direction_rows_from_year_1)
deferred = held.advance(2, previous_rows=direction_rows_from_year_1)
audit_civic_pair(regular[0, 1], previous_row=first_year[0, 1])
```

포크 양쪽에 같은 입력 행을 쓰려면 리스트처럼 두 번 순회할 수 있는 값을 넣는다. 각 세계는 쌍마다 활성 여부·조용한 관측 횟수·협의 상태만 보관하며 연간 행을 호출자에게 돌려준다. CSV 문자열과 정수를 입력으로 받을 수 있다. 같은 방향이 중복되거나 시드·연도·정책·범위·양방향 신뢰도/긴장도가 맞지 않으면 그해 어느 쌍의 상태도 바꾸지 않고 실패한다. 반환한 기록을 나중에 편집해도 이미 저장한 다음 해의 기초 상태에는 영향을 주지 않는다.

각 기록은 시드·연도·국가쌍·정책, 연초와 연말 상태, 실제 근거 연도와 방향별 원수치, 신호 계산의 분자·분모, 사건, 양국의 요청 및 승낙 판정을 담는다. `audit_civic_pair`는 해당 근거로 계산을 재실행한다. 직전 기록을 함께 주면 시드·양자쌍·연도와 기말→기초 연결도 검사한다. 실제 입력이 이전 경제 원장에서 왔는지는 별도로 해당 출처 원장과 대조한다.

`python -B -m unittest tests.test_civic_diplomacy63 -v`로 6개 회귀 테스트를 실행했다. 실제 개발 시드의 CSV 입력 순서를 뒤집어 동일 기록이 나오는지, 협의 허용·보류 분기의 원자료와 분쟁 여부가 같은지, 수락·거절·완화·결손·시점 위조를 각각 검사했다.
