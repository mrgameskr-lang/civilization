주 대비는 각 시드의 200년 통합 정책과 정부 없음이며 시드 0~19와 20~39를 따로 계산했다. 50·100년은 같은 연속 경로의 중간 관측이다. 네 군의 초기 32개 지역·8개국, 비축과 도로 추가분이 0인 공공 상태를 각각 SHA-256으로 대조했다. 매년 정부·민간의 재화와 인구를 검산하며, 무개입 민간 원장을 직렬화할 때 정부 장부만 제거한다. 개발 시드의 50·200년 민간 원장 해시 40개가 기존 4.0 보관본과 일치했다.

부족률은 주민이 먹지 못한 식량을 전체 식량 필요량으로 나눈다. 배급 격차는 각 지역의 연간 식량 충족률과 같은 해 세계(또는 소속 국가) 충족률 사이의 절대차에 그 지역의 식량 수요를 곱한 뒤 모든 인년으로 나눈 값이다. 인구 0인 지역은 가중치가 0이다. 지역 수를 동일하게 세지 않으며, 국내와 세계 격차는 합이 일정한 분해 항이 아니다. 현금 HHI는 세계 현금 중 각 국가의 기말 민간 현금 비중의 제곱합이다. 토양은 농지 타일 수로 가중했다.

국내 민간·공공 물류는 같은 도로 용량을 사용한다. 다중 구간 화물은 통과한 구간마다 사용량을 차감한다. 도로 신설은 이듬해부터 용량을 늘린다. 표의 행정 계획 수와 배정 노동, 지불한 현물, 실제 배송량은 각자 다른 항목이다. 비축의 편익은 실제 배급과 재고·부패의 관측으로 평가했다. 별도 재난 충격을 주입한 실험, 확률적 신뢰구간, 수백 지역의 성능 측정은 시행하지 않았다.

python -B -m experiments.phase5a --sample dev --out ../../work/phase5-replay-dev --workers 8 --verify-against examples/phase5/study/dev
python -B -m experiments.phase5a --sample holdout --out ../../work/phase5-replay-holdout --workers 8 --verify-against examples/phase5/study/holdout

동결 커밋 `75af26c`로 두 표본을 실행한 뒤, 예산 승인·집행을 매년 별도로 대조하는 읽기 전용 감사까지 켜고 새 프로세스에서 32,000세계연도를 재실행했다. 개발과 독립 검증 각각 240/240 체크포인트에서 두 초기 상태와 연간 원장 해시가 일치했다. 최초 Windows 출력은 별도 복사해 보존했고, 공개본은 Git 규칙에 맞춰 두 JSON 파일의 줄바꿈을 LF로 통일했다. 재실행 결과의 CSV 5개와 `cases.json`은 공개본과 각 바이트가 일치했다. 재실행 시간은 개발 230.864초, 독립 검증 233.165초였다. 두 표본을 동시 실행했고 같은 호스트에서 테스트·다른 검증도 실행했으므로 이 값은 해당 실행의 경과시간이다.
