# 공공창고의 식량은 왜 사라졌나

PR #24의 기본 경로에서는 151–200년의 **64,000지역·연도 모두 양의 수확**을 냈다. 그중 **63,939건(99.90%)**은 국경 교역과 운임 정산 후 보호선을 넘는 민간 식량이 없었다. 나머지 61건 중 12건은 잉여가 있었지만 실제 징수는 0이었고, 49건만 징수로 이어졌다. 40개 세계의 마지막 50년 동안 식량세로 실제 입고한 식량은 총 331단위였다. 국가 간 비축 이동도 세계 전체 재고를 보충할 수 없다. [지역·과세 원인별 집계](../examples/food-reserve-v1/fiscal-diagnosis.json)

검증 20개 세계에서 200년차 A의 세계당 평균 총수확은 107,200.80단위, 주민 필요량은 약 122,576단위였다. 경작을 계속하고도 해당 연도 세계 수확이 필요량에 못 미쳤다. 재고의 지역 분포, 국경 거래, 운임, 12.5%의 주민 보호 여유를 거친 후에야 징수할 수 있어 정부 세원은 일찍 사라졌다. 구호와 기존 유지비의 우선순위만 바꾸는 B에서도 고갈은 지속됐다.

## 생산과 징수가 갈라지는 시기

A에서 수확한 지역의 과반이 과세 잉여를 잃은 상태가 처음 5년 지속된 시작 연도의 중앙값은 개발 21년, 검증 25.5년이었다. 세계 공공 식량이 1일분 아래로 내려간 5년 구간의 시작 중앙값은 각각 31년, 38년이었다. 5년 연속 기말 공공 식량이 정확히 0이 된 시작은 57년, 56년이었다. 값이 짝수 개라 중앙값에 0.5년이 나타날 수 있다.

## 지속 가능성과 주민 부담

151–200년 매년 말 주민 식량 1일분 이상을 비축한 세계는 A와 B 각각 0/40, C는 40/40이었다. C는 320개 국가 각각에서도 이 조건을 만족했다. C의 200년 말 창고는 개발 33.51일분, 검증 32.78일분이었다. 50년간 1일분을 유지하고 151년 기초보다 200년 기말 재고가 줄지 않은 세계는 C에서 개발 9/20, 검증 7/20이었다. 따라서 200년까지 비축을 유지하는 방법은 확인됐지만 그 재고가 계속 증가한다는 증거는 없다.

C의 200년 누적 부족률은 A 대비 40/40개 세계에서 증가했다. 시드별 차이를 평균하면 개발 +0.1320%p, 검증 +0.1483%p다. 표의 표본 합산 부족률은 인구 규모에 따라 각 세계의 가중치가 달라진다. 200년차 인구는 세계당 평균 개발 5,518.55명, 검증 6,091.30명 적었다. 누적 실제 섭취는 각각 평균 751,870.25와 779,269.50단위 줄었다. 절대 미충족량도 줄었지만, 인구 경로가 달라져 누적 필요량이 더 크게 줄었다.

검증 시드 36에서 C의 기말 인구는 A의 117,506명에서 106,224명으로 감소했고 누적 부족률은 10.1540%에서 10.4721%로 올랐다. 국가별 결과 방향은 섞여 있었다. 마지막 50년 C에서 A보다 부족률이 낮아진 국가는 개발 85/160, 검증 75/160이었고, 높아진 국가는 각각 75/160, 85/160이었다.

기존 표시 유닛의 1–200년 실제 지급 / 표시 유닛-턴은 개발 A 994/7,960, B 936/7,960, C 7,468/7,960, 검증 A 886/7,960, B 858/7,960, C 6,841/7,960이었다. 이것은 창고에서 비용을 낸 게임 세트의 충족도다. 위의 주민 섭취 지표는 별도의 실제 소비 영수증에서 가져왔다. [표시 유닛과 지급의 분자·분모](../examples/food-reserve-v1/verification.json)

## 재현과 한계

[실행 명령과 검증 로그](food-reserve-run.md) · [규칙·수식·자료 사전](food-reserve-rules.md)

- 같은 지역의 단일 작물 함수와 유효 경작 슬롯을 사용한다. 개별 농지의 위치나 작황 예측 오차, 별도의 공공 농장 건설·임금·운영비를 모형화하지 않았다. 총생산이 같은 경우에도 공공 소유권만으로 보호선 이전의 민간 식량이 줄 수 있다.
- 필요량은 연초 인구, 식사는 지역 합계다. 일수 환산은 연중 균등 소비를 가정하며 계절별 접근성이나 모든 지역 주민에게 전달 가능한 양을 뜻하지 않는다.
- 1/8 배정 한도와 비축 목표는 이 실험에 고정된 게임 규칙이다. 다른 계수·정책 조합, 보호선 변경, 200년 이후 안정성은 검증 범위 밖이다.
