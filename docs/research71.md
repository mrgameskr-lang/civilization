# 7.1 지역 농업 기술

토양 보전 사업을 승인한 정부가 그 현장에서 재배법을 시험할 수 있다. 한 지역이 시험을 두 번 마치면 그 지역의 농업 숙련도가 0에서 1로 오른다. 숙련은 이듬해 생산부터 적용된다. 국가 안에서도 어떤 지역은 먼저 배우고 다른 지역은 200년 동안 배우지 못할 수 있다.

## 경제에 들어가는 위치

기존 국가의 기초 기술 계수 `technology`는 세계 생성 때 850~1,200에서 정해진다. 지역은 이 값을 물려받고 국가 장부는 지역 기술을 토지 면적으로 가중 평균한다. 기존 생산식은 농업·광업·제조업 모두에서 `productivity × technology`를 쓴다. 7.1은 농업에만 작용하는 지역 상태 `farm_tech_level`을 생산 원장에 더한다. 지역마다 계속되는 진도와 취득 연도는 국가 소유 지역별로 조회할 수 있다.

시드 0의 타비르는 기초 기술 계수 1,140으로 시작한다. 첫 지역인 타비르 1(지역 ID 28)의 기초 기술은 1,140, 생산성은 944다. 새 농법을 배운 뒤에도 1,140은 유지되고, 곡물 생산에 쓰는 지역 숙련도만 높아진다. [토양 사업 선택부터 이듬해 수확까지의 흐름도](https://www.tldraw.com/f/0bUzL9_Y5-sq8tpY7HMM6?d=spsUAFWy99U-dsfojMrNmc)

| 한 지역의 승인된 사업 1건 | 보통 토양 보전 | 재배법 시험을 병행 |
|---|---:|---:|
| 출고한 광석·도구 | 각각 2 | 각각 2 |
| 민간 생산에서 빠지는 노동 | 4인년 | 4인년 |
| 그중 연구가 사용한 몫 | 0 | 광석 1, 도구 1, 노동 2인년 |
| 직접 관리하는 농지 | 최대 12타일 | 최대 6타일 |
| 시험 진도 | 0회 | 실제 집행한 경우 1회 |

정치·재정 엔진이 선택한 사업과 지역, 행정 한도, 창고와 노동 한도가 먼저 결정된다. 연구는 그 사업의 집행 방법이다. 구호나 도로가 선택된 해에는 그 예산을 가져올 수 없다. 재료와 노동은 기존 공공사업 장부에서 한 번 출고·배정되며, 연구 원장은 이 중 시험 몫을 표시한다. 두 번의 유상 시험으로 숙련을 얻을 때까지 연구에 쓴 누계는 광석 2, 도구 2, 노동 4인년이다. 덜 관리한 농지로 인해 첫해 수확량이 줄 수 있다.

## 의사결정과 생산식

연초 토양 수치를 `S`, 농지 타일 수를 `F`, 직접 관리할 타일 수의 한도를 `m`이라 두면 회복량과 연구 선택에 쓰는 값은 다음과 같다.

```text
gain(m) = min(max(0, 1150 − S), floor(24 × min(F, m) / max(1, F)))
예상 당해 비용 = ceil(직전 수확 × (gain(12) − gain(6)) / max(S, 1))
예상 편익 = floor(3 × 직전 수확 × 30 / (1000 × 2))
```

해당 지역에 토양 사업이 승인되고, 아직 숙련을 얻지 않았으며, 직전 미충족 식량이 필요량의 25% 이하여야 검토한다. 보전 효과를 실제로 일부 포기하고 예상 편익이 예상 비용보다 클 때 시험을 선택한다. 예상 편익은 세 번의 수확에 대한 기술 효과를 필요한 두 시험에 나눈 의사결정용 값이다. 당해 기후나 미래 수확량을 입력으로 삼지 않는다. 집행할 인력·물자가 모자라 사업이 실패하면 진도를 적립하지 않는다.

식량 생산식의 농업 승수는 `1000 + 기존 농업 설비 보너스 + 30 × 연초 숙련도`다. 농업 노동, 토지 수용력, 토양, 기후, 현장에서 쓴 도구와 정수 내림이 함께 실제 생산량을 결정한다. 기존 설비 보너스가 있으면 숙련에 의한 상대 증가율은 3%보다 작을 수 있다. 당해 두 번째 시험에 성공해도 당해 수확은 아직 옛 숙련도로 계산한다. 광석과 도구 생산에 직접 붙는 연구 보너스는 없다.

## 저장과 연대기

```console
python -m civsim.annual_game new --seed 0 --out runs/research/start.json
python -m civsim.annual_game step runs/research/start.json --research --out runs/research/year1.json
python -m civsim.annual_game step runs/research/year1.json --out runs/research/year2.json
python -m civsim.annual_game show runs/research/year2.json
python -m civsim chronicle runs/research/year2.json --format json
```

`--research`는 경제 규칙을 한 번 활성화한다. 이후 정부가 매년 자율적으로 방법을 선택한다. 연구는 각 연도의 `research/regions`, 실제 사업은 `government/works/projects`, 적용한 숙련도와 식량 생산량은 `regions/*/production`에서 대조한다. 새 저장 형식 `annual-game/5`는 원래 시드와 명령, 매년의 원장 해시와 기말 연구 상태를 저장한다. 재생기는 실제 결산이 그 해시 및 상태와 일치하는지 확인한다.

연대기는 두 번째 시험을 마친 해에 취득을 한 번 기록한다. 다음 연도 원장이 있으면 그 원장의 해시와 숙련도·생산량 근거를 연결한다. 마지막 저장 연도가 취득 연도라면 그 이후의 수확은 아직 관측할 수 없다. 다음 해 지역 전체의 인구나 정치 변화에는 경제·이주·선거 등도 관여한다.

## 같은 지역의 두 가지 수확

시드 0의 타비르 1은 4년차에 첫 시험을 마쳤다. 복제한 동일 5년차 연초에서 한 경로는 두 번째 시험을 집행하고, 다른 경로는 그 해의 시험을 보류했다. 두 정부 모두 같은 토양 사업에 광석 2·도구 2·노동 4인년을 썼다. 시험 경로는 이 중 절반을 연구에 썼고 직접 관리한 농지는 6타일이었다. 보류 경로는 12타일을 관리했다.

| 타비르 1의 실제 원장 | 시험 집행 | 시험 보류 |
|---|---:|---:|
| 5년차 수확 | 6,832 | 6,847 |
| 5년차 말 농법 숙련도 | 1 | 0 |
| 6년차 생산에 적용한 숙련도 | 1 | 0 |
| 6년차 수확 | 7,248 | 7,052 |
| 6년차 말 주민 수 | 7,064 | 7,064 |

시험을 집행한 지역은 당해에 15단위를 덜 거뒀고 이듬해에는 보류 경로보다 196단위를 더 거뒀다. 별도로 6년차 시험 경로의 노동·토양·설비를 고정해 옛 농법만 대입하면 수확량은 7,037이다. 새 농법이 그해 생산식에서 만든 차이는 211단위이고, 두 경로 전체의 차이에는 전년에 포기한 토양 관리의 영향도 들어 있다.
