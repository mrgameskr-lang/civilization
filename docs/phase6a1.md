# Civilization 6.0A.1 국제 원조의 결산과 정책별 효과

국제 원조에는 주민이 먹을 식량과 운임으로 지불할 식량이 모두 필요하다. 국가는 연초에 양국 승인량과 자국 지출 예산을 정한다. F군은 국경도로를 지날 때마다 **실제 발송량 + 해당 송장의 실제 운임**을 공여국 연간 예산에서 차감한다. 취급 손실은 발송량에 들어 있다. 공여국의 현금은 이 거래에 사용하지 않는다.

[여섯 실험군과 사전 계획](phase6a1-protocol.md) · [국경별 결제와 원장 수식](aid-budget61.md) · [선택 정책과 실행 순서](diplomacy61.md) · [시드별 원자료 사전](../examples/phase6a1/study/README.md)

## 40개 세계에서 확인한 효과

200년 동안 기존 전 기능 E에서 개발 20개 세계의 공여국 예산을 초과한 경우는 484국가·년, 합계 식량 3,599였다. 검증 20개에서는 480국가·년, 합계 3,512였다. F의 초과는 두 표본 모두 **0회**였다. 검증 F에서 수혜 창고에 실제 도착한 양은 110,639였다. 그중 얼마가 그해 주민의 한 끼가 되었는지는 입고량과 별도로 계산했다.

| 같은 시드의 200년차 비교 | 개발 평균 인구 차이 | 검증 평균 인구 차이 | 검증 세계 수(인구 증가 / 동일 / 감소) |
|---|---:|---:|---:|
| 원조 추가 B−A | −49.50 | +9.60 | 14 / 0 / 6 |
| 수출 제한 추가 C−A | −27.10 | +4.30 | 10 / 0 / 10 |
| 이주 제한 추가 D−A | +8.00 | +10.15 | 9 / 1 / 10 |
| 세 수단 결합 E−A | −8.50 | −18.35 | 12 / 0 / 8 |
| 실제 지출 상한 추가 F−E | −37.30 | +0.85 | 8 / 4 / 8 |

검증 표본에서 세 단독 정책의 평균 인구 차이는 합계 +24.05명이었고 결합 정책은 −18.35명이었다. 상호작용 잔차는 **−42.40명**이다. 상한 하나의 효과도 시드에 따라 달랐다. 검증 시드 27의 인구는 E보다 238명 늘었고 시드 34는 103명 줄었다. 검증 E−A의 평균은 50·100·200년차에 각각 −183.80, −100.70, −18.35명이었다. 평균이나 하나의 시점만으로 일관된 개선을 말하기 어렵다. [경제·외교 효과와 시드별 반례](phase6a1-effects.md)

원조만 추가한 검증 B에서 누적 순입고는 **113,113**, 그해 실제 송장을 없앤 반사실 대비 입고 지역 주민의 섭취 차이는 **−11,017**이었다. 같은 입고 지역·연도를 1년차부터 원조를 허용하지 않은 A와 비교한 섭취 차이는 **+34,569**였다. 후자의 연초에는 두 경로의 인구와 재고도 이미 달랐다. 검증 F에서 입고가 있었던 754세계·년 중 세계 총섭취가 송장 없는 같은 해보다 늘어난 경우는 119회, 같은 경우는 440회, 줄어든 경우는 195회였다. [입고·공여국 부담·실제 섭취](phase6a1-aid-results.md)

## 실행

```sh
python -B -m civsim.aid61 run --seed 0 --years 4 --arm F --out runs/aid61-seed0
python -B -m civsim.aid61 verify runs/aid61-seed0
```

각 실행은 새 디렉터리에 초기 세계, 설정, 모든 연도의 원장을 쓴다. 제공된 예제를 재생하려면 `python -B -m civsim.aid61 verify samples/phase6a1/seed0-capped`를 사용한다. A는 기존 6.0A C, E는 기존 6.0A D의 연간 원장 형식과 계산을 사용한다. B·C·D·F의 감사와 실행은 새 모듈에서 수행한다. [실행 코드](../civsim/aid61.py) · [공개 예제](../samples/phase6a1/seed0-capped)

## 이슈 #13에서 실제로 바뀐 것

시드 0에서 4년차 국가 2는 최단 거리 2타일을 사용해 식량 187에 운임 4를 예상했다. 실제 세 송장의 거리는 2·12·13, 운임은 1·6·12였다. 상한이 마지막 송장의 화물을 87에서 74로 줄이면 같은 연초의 결산은 다음과 같다. 마지막 열은 비교를 위해 **이미 승인된 2→3 하나만 그해 집행 보류**한 경우다.

| 시드 0 4년차 | E 원래 집행 | 같은 연초에서 상한 적용 | 같은 연초에서 2→3 집행 보류 |
|---|---:|---:|---:|
| 국가 2 예산 · 양국 승인량 | 191 · 187 | 191 · 187 | 191 · 187 |
| 실제 발송 · 실운임 · 총지출 | 187 · 19 · 206 | 174 · 17 · 191 | 0 · 0 · 0 |
| 수혜 창고 순입고 · 취급 손실 · 미발송 | 180 · 7 · 0 | 167 · 7 · 13 | 0 · 0 · 187 |
| 수혜국 전체 민간 식량 수입 | 513 | 526 | 650 |
| 수혜국 국내 구호 배급 | 0 | 0 | 0 |
| 수혜국 주민 실제 섭취 | 6,893 | 6,906 | 7,030 |
| 수혜국 기말 공공 식량 | 165 | 154 | 0 |

그해 공여 정부의 식량과 민간 상인의 식량이 같은 국경 용량을 사용했다. 수혜국은 원조 식량을 창고에 보관했고, 공공 선적이 줄자 민간 수입이 늘었다. 이 사례에서 원조의 당해 수혜국 섭취 효과(집행−보류)는 **−137**이었다. 창고에 남은 식량의 미래 가치와 전국 장기 효과는 따로 측정해야 한다. ## 측정값 읽기

연간 시뮬레이션에는 네 종류의 질문이 있다.

- **국고가 얼마나 썼는가.** 입고가 있는 해의 적재량과 송장별 운임을 공여국 단위로 합친다. 예산 총액, 승인 물량, 실제 지출, 남은 예산과 보내지 못한 물량은 각각 단위와 분모를 표시한다.
- **올해 원조로 주민이 얼마나 더 먹었는가.** 실제 국제 원조가 있었던 해에는 동일한 이미 완료된 생산·연초 정책으로 민간 국경 거래, 징수, 국내 구호, 물류, 소비를 다시 계산한다. 먼저 원래 송장들을 넣어 32개 지역의 전체 식사 원장을 재현한 뒤 국제 원조 송장을 전부 빼고 같은 단계를 실행한다. 차이는 부호를 유지해 기록한다. 입고 지역 외에도 민간 거래나 국내 운송의 변화가 나타날 수 있다. [섭취 비교 계산](../experiments/aid_incidence61.py)
- **정책을 200년 유지하면 어떤 세계가 생기는가.** 원조만·수출 제한만·이주 제한만을 같은 시드의 협정 전용 A와 대조하고, 상한의 효과는 F−E로 계산한다. 인구와 필요량이 달라지는 장기 경로에서는 식량 부족량, 부족률, 실제 섭취를 함께 읽는다.
- **효과가 단순히 더해지는가.** 모든 기능을 적용한 E−A에서 세 단독 차이의 합을 뺀다. 비선형 반응과 이후 경제·정치의 되먹임이 포함된다. 이 여섯 군으로 특정 두 수단의 상호작용과 세 수단의 상호작용을 따로 식별할 수 없다.
