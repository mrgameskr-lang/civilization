# 3.1 사전 실험 계획

기준은 PR #4의 커밋 `64fcfeb1a83c046ed523949583c251abc329dfbf`이다. 모든 군에서 동일 시드의 초기 지도·자원·인구 및 기후열을 공유한다. 무역 결제는 식량→광석→도구, 초과 농업 노동은 재배치한다. 투자 실험은 환경·분배 처치와 독립적이다.

## 인구 진단

개발 시드 0–19의 3.0 실물투자 세계를 500년까지 추적한다. 50년 말의 동일 상태에서 각각 토양 손실 방지, 최초 매장량과 같은 유한한 심부 광맥 1회 개방, 현금의 20% 정수 기여·인구비례 재분배를 적용한다. 개입별 200년 결과와 대조군의 시드 내 차이를 사용한다. 광맥 개방량은 외생 지질 조건으로 별도 계상한다. 현금 총액과 양자 간 결제 수지는 유지한다. 자연증감과 이주를 분리한다.

## 투자 실험

3.0의 기존 고정효과·1사업을 대조군으로 사용한다. 두 가지 물리적 효과 조정(체감, 규모)과 연간 사업 한도(1개, 최대 3개)를 교차한 2×2×2 실험이다. 새 일곱 조합은 모두 선택형 3.1이다. 첫 단위당 기본 효과는 농업 12‰, 광공업 25‰, 개간 24명이다. 체감군의 총효과는 `floor(4*b*k/(k+3))`이다. 규모군은 농업·광공업 효과에 `min(2000,P)/max(1,P)`를 적용하고 정수 절삭한다. 규모군의 j번째 가동 자산의 유지비 배수는 `max(1,ceil(P/2000))+floor((j-1)/2)`이다. 2,000명은 명목 설비 범위에 대한 가정이다. 건설의 노동·재료비, 수명, 수요 상한, 5년 예측기간과 재화 평가가격은 3.0을 따른다. 개간 선택에 별도 가중치를 부여하지 않는다.

시드 0–19를 개발 표본, 시드 20–39를 독립 검증 표본으로 구분한다. 검증 표본 확인 전 모든 계수와 주 비교를 고정한다. **주 비교는 combined-multi와 3.0의 200년 시드 내 차이**다. 50·100·150년은 같은 경로의 중간 관측이다. 시드별 기말 인구와 누적 부족량, 부족률(누적 미충족 식량 / 누적 필요 식량), 생산량, 토양, 남은 광맥, 자산별 건설·가동·비용, 현금 집중도를 보고한다. 동일한 다른 두 요인 아래 세 요인을 개별 대조한다. 가장 유리한 검증군으로 주 비교를 교체하지 않는다.

운영 편익은 같은 국가·연도 조건에서 가동 설비의 유무에 따른 재화 순산출 차이를 고정가격으로 평가한다. 유형별 한계값은 해당 유형만 끈 반사실로 정의한다. 상호작용이 있으므로 이 값들을 합하여 사회 전체 편익을 구하지 않는다. 건설·노동·유지비는 실제 원장 지출로 계산한다. 부족량과 부족률의 방향이 다르거나 개간·복수 사업이 불리한 사례도 그대로 기록한다.
