# 협정·원조·국경 제한의 실물 계산

국제도로 한 개는 인접한 두 나라의 지역 중심을 잇는 연속 타일 경로다. 양방향, 세 재화, 민간 매매 및 공공 원조가 하나의 연간 화물 용량을 나눠 쓴다. 사람에게는 기초 인구·결산 후 정주 여력에 따른 별도 이주 기준을 적용한다.

## 연간 집행 순서와 단위

1. 기존 내각이 예산을 승인하고 국내 공공사업을 집행한다. 연초 외교 결정이 승인한 원조는 사업비 차감 후 국경 **출발 지역의 공공창고**에서만 출고한다. 이후 국경 민간 시장, 현물세, 국내 구호·민간 운송과 소비, 출생·사망·이주, 공공창고 부패가 차례로 정산된다.
2. C와 D에서 활성 협정의 양국은 같은 재화 안에서 실제 매칭 가능한 제안을 먼저 처리한다. 협정 상대끼리와 비협정 상대끼리는 기존 순서(높은 매수가, 낮은 구매 지역 ID, 낮은 매도가, 낮은 판매 지역 ID)를 유지한다. 식량·광석·도구의 순서와 가격, 구매자 현금, 판매자의 보호 식량, 운임, 물리적 도로 용량은 기존 계산을 따른다. 대체 가능한 상대와 경쟁하지 않는 협정, 이미 품절인 시장, 수요가 없는 시장의 체결 효과는 0일 수 있다.
3. D의 수출 허용률은 특정 방향에 적용한다. 한 도로의 방향별 민간 누적 판매량은 ⌊기본 도로용량 × 해당 수출 허용률 / 1000⌋ 이하다. 그해 남은 양방향 공용 운송 여력도 동시에 지켜야 한다. 예를 들어 용량 50, 허용률 100‰이면 그 방향의 식량 3을 보낸 뒤 같은 해 광석·도구에 쓸 수 있는 허가는 2뿐이다.
4. 국제 이주에는 먼저 발신 허가, 이어 수신 허가를 적용한다. 발신 **지역**에서 해당 상대 **국가**로 가는 누적 인원 한도는 ⌊그 지역의 연간 출발 희망자 × 발신 허용률 / 1000⌋이다. 수신 **지역**이 같은 상대 **국가**에서 받아들이는 누적 인원은 ⌊그 지역의 정주 여력 × 수신 허용률 / 1000⌋ 이하다. 한 수신 지역에 거절된 사람은 여력이 있는 다른 인접 지역을 시도할 수 있다. 국내 이동에는 기존 규칙이 적용된다.

## 원조 출고와 수령

공여·수혜 양측이 승인한 발송량을 국가 방향별로 읽는다. 한 국가가 여러 국가와 동시에 약속한 양이 가용 재고보다 많으면 공여·수혜 국가 ID순으로 집행한다. 각 방향에서는 가까운 국경도로를 먼저 시도하며, 동률이면 도로 양 끝 지역 ID순이다. 해당 연도 국내 사업이 끝난 시점의 출발 창고 식량만 공여 재원에 들어간다. 같은 해 외국에서 받은 물량과 올해 국경 거래 이후에 징수할 세금은 이번 해의 원조 재원이 될 수 없다.

발송 식량을 q, 타일 간 거리를 d라 하면 아래 항목을 각각 기록한다.

| 항목 | 계산 또는 수량 상한 |
|---|---|
| 운임 | 출발 공공창고에서 ⌈q × d / 100⌉ 식량 차감 |
| 취급 손실 | 실은 q에서 ⌈q / 32⌉ 식량 손실 |
| 수혜 창고 입고 | q − 취급 손실. 식량 저장 한도(수혜 지역 기초 인구//4)의 남은 자리까지 |
| 실제 출고 | 남은 양측 승인량·도로 잔여 용량·출발 재원·도착 저장 공간을 모두 지키는 최대 정수 q. q가 2 미만이면 출고 0 |
| 다음 단계 | 도로 잔여 용량에서 q 차감. 수혜 창고 식량은 후속 국내 구호·보관 등에 쓸 수 있다. |

현금 결제는 민간 국제 매매에서 일어난다. 공공 원조는 발송지 공공식량으로 재원과 운임을 모두 지급한다. 공여국 공민 합산 장부에서 q+운임이 빠지고, 수혜국 공민 합산 장부에 q−취급 손실이 들어간다. 세계 전체 원조로 소모된 식량은 운임과 취급 손실의 합이다. 국경 창고에 들어간 식량을 국민이 같은 해 먹었는지는 후속 국내 배급·소비 원장에서 확인해야 한다. 해당 지역의 국내 세수는 원조 이후의 실제 창고 잔여 용량으로 다시 계산된다.

## 검산과 관측

연간 `diplomacy.physical`의 도로별 `aid_cargo + private_cargo + unused = capacity`다. `aid.shipments`에는 출발·도착 지역, 공여·수혜 국가, 방향을 맞춘 타일 경로, 보낸 양·받은 양·운임·손실이 남는다. `aid.directions`는 양측 승인량이 양수인 방향의 집행 상황이며, `unshipped`는 승인 후 실제로 보낼 수 없었던 양이다. 합의하지 않은 제안·요청은 외교 정책 원장에서 확인한다.

`trade_attempts.denied`는 그 순서에 현금·운송·재고·수요로 가능했던 수량에서 수출 한도 때문에 줄어든 양이다. `migration_attempts.denied_exit`와 `denied_entry`는 같은 시도에서 발신·수신 단계에 각각 걸린 사람 수다. 다른 시장이나 경로에 재신청할 수 있으므로, 거절 합계의 단위는 거래 또는 경로 시도량이다. 대안 정책 시행 시 세계 교역·이주가 얼마나 달라졌는지는 별도 반사실 실행으로 측정한다.

실행 중 실제 세계 지형과 연간 국경 경로를 대조한다. 보관된 한 해만 감사할 때는 좌석·거리·격자 경로·순액을, 전년도까지 주면 국경의 연속성도 검산한다. 초기 지도부터 전체 보관 기록을 검증하면 물리적으로 가능한 도로의 지형·용량·경로까지 재생한다. 공공 지출에는 현행 승인량, 원본 공공창고, 창고 한도 및 다음 징수 원장의 기초 잔액을 독립 적용한다. 민간 거래·수출 허가·입국 허가는 당해 기초에서 재구성한 실제 수확량·현금·식량·인구를 입력으로 다시 매칭한다.

집중 시험은 우선권이 실제 구매자를 바꾸는 경우, 국경 양방향·세 재화의 연간 공유 용량, 원조 수령 당해 재수출 시도, 도착 창고 포화, 미미한 발송량, 인력의 재신청, 조작된 원조 송장·운임·경로를 포함한다. [실물 계산](../civsim/diplomatic_flows.py) · [자동 시험](../tests/test_diplomatic_flows.py)

## 개발 단계 실행 확인

CPython 3.12.14에서 개발 시드 0 전체 지도·8개국으로 A/B/C/D를 각 20년 실행했다. B에서 외교 원장을 제외한 연간 JSON은 A와 20회 모두 바이트가 일치했다. D는 공공창고에서 원조 식량 1,895를 발송하고 1,813을 수령했으며 운임 152와 취급 손실 82를 지불했다. C의 우선 대상에게 실제 체결된 화물은 14,794단위였다. 여기에는 협정이 없어도 체결됐을 거래가 포함된다. 시드 0의 첫 실제 원조는 4년차 지역 9→15로 50 발송, 48 입고, 1 운임, 2 손실이었다. 실제 송장 재검산 시험은 이 경로에서 찾은 최초 양수 송장을 사용한다.

```sh
python -B -m unittest tests.test_diplomatic_flows tests.test_regional_engine tests.test_government5 tests.test_collective_integration tests.test_appropriation_audit5 -q
python -B -m unittest tests.test_diplomacy_integration -q
```

위 두 명령에서 각각 28개, 3개가 통과했다. 원본 `examples` 아래 실제 세계·연간 장부를 함께 보존한 이전 세대 8개도 각각 `verify_run`으로 직접 재생했다. 1.0·2.0·3.0 각 50년, 4.0 2년, 5.0A·B 각 3년, 5.0C 9년, 5.0D 6년으로 총 173개의 연간 장부 및 여덟 초기 세계가 원본 바이트와 일치했다. 5.0D 6년 장부 SHA-256은 `c96297045b5475154e9a6e0cebd0b21a37e9ab6e883b2cd8fe6fcecdbd00c169`다. PR #11 기준 `a4721bd`의 `examples/` 추적 파일 184개에 대한 Git 차이도 없었다. 이 소급 검사의 재생 범위는 보관된 연간 원본 8개이며, 이전 단계별 장기 실험 전체를 다시 실행한 수치와는 구별한다.
