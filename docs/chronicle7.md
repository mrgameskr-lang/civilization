# 연간 원장에서 읽는 문명 연대기

연대기를 만드는 시점은 한 해의 결산이 끝난 뒤다. 예를 들어 시드 0의 첫해에 다르온 1 지역은 식량 7,783단위가 필요했고 6,027단위를 먹었다. 차이인 1,756단위가 소비 원장에 남아 이 해가 식량 위기로 수록됐다. 같은 지역의 다음 해 인구 감소는 별도의 인구 장부에서 읽는다.

## 읽는 법

```console
python -m civsim chronicle studies/chronicle7/small/seed-0/save.json
python -m civsim chronicle studies/chronicle7/small/seed-0/save.json --format json
python -m civsim chronicle studies/chronicle7/small/seed-0/save.json --ledger-year 1
python -m civsim chronicle studies/chronicle7/long/seed-20/save.json --format highlights
python -m civsim chronicle examples/phase6a/seed0-diplomacy
```

첫 명령은 연도별 사건을 보여 준다. 두 번째는 모든 수록 사건의 국가·지역 ID, 양자 사건의 상대국, 중요도, 한국어 설명, 근거를 출력한다. 한 국가 전체의 사건과 양자 협정에는 지역 ID가 없다. 마지막 명령은 그 해의 전체 원장을 UTF-8 JSON 한 줄로 출력한다. 식량 위기의 근거 `/regions/12/consumption/food_unmet`는 이 원장의 `regions` 배열에서 열세 번째 항목의 미충족량이다. 배열 순번과 지역 ID는 개별적으로 확인한다. 각 사건의 `record_sha256`는 마지막 줄바꿈을 포함하는 표준 원장 바이트의 SHA-256이다.

저장 파일에는 시드와 매년 실제 적용한 명령, 연간 원장 해시가 들어 있다. 원래 엔진으로 재생해 모든 해의 해시와 저장 상태를 확인한 뒤 결과를 출력한다. 읽는 동안 저장 파일에 쓰지 않는다. Markdown은 각 사건의 주요 근거 한 곳을 보여 주고, JSON의 `evidence`는 설명에 사용한 각 원본 값을 경로와 함께 보존한다. 인구 차이와 구호 합계는 이 값들로 다시 계산할 수 있다.

긴 기록은 `--format highlights`로 읽을 수 있다. 이미 수록된 사건 중 10년 구간마다 종류별 최고 점수를 구하고, 그중 최대 세 종류의 사건을 연도 순서로 싣는다. 동점이면 먼저 기록된 사건을 우선한다. 원본 `years.jsonl`을 가진 4.0·5.0A~D·6.0A·6.0A.1·6.0B1·6.0B2 실행 디렉터리도 열 수 있다. 이 경로는 모델별 검증기를 통과한 원장과 읽을 사본의 해시를 대조한다. 저장된 연간 원장 크기만큼 임시 디스크를 사용한다. 국가 단위 장부만 있는 1.0~3.1은 이번 지역별 연대기의 지원 범위 밖이다.

## 무엇을 사건으로 수록하는가

검출·선별 규칙의 버전은 `chronicle/1`이다. 표에서 `⌊x⌋`는 내림이다. 중요도는 지면을 배정하는 편집 점수이며 발생 확률을 뜻하지 않는다. 국가의 실제 예산, 정파의 점수, 주민의 선택에 입력되지 않는다.

| 사건 | 후보가 되는 조건 | 중요도 |
|---|---|---|
| 지역 식량 위기 | 필요량 대비 미충족 비율 (r)이 20% 이상이며 부족량도 100단위 이상 | 55 + min(40, ⌊50r⌋) |
| 지역 인구 급증·급감 | 연초 대비 절대 증감 비율 (r)이 5% 이상이며 증감 규모도 50명 이상 | 62 + min(32, ⌊200r⌋) |
| 대규모 국내 구호 | 해당 지역의 정규·긴급 구호 도착량 합계가 100단위 이상이며 연간 식량 필요량 대비 비율 (r)이 5% 이상 | 65 + min(30, ⌊100r⌋) |
| 정권 교체 | 기존 집권 정파가 선거에서 패하고 당선 정파가 실제 정책을 집행함. 최초 내각 구성과 유임 제외 | 90 |
| 집단행동 | 청원·시위·현물세 납부 거부·부분 노동 중단 중 새 행동 또는 요구가 시작된 해. 해당 대표 집단의 참여자가 15명 이상이며 참여 비율 (r)이 8% 이상 | 56 + min(20, ⌊100r⌋) + 행동별 0·3·7·9점 |
| 양자 무역 협정 | 외교 원장에 체결 또는 조기 종료 영수증이 있음. 제안·거절·기한 만료 제외 | 체결 77, 조기 종료 91 |

한 해 최대 4건을 중요도 순으로 싣는다. 동점이면 종류, 국가, 지역, 상대국, 설명과 근거 순으로 정렬한다. 식량 위기·같은 방향의 인구 급변·대규모 구호가 같은 지역에서 여러 해 지속되면 첫 수록 뒤에는 직전 수록 점수보다 10점 이상 높아진 해만 다시 싣는다. 한 해라도 후보 기준을 벗어나면 다음 발생은 새로 수록할 수 있다. 연간 한도 때문에 아직 실리지 않은 현상도 다음 해에 다시 심사한다. 보고서에는 전체 후보 수, 반복으로 생략한 수, 연간 한도로 생략한 수가 따로 있다.

정규·긴급 구호의 실제 도착량에는 운임이나 승인 후 미발송량이 들어가지 않는다. 구호로 식량이 도착한 양만으로 주민이 추가로 먹은 양을 추정하지 않는다. 집단행동의 참여자 수는 게임의 대표 집단 집계값이다. 같은 사람의 여러 해 참여를 합쳐 고유 인원으로 해석할 수 없다.

## 재현 실험

시드 0과 20에 같은 명령을 적용했다. 1년차는 기본 정책이고 2년차부터 기존 공공 경작·긴급구호 정책을 사용했다. 두 세계 모두 이동 명령은 없었다. 6년짜리 세계 두 곳에서 먼저 근거 대조를 마친 뒤 같은 조건을 200년까지 진행했다.

```console
python -m experiments.chronicle7 --years 6 --out runs/chronicle-small
python -m experiments.chronicle7 --years 200 --out runs/chronicle-long
python -m unittest discover -v
```

각 시드·기간마다 연대기 기능을 끈 원본 실행 1회와 같은 저장의 독립 재생 2회를 수행한다. 두 재생은 매년 원본 해시를 검증한다. 마지막 경제 상태까지 대조하고, 두 번 만든 연대기가 바이트 단위로 같은지 확인한다. 두 번째 재생은 모든 수록 사건의 지시 경로를 직접 따라가 수량과 자료형을 검산한다. 시드 간 비교에서는 연간 해시와 시드 표기를 빼고 수록된 사실을 비교한다. [6년 검산 자료](../studies/chronicle7/small/verification.json) · [200년 검산 자료](../studies/chronicle7/long/verification.json)

같은 정책에서도 9년 아르덴의 내각은 서로 달라졌다. 시드 0은 상호부조에서 건설 정파로 교체됐고 새 집권 정파는 11석을 얻었다. 시드 20은 농지관리에서 상호부조로 교체됐고 새 집권 정파는 14석을 얻었다. 각각 9년 원장의 `/competition/countries/0/election/seats/builders`와 `/competition/countries/0/election/seats/mutualists`에서 확인할 수 있다. [시드 0 발췌](../studies/chronicle7/long/seed-0/highlights.md) · [시드 20 발췌](../studies/chronicle7/long/seed-20/highlights.md)

시드 20의 11년에는 로벤 1 지역에 긴급 구호 339단위가 도착했다. 이 지역의 같은 해 정규 구호 도착량은 0이었다. 연대기는 도착한 양까지 기록한다. 추가 섭취량이나 향후 지지율 변화는 이 영수증으로 산출할 수 없다. [시드 20의 전체 사건과 근거](../studies/chronicle7/long/seed-20/chronicle.json)

### 해석 범위

두 장기 표본에서 집단행동은 각각 전체 수록 사건 799건 중 547건, 790건 중 488건이었다. 같은 행동이 여러 해 지속되는 경우를 걸러도 여러 지역·집단에서 시작된 행동이 많이 남았다. 연간 한도는 다른 사건도 생략하게 하므로 연대기의 빈도를 실제 발생률로 쓸 수 없다. 시드 20에는 식량 위기가 한 건도 수록되지 않았지만 이 결과로 주민 식량 부족이 없었다고 판단할 수 없다. 선별 전의 현상을 조사하려면 연간 원장을 확인해야 한다.

두 세계는 재현성과 시드 간 차이를 검증하는 표본이다. 전체 시드에서의 발생 빈도, 중요도 가중치에 대한 독자 평가, 특정 정책이 사건을 유발했는지에 대한 반사실 실험은 수행하지 않았다. 연대기는 관측 사실과 그 산술적 차이만 기술한다.
