# 구호 수혜 관측의 연간 대조

PR #26의 E 규칙을 사용했다. 각 시드에서 같은 초기 세계를 복사해 양쪽 모두 같은 명령과 긴급구호를 집행했다. 한 경로만 종결된 연도의 수혜 영수증을 읽었다. 시드 0은 개발 표본, 시드 20은 독립 검증 표본에서 골랐다.

| 1~16년 합계 | 시드 0 | 시드 20 |
|---|---:|---:|
| 확인한 지역연도 | 512 | 512 |
| 정규 구호 실수령 | 13,473 | 17,903 |
| 긴급구호 실수령 | 12,675 | 12,220 |
| 긴급구호 실수령이 양수인 지역연도 | 46 | 47 |
| 긴급구호만 받은 지역연도 | 42 | 36 |
| 해당 지역연도의 긴급구호 수량 | 11,813 | 10,990 |

시드 0의 2년차 지역 0은 정규 0, 긴급 358을 받았다. 같은 지역의 실제 섭취는 5,205, 미충족은 3,230이었다. 게임은 기존 버전의 지지·불만과 정규 구호 귀속으로 다음 해를 결정한다. 관측을 켰을 때와 껐을 때 두 시드 각각 200개 연간 원장이 같았다. 두 시드에서 열린 국가별 선거 784건의 결과, 지역 집단 지지·불만, 국가별 정책 결정의 차이는 각각 0건이었다. 각 시드의 50·100·200년 E 원장 SHA-256도 기존 원본과 일치했다. 구호 시행 자체의 정치 효과를 추정하려면 구호 정책을 바꾼 별도의 비교가 필요하다.

- `*-receipts.jsonl.gz`에는 처음 16년의 지역별 수령·섭취가 담겨 있다. 압축을 풀면 한 줄이 한 해다.
- `*-years.jsonl.gz`는 200년의 관측 유무별 전체 원장·국내 정치·대표 선거·정부 재정·집단행동 해시와 그해 선거·교체 건수를 담고 있다.
- [요약과 파일 지문](summary.json)에는 압축 파일과 압축 해제 후 원문의 SHA-256을 각각 기록했다.

저장소 루트에서 아래 명령을 실행하면 새 디렉터리에 비교할 수 있는 JSONL 원문과 실행 요약이 생성된다.

```sh
python -m experiments.release_relief_check --seeds 0 20 --years 200 --out runs/relief-benefits-check
```
