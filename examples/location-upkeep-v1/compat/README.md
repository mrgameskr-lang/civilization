# PR 21 기본 경로 호환성

기준은 Git 커밋 `a6d9e6b85f58a2cfc35fc96b1afd8c23b781276c`이다. 검사는 해당 버전의 실험 코드 세 파일을 확인한 뒤, 공개된 두 경로를 기존 인자 그대로 실행한다. 기준 데이터는 Git 객체에서 읽으며 재생 결과는 임시 폴더에서 비교한다. [검증 코드](../../../experiments/verify_annual21.py)

시드 0의 두 경로를 50년까지 재생한 결과, 누적 연간 원장 해시 2개와 해당 시점의 시드 데이터가 일치했다. 별도로 재생한 기존 사례 파일 8개도 일치했다. 압축 파일은 압축 해제한 원장과 압축된 파일의 해시를 모두 기록했고, 이번 실행에서는 두 비교 모두 같았다. 13.945초가 걸렸다. [단기 확인서](smoke.json)

최종 소스에서는 시드 40개의 결과 JSON 40개 전부가 Git 기준 파일과 바이트 단위로 일치했다. 두 경로의 50·100·200년 누적 원장 해시 240개 및 사례 파일 8개도 모두 일치했다. 한국 시간 2026년 11월 22일 03:15:10.577에 시작해 03:27:00.695에 확인서를 기록했고, 작업자 4개로 측정한 경과시간은 710.114초였다. 게시 직후 별도 프로세스에서 240개 원장 해시와 사례 8개의 파일 해시를 원래 Git 객체와 다시 대조했다. 최종 확인서의 SHA-256은 `f2e0855711eb15fa29fdab2f3a7d91f289566a4cff6c7c202dbb0edce0549f62`다. [전체 확인서](full.json)

## 재현

저장소 루트에서 다음 명령을 실행한다. 출력 파일은 매번 새 경로를 지정한다. Python 표준 라이브러리와 기준 Git 객체가 필요하다.

```text
python -B -X utf8 -m unittest discover -v -s examples/location-upkeep-v1/compat -p test_compat_checker.py
python -B -X utf8 -m experiments.verify_annual21 --scope smoke --workers 1 --out fresh/compat-smoke.json
python -B -X utf8 -m experiments.verify_annual21 --scope full --workers 4 --out fresh/compat-full.json
```

전체 검사는 시드 0~39의 두 경로에서 50·100·200년을 확인한다. 시드별 결과 JSON 전체를 기준 Git 파일과 바이트 단위로 비교한다. 각 경로에 포함된 첫해는 동일한 계산 결과를 공유하므로, 16,000개 경로·연도를 얻기 위한 실제 연간 호출은 15,960회다. 소요 시간은 사례 재생까지 포함하며, 새 확인서에는 시작 시간·작업자 수와 당시 소스 파일 해시도 기록한다.

검사기 자체의 회귀 테스트 2개도 실행했다. 원장 해시를 바꾸거나 검증 시점을 누락한 결과를 거부했고, 기존 확인서에 덮어쓰려는 호출은 원래 바이트를 보존했다. [검사기 테스트](test_compat_checker.py)
