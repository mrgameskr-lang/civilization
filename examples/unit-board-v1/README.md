# 두 칸 게임의 이동·저장 검증

40개 초기 보드에서 첫 턴에 주소지 0·소속 1인 말 한 개를 0번 칸에서 1번 칸으로 옮겼다. 같은 초기 보드를 복사한 비교 경로에서는 이동하지 않았다. 이후 양쪽 모두 이동 명령 없이 200턴까지 진행했다. 게임의 초기 식량 조합은 40가지다. 기존 문명 시뮬레이션의 지역·주민·창고 자료는 사용하지 않았다. [게임 시나리오](../../civsim/unit_board_scenario.py)

먼저 짧은 검사 6개가 통과했다. 성공 사례에서는 2개를 옮겨 출발지 식량과 해당 턴의 통과 한도가 각각 3에서 1로 줄었다. 다음 턴에 한도는 3으로 회복됐고 출발지 식량은 1로 남았다. 옮긴 말 2개는 도착지에 그대로 있었다. 이동 직후의 JSON을 새 Python 프로세스에서 읽어 복원한 상태와 다음 턴 상태도 원본과 같았다. [이동 전후·복원 영수증](short-cases.json)

출발지 식량이 0인 사례와 이번 턴 남은 한도가 0인 사례에서는 이동이 거절됐다. 두 경우 모두 입력 직전·직후의 전체 보드가 같았다. 기본 한도 자체가 0인 별도 보드에서도 거절되고, 다음 턴의 한도도 0이었다. [기본 한도 0의 전후 상태](zero-maximum.json)

본 시험에서는 40개 보드 모두 첫 이동이 가능했고 200턴 말에도 옮긴 말이 도착지에 있었다. 두 경우의 주민 수는 주소지별 12명·10명, 역할 명부에 없는 생산 참여 가능 인원은 9명·8명으로 유지됐다. 두 경로에서 게임턴 8,000개씩을 기록했다. 50·100·200턴의 표 240행을 포함한다. 실패 반례는 별도의 통제 입력에서 재현했다. 게임턴과 경제 시뮬레이션의 연도는 별도로 센다. [집계](summary.json) · [시드별 체크포인트](seeds.csv) · [턴별 전체 상태](traces.jsonl.gz)

Python 3.12.14에서 첫 6개 검사는 0.548초에 끝났다. 짧은 재검사를 포함한 본실험은 2.566초, 새 프로세스의 첫 독립 반복은 2.612초였다. 최종 실행기로 한 차례 더 전체를 반복한 시간은 1.833초였고 과학 파일 4개의 전체 바이트와 별도 한도 0 사례가 같았다. 누적 해시는 각 경로의 첫 턴부터 해당 턴까지, JSON 키를 정렬한 상태 행과 줄바꿈을 SHA-256에 순서대로 입력한 값이다. [첫 실행](execution.json) · [첫 반복](replay.json) · [최종 독립 반복](standalone-replay.json)

저장소 루트에서 다음 명령으로 각각 새 경로에 생성한다.

```text
python -B -m unittest tests.test_unit_board_trials -v
python -B -m experiments.unit_board_trials --out fresh-unit-board --verify-against examples/unit-board-v1
python -B -m experiments.unit_board_trials --zero-maximum-out fresh-zero-maximum.json
```
