# 같은 연초 상태에서 추가 구호의 효과

시드 0에서 기존 공공농장 규칙 C를 각각 2년과 10년까지 실행했다. 직후의 국가·지역·창고·도로 상태를 복제해 한쪽은 E를 시작하고, 다른 쪽은 C를 1년 더 유지했다. 다음 해에는 양쪽 모두 E를 사용했다. 이 비교에서 두 번째 해의 차이는 첫해의 선택으로 달라진 재고, 인구, 생산과 후속 결정을 포함한다.

| 분기 | 연도 | 추가 구호 수령 차이 | 정규 구호 수령 차이 | 실제 가계 섭취 차이 | 미충족 차이 | 총수확 차이 | 기말 인구 차이 | 민간 국내 운송량 차이 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 3년차 | 3 | +530 | 0 | 0 | 0 | 0 | 0 | −523 |
| 3년차 | 4 | +84 | 0 | 0 | 0 | −239 | 0 | +391 |
| 11년차 | 11 | +1,254 | 0 | +421 | −421 | 0 | +58 | −735 |
| 11년차 | 12 | +165 | −163 | −412 | +470 | −257 | −5 | +471 |

차이는 조기 E에서 1년 보류 경로를 뺀 값이다. 민간 국내 운송량은 재화별 발송 수량을 합했다. 두 분기의 최초 연도에서 정규 구호 송장은 모두 같았다. 추가 구호는 정규 구호가 끝난 뒤 집행했다. 11년차에 지역 4는 296을 더 받아 296을 더 먹었고, 지역 0은 360을 더 받아 125를 더 먹었다. 이때 세계 가계 미충족은 421 줄었다. 12년차에는 조기 E 경로에서 두 지역의 정규 구호가 각각 38과 125 줄었고 실제 섭취는 각각 127과 230 줄었다. 12년차 기초 인구도 조기 집행 경로가 58 더 많았다.

**관측된 운송 실패.** 개발과 검증 표본의 각 4,000세계연도 중 E를 적용한 기간은 각 3,980세계연도였다. 도로·운임으로 미발송한 세계연도는 개발에서 1개, 검증에서 0개였다. 두 표본에서 승인 뒤 운임이 부족해 중단된 수량은 0이었다. [전체 집계와 자연 사례의 관측·보류 영수증](natural-obstructions.json)

시드 9의 정규 E 115년차에 지역 25는 인구 6,582, 민간 식량 5,438, 이미 지급된 가계 몫 79를 근거로 1,065를 신청했다. 지역 접수 한도 411과 남은 국가 집행 한도 322를 적용한 뒤, 지역 창고에서 311을 전달했다. 유일한 진입 도로 24–25의 연간 용량 463은 추가 구호 전에 모두 사용되어 나머지 11이 도착하지 못했다. 같은 국가의 다른 세 창고에는 각각 1,015, 470, 592의 식량이 있었다. 동일 연초에서 그해의 추가 구호만 보류한 경우보다 정규 E는 세계에서 1,052를 더 전달했고 실제 섭취 또한 1,052 늘었다. 이 세계 차이는 같은 해 모든 지역의 지급을 포함한다.

### 자료

- [3년차 분기](seed-00-year-003.json.gz)와 [11년차 분기](seed-00-year-011.json.gz)는 각 지역의 기초·기말 인구, 민간 식량과 공공창고 재고, 섭취·미충족, 정규·추가 구호 수령을 담는다. 국내 민간 운송과 국경 거래의 개별 전표, 각 도로의 용량과 사용량도 함께 기록했다. 조기 집행 경로는 `early`, 보류 경로는 `held`이다. 각 완전한 연간 원장의 SHA-256과 양쪽 기초·기말 상태 해시를 포함한다.
- [세계 합계와 압축 파일 해시](summary.json)는 각 세계의 절대량과 차이를 제공한다. 식량량은 모형의 정수 식량 단위다. 도로 이용량은 화물이 각 구간을 통과할 때마다 한 번씩 센다.
- [도로·운임 제약 대조](transport-control.json)는 시드 0의 3년차 실제 지도와 가계 수령 신청을 사용한 **인위적 단계 실험**이다. 같은 국가에서 지역 17 이외 창고의 식량을 고갈시킨 조건으로 지역 16의 신청을 비교했다. 도로를 열고 지역 17의 관측 재고를 사용하면 9를 보내고 운임 1을 냈다. 같은 재고에서 목적지의 인접 도로 잔여 용량을 모두 0으로 두면 수령이 0이다. 도로를 열고 지역 17의 재고를 1로 두어도 수령이 0이다. 한 수량을 배달하려면 운임까지 조달해야 한다. 세 대조의 승인은 각각 248이었다. 종단 미발송 사유는 집행이 멈췄을 때의 승인 잔여량을 분류한다. 장애 제거로 모두 지급 가능해진다는 추정에는 사용할 수 없다.

### 재현

저장소 루트에서 다음 명령을 실행한다. 출력 경로는 새 경로여야 한다.

```text
python -B -X utf8 -m experiments.relief_forks --out reproduced/relief-forks
python -B -X utf8 -m unittest tests.test_emergency_relief tests.test_relief_forks
```

정규 E의 장기 궤적에서 자연 발생한 도로·운임 장애를 확인하려면 40개 시드의 결과가 모두 게시된 후 다음 명령을 실행한다. 각 표본에서 200년간의 실제 미발송 사유를 합산한다. 자연 사례가 있으면 시드와 관측 연도가 가장 이른 사례를 재실행하여 그해만 추가 구호를 보류한 경제와 비교한다.

```text
python -B -X utf8 -m experiments.relief_forks --natural-study examples/reserve-relief-v1/study --out reproduced/natural-obstructions.json
```
